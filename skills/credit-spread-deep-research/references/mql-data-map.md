# MQL 取数映射与模板（references/mql-data-map.md）

本文件是信用利差分析技能的数据获取权威参考。所有报表路径、过滤字段、返回字段均基于 Choice「利差监测」三类接口文档，并经 `mcp-mql-tools` 参考检索验证（验证时间 2026-09-29）。首次使用时仍须走一遍参考查询流程复核。

## 1. 数据源与 MQL MCP 工具

- 数据源：Choice 数据中心 HTTP API（基地址 `https://datacenter-choice.eastmoney.com/api/`），MQL 是其上的取数语义层
- 涉及的 MCP 工具：

| 用途 | MCP Server | 工具名 |
|------|------|------|
| 工作流/语法参考 | mcp-mql-tools（远程） | `Get_MQL_Reference` |
| 业务知识检索 | mcp-mql-tools（远程） | `Search_Business_Knowledge` |
| 报表/字段/指标定位 | mcp-mql-tools（远程） | `Search_Context` |
| 数据取数 | mcp-mql-tools（远程） | `Execute_MQL` |

- 取数顺序约束：首次生成 MQL 前必须依次完成 `Get_MQL_Reference` → `Search_Business_Knowledge` → `Search_Context`；后续补查可直接调用。`Execute_MQL` 仅接受完整 MQL 脚本，不接受自然语言。

## 2. 已验证报表路径与字段映射

> 路径内分隔符用**单个实际反斜杠** `\`；`REPORT_FIELD("...")` 中必须使用返回列**中文名**（含括号全名）。

### 2.1 RPT_SCREEN_SPDETE_BASE（利差监测_筛选框）

用于查询可选参数列表：债券类型1/2、期限、评级/品种、曲线编码等。

- **MQL 报表路径**：`Choice报表\报表指标\Choice金融终端\利率与曲线\利率走势分析\利差监测\利差监测_筛选框`
- **过滤列（加载列）**：

| 参数中文名 | 枚举 |
|-----------|------|
| 债券类型1代码 | 101: 利率债 / 102: 中短期票据 / 103: 城投债 / 104: 产业债 / 105: 银行普通债 / 106: 银行二级资本债 / 107: 银行永续债 / 108: 证券普通债 / 109: 证券次级债 / 110: 证券永续债 / 111: 保险资本债 / 112: 同业存单 / 113: 企业债 / 114: 非存款类金融机构债 |
| 债券类型2代码 | 10101: 国债,国开债,地方债,口行债,农发债 / 10201: 中短期票据 / 10301: 城投债 / 10302: 私募城投债 / 10303: 永续城投债 / 10401: 私募产业债 / 10402: 永续产业债 / 10403: 次级永续产业债 / 10501: 银行普通债 / 10601: 银行二级资本债 / 10701: 银行永续债 / 10801: 证券普通债 / 10901: 证券次级债 / 11001: 证券永续债 / 11101: 保险资本债 / 11201: 同业存单 / 11301: 企业债 / 11401: 非存款类金融机构债 |
| 业务类型 | 1: 到期收益率 / 2: 期限利差 / 3: 品种利差 / 4: 评级利差 |

- **返回列（常用）**：收益率曲线编码（YIELD_CURVE_CODE，唯一性字段）、曲线名称（INDICATOR_NAME）、基准期限（EXPIRE_BASE）、债券类型1代码/名称、债券类型2代码/名称、评级/品种序号（CREDIT_LEVEL_NUM）、评级/品种（CREDIT_LEVEL）、期限说明（EXPIRE_DESC）、期限（年）（STD_EXPIRE）、业务类型（BUS_TYPE）

> 评级/品种序号对应关系：0: 地方债,国开债,国债,口行债,农发债 / 1: AAA+ / 2: AAA / 3: AAA- / 4: AA+ / 5: AA / 6: AA(2) / 7: AA-
>
> 期限说明与期限（年）对应：0.08: 1M / 0.25: 3M / 0.5: 6M / 0.75: 9M / 1: 1Y / 2: 2Y / 3: 3Y / 5: 5Y / 7: 7Y / 10: 10Y / 15: 15Y / 20: 20Y / 30: 30Y / 50: 50Y

### 2.2 RPT_CUSTOM_SCREEN_SPDETE（利差监测_利差监测，截面）

获取各品种/期限/评级利差最新截面数据（最新值、区间变动、历史分位）。

- **MQL 报表路径**：`Choice报表\报表指标\Choice金融终端\利率与曲线\利率走势分析\利差监测\利率走势分析_利差监测_利差监测`
- **过滤列（加载列）**：

| 参数中文名 | 说明/枚举 |
|-----------|----------|
| 开始日期 | datetime，与截止日期组合定义截面区间 |
| 截止日期 | datetime |
| 期限 | 1M、3M、6M、9M、1Y、2Y、3Y、5Y、7Y、10Y、15Y、20Y、30Y、50Y |
| 利差类型 | 枚举多选：1: 到期收益率 / 2: 期限利差 / 3: 品种利差 / 4: 评级利差 |
| 基准期限 | 1M、3M、6M、9M、1Y、2Y、3Y、5Y、7Y、10Y、15Y、20Y、30Y、50Y（利差类型=1 到期收益率时传 "-"） |
| 债券类型1级 | 单选，同 §2.1 债券类型1代码枚举 |
| 债券类型2级 | 单选，不筛选时输入 "-"；品种利差（利差类型=3）时形如 `10401-10101-1`（私募产业债-国债） |

- **返回列（常用）**：收益率曲线编码、债券类型1代码/名称、债券类型2代码/名称、评级序号、评级、期限说明、期限(年）、起始日期、截止日期、**最新值（LATEST_VALUE）**、**区间变动（RANGE_FLU）**、**历史分位（HIS_PERCENT）**、业务类型（BUS_TYPE）

> **注意**：该接口返回的"最新值"即当前利差值（bp），"区间变动"为（开始日期, 截止日期）区间的变化，"历史分位"为利差历史分位数。

### 2.3 RPT_CUSTOM_SCREEN_SPDETE_HIS（利差监测_历史走势）

获取利差历史走势时间序列。

- **MQL 报表路径**：`Choice报表\报表指标\Choice金融终端\利率与曲线\利率走势分析\利差监测\利率走势分析_利差监测_历史走势`
- **过滤列（加载列）**：

| 参数中文名 | 说明/枚举 |
|-----------|----------|
| 开始日期 | datetime |
| 截止日期 | datetime |
| 期限 | 同 §2.2 |
| 利差类型 | 同 §2.2 |
| 基准期限 | 同 §2.2 |
| 债券类型2级 | 同 §2.2 |
| 图例类型 | 单选：1-同期限（对比不同类型）/ 2-同类型（对比不同期限） |
| 对比项 | 图例类型=1 时传入期限（如 "1Y"）；图例类型=2 时传入收益率曲线编码（如 "ZB264"） |

- **返回列（常用）**：估值日期（TRADE_DATE）、收益率曲线编码、债券类型1代码/名称、债券类型2代码/名称、评级序号、评级、期限说明、期限(年）、**最新值（YIELD，即当日利差值）**、业务类型（BUS_TYPE）

## 3. 日期窗口（agent 基于报告日 today 计算）

| 变量 | 计算 | 用途 |
|------|------|------|
| `today` | 报告日（YYYY-MM-DD） | 截面取数截止 |
| `start1Y` | today - 364 天 | 近 1 年数据，历史分位与走势基线 |
| `start3M` | today - 89 天 | 近 3 月变化 |
| `start1M` | today - 29 天 | 近 1 月变化 |
| `start6M` | today - 179 天 | 近 6 月补充走势 |

## 4. MQL 脚本模板（基线参考）

以下模板的报表路径、过滤列、返回列均经参考检索验证。替换日期/参数占位符即可执行。

**关键语法约束**：`SetReportFilter` 比较运算符用 `==`（非 `=`）；范围用 `>=` / `<=`；多条件用 `AND` 连接；`in` 运算符不支持，用 `OR`/`IN()` 替代（当前语法支持 `IN`）；`Sort()` 放在所有 `REPORT_FIELD` 声明之后；`OutputBlock()` 零参数标记输出 Block；路径内分隔符用单个反斜杠。

### 4.1 截面取数（RPT_CUSTOM_SCREEN_SPDETE）

```text
// ===== Block #1 品种利差-最新截面（各品种-国开/国债，10Y）=====
ReportBlock(#1, {Choice报表\报表指标\Choice金融终端\利率与曲线\利率走势分析\利差监测\利率走势分析_利差监测_利差监测});
SetReportFilter(
    {截止日期} <= "{today}"
    AND {债券类型1级} == "101"
    AND {基准期限} == "10Y"
    AND {利差类型} == "3"
);
{债券类型1代码}: REPORT_FIELD("债券类型1代码");
{债券类型2代码}: REPORT_FIELD("债券类型2代码");
{债券类型2名称}: REPORT_FIELD("债券类型2名称");
{评级}: REPORT_FIELD("评级");
{评级序号}: REPORT_FIELD("评级序号");
{期限说明}: REPORT_FIELD("期限说明");
{最新值}: REPORT_FIELD("最新值");
{区间变动}: REPORT_FIELD("区间变动");
{历史分位}: REPORT_FIELD("历史分位");
OutputBlock();
```

```text
// ===== Block #2 期限利差-最新截面（国债，10Y-1Y 等）=====
ReportBlock(#2, {Choice报表\报表指标\Choice金融终端\利率与曲线\利率走势分析\利差监测\利率走势分析_利差监测_利差监测});
SetReportFilter(
    {截止日期} <= "{today}"
    AND {债券类型1级} == "101"
    AND {债券类型2级} == "10101"
    AND {基准期限} == "-"
    AND {利差类型} == "2"
);
{期限说明}: REPORT_FIELD("期限说明");
{最新值}: REPORT_FIELD("最新值");
{区间变动}: REPORT_FIELD("区间变动");
{历史分位}: REPORT_FIELD("历史分位");
OutputBlock();
```

```text
// ===== Block #3 评级利差-最新截面（中短票，3Y，AA+-AAA 等）=====
ReportBlock(#3, {Choice报表\报表指标\Choice金融终端\利率与曲线\利率走势分析\利差监测\利率走势分析_利差监测_利差监测});

    {截止日期} <= "{today}"

    AND {债券类型2级} == "10201"
```

### 4.2 历史走势取数（RPT_CUSTOM_SCREEN_SPDETE_HIS）

```text
// ===== Block #4 品种利差-历史走势（近1年，同期限=1，对比项=1Y）=====
ReportBlock(#4, {Choice报表\报表指标\Choice金融终端\利率与曲线\利率走势分析\利差监测\利率走势分析_利差监测_历史走势});
SetReportFilter(
    {开始日期} >= "{start1Y}"
    AND {截止日期} <= "{today}"
    AND {利差类型} == "3"
    AND {债券类型2级} == "10101-10101-2"   // 国开-国债；其他品种请查 §2.1/§2.2
    AND {基准期限} == "-"
    AND {图例类型} == "1"
    AND {对比项} == "1Y"
);
{估值日期}: REPORT_FIELD("估值日期");
{最新值}: REPORT_FIELD("最新值");
{期限说明}: REPORT_FIELD("期限说明");
Sort({估值日期}, "ASC");
```

### 4.3 参数筛选（RPT_SCREEN_SPDETE_BASE）

需要确认某债券类型支持哪些期限/评级/曲线编码时使用：

```text
// ===== Block #10 查询产业债（103/104）到期收益率可用的曲线列表 =====
ReportBlock(#10, {Choice报表\报表指标\Choice金融终端\利率与曲线\利率走势分析\利差监测\利差监测_筛选框});
SetReportFilter(
    {债券类型1代码} == "104"
    AND {业务类型} == "1"
);
{收益率曲线编码}: REPORT_FIELD("收益率曲线编码");
{曲线名称}: REPORT_FIELD("曲线名称");
{债券类型1代码}: REPORT_FIELD("债券类型1代码");
{债券类型2代码}: REPORT_FIELD("债券类型2代码");
{债券类型2名称}: REPORT_FIELD("债券类型2名称");
{评级/品种}: REPORT_FIELD("评级/品种");
{期限说明}: REPORT_FIELD("期限说明");
{期限（年）}: REPORT_FIELD("期限（年）");
OutputBlock();
```

> 占位关键：不同维度要用的 `债券类型2级` 与 `基准期限` 组合不同。建议先执行筛选框 Block 确认可用取值，再取截面与走势，避免因参数不匹配返回 0 行。

## 5. 后处理逻辑与容错降级规则（agent 在内存中完成）

### 5.1 后处理逻辑

1. **截面展平**（`snapshot`）：将 #1/#2/#3 各行按 `债券类型2名称×评级×期限说明` 展开为利差矩阵，提取 `最新值`、`区间变动`、`历史分位`
2. **走势序列**（`series`）：将 #4/#5/#6 按 `估值日期` 升序排列，得到各利差指标的时间序列；近 1 月/近 3 月变化 = 最新值 - 窗口起始值
3. **历史分位**：优先使用报表已给 `历史分位` 字段；缺失时按近 1 年序列自算分位
4. **基准对齐**：品种利差识别基准（国开/国债）；评级利差计算组合（如 AA+-AAA）；期限利差计算组合（如 10Y-1Y）
5. **参考结构**：

```json
{
  "as_of": "<today>",
  "snapshot": { "spread_variety": [], "spread_term": [], "spread_rating": [] },
  "series": { "variety_1y": [], "term_1y": [], "rating_1y": [] },
  "params": { "curves": [], "expire_desc": [], "credit_levels": [] }
}
```

### 5.2 容错与降级规则

| 场景 | 处理 |
|------|------|
| 单个 Block 报"报表不存在/字段不存在/字段名错误" | 回到 §2 参考查询重新定位报表与字段；确认仍不可用则该维度启用外部兜底 |
| 单个 Block 成功但返回 0 行 | 检查 `债券类型2级`/`基准期限`/`利差类型` 组合是否匹配（参考 §4.3 筛选框确认可用取值）；仍无结果则启用外部兜底 |
| 部分字段非空、部分为空 | 使用已有字段，空字段对应内容省略；可选择用外部数据补充空字段 |
| 整个 MQL 调用失败（鉴权/网络/连接器错误） | 降级为外部数据源取数（`WebSearch`/`WebFetch`/研报/已授权 API），在头部 meta 与页脚注明"数据来源：公开渠道"，并提示用户检查 MQL MCP 配置（`em_api_key` 与连接器信任状态） |
| 历史分位缺失 | 用近 1 年走势序列自算分位；序列不足时省略分位维度，不编造 |
| 外部数据与 MQL 数据冲突 | 以 MQL 数据为准，冲突内容省略，不在正文展示矛盾数据 |

**外部数据兜底来源（优先权威）**：
- 中债估值中心（中债收益率曲线与估值）、上清所/中证登官网（估值与发行数据）、中国货币网（银行间市场）、Choice 资讯页面、券商固收研报（利差周报/月报）
- 引用时在正文或图表图注标注确切来源名称与数据日期，例如"（据中债估值中心，2026-09-2x）"

- **禁止**：将多个 Block 报错后硬用近似报表/字段替代；把未经核实的新闻/研报资料混入；用示例数据冒充当日数据。
