# 信用利差分析框架（references/analysis-framework.md）

本文件是信用利差分析技能的**分析框架权威参考**，包含核心概念与定义、7 大分析维度、利差温度计评分法、判断规则库、分维度表模板、未来推演与跟踪清单模板。配合 `mql-data-map.md`（取数）与 `html-guide.md`（版式）使用。

## 1. 核心概念与定义

### 1.1 品种利差（利差类型=1，与 Choice 报表一致）

同期限、同评级下，不同品种收益率之差。默认基准为同期限国开债，可选国债。常见组合：

- 中短票-国开（信用债基准）
- 城投债-国开
- 产业债-国开
- 企业债-国开
- 银行普通债-国开
- 银行二级资本债-国开
- 银行永续债-国开
- 非存款类金融机构债-国开（或金融机构债-国开）
- 地方债-国债（流动性利差）
- 国开-国债（税收利差）

**未选择品种时，默认分析：中短票-国开、非存款类金融机构债-国开、企业债-国开、产业债-国开品种利差。**

### 1.2 期限利差（利差类型=2）

同品种、同评级下，长端收益率-短端收益率。常见组合：

- 10Y-1Y、30Y-10Y、5Y-3Y、7Y-5Y、3Y-1Y
- 利率债看国债/国开，信用债看中短票/城投/二级资本债

**未选择期限时，默认分析 1Y、2Y、3Y、5Y、7Y、10Y、15Y、20Y、30Y、50Y 的期限利差。**

### 1.3 评级利差（利差类型=3）

同品种、同期限下，低评级收益率-高评级收益率。常见组合：

- AA+-AAA、AA-AA+、AA--AA、AAA--AAA
- 可看中短票、城投、产业、二级资本债等品种

**未选择评级时，默认分析 AAA、AAA-、AA+、AA、AA- 的评级利差。**

### 1.4 其他利差

- **信用利差**：信用债-同期限国开/国债
- **税收利差**：国开-国债
- **流动性利差**：地方债-国债
- **条款利差**：二级资本债-普通债、永续债-普通债、含权债-不含权债

## 2. 分析维度与子问题

### 2.1 品种利差

- 城投债：政策化债、土地财政、区域分化、隐债置换、再融资债
- 产业债：行业景气、民企/国企分化、地产链、煤炭钢铁、新能源
- 企业债：发行主体、城投属性、老券流动性
- 中短期票据：信用债基准、流动性好、评级分布广
- 银行普通债：银行负债成本、信用资质、流动性
- 银行二级资本债：银行资本补充、赎回、不赎回事件、流动性、机构配置
- 银行永续债：条款、流动性、资本属性
- 利率债：国债、国开、地方债，看税收、流动性、供给
- **判断**：品种利差绝对水平、历史分位、走阔/收窄、分化

### 2.2 期限利差

- 曲线形态：水平、斜率、曲率；牛平、熊平、牛陡、熊陡
- 关键组合：10Y-1Y、30Y-10Y、5Y-3Y、7Y-5Y、3Y-1Y
- 驱动：货币政策、资金面、经济预期、通胀、供给、配置行为、机构久期
- **判断**：陡平、拐点、骑乘机会、期限选择

### 2.3 评级利差

- 评级：AAA、AAA-、AA+、AA、AA-
- 关键组合：AAA--AAA、AA+-AAA、AA-AA+、AA--AA
- 驱动：风险偏好、信用事件、评级迁移、杠杆、机构行为、流动性分层
- **判断**：评级利差走阔/收窄、等级分化、下沉性价比

### 2.4 利差矩阵

- 品种 × 期限 × 评级
- 输出当前值、历史分位、近1月变化、近3月变化、信号
- 识别：哪些品种/期限/评级利差偏窄/偏阔，哪些有性价比

### 2.5 驱动归因

| 维度 | 关键变量 |
|------|---------|
| 宏观 | 经济增长、通胀、PMI、社融、汇率 |
| 政策 | 货币政策、财政政策、化债政策、资本新规、理财新规 |
| 资金面 | DR007、R007、存单、杠杆、分层 |
| 信用 | 违约、展期、评级下调、不赎回、区域风险 |
| 供需 | 政府债供给、信用债净融资、理财/基金/保险配置 |
| 机构 | 银行、理财、基金、保险、券商自营行为 |
| 情绪 | 成交、换手、经纪报价、取消发行 |

### 2.6 未来推演

- 1-5 日、1-2 周、1-3 月
- 关键触发因素

### 2.7 策略提示

- 久期：拉长/缩短/中性
- 评级：下沉/不下沉/优选
- 品种：城投/产业/二级资本债/中短票/利率债
- 曲线：骑乘、陡平交易、套息
- 杠杆：加/减/中性
- 对冲：国债期货、IRS、信用保护

## 3. 利差温度计评分法

- 评分：**-2 极窄、-1 偏窄、0 中性、+1 偏阔、+2 极阔**
- 分项：品种利差、期限利差、评级利差、流动性、供需
- 综合：各分项加权后给出总分与状态（如：总分 -1.2 → 偏窄）

评分依据（内部使用，报告中只展示结论标签与分项状态）：

| 分项 | 依据 |
|------|------|
| 品种利差 | 各品种利差历史分位加权（<10% 极窄 … >90% 极阔） |
| 期限利差 | 10Y-1Y 等关键组合分位与曲线斜率 |
| 评级利差 | AA+-AAA 等关键组合分位 |
| 流动性 | 地方债-国债、流动性溢价与成交活跃度 |
| 供需 | 供给放量/净融资、机构配置力量 |

## 4. 判断规则库（需按历史分位数和当时市场校准）

| 指标 | 偏窄阈值 | 中性区间 | 偏阔阈值 |
|------|---------|---------|---------|
| 历史分位 | <10% 极窄 | 30-70% 中性 | >90% 极阔 |
| 10Y-1Y 国债期限利差 | <50BP 偏平 | 50-100BP 中性 | >100BP 偏陡 |
| AA+-AAA 中短票3Y 评级利差 | <30BP 偏窄 | 30-60BP 中性 | >60BP 偏阔 |
| 二级资本债-普通债3Y AAA- 品种利差 | <20BP 偏窄 | 20-40BP 中性 | >40BP 偏阔 |
| 城投-产业3Y AA+ 品种利差 | <20BP 偏窄 | 20-50BP 中性 | >50BP 偏阔 |
| 国开-国债10Y 税收利差 | <10BP 偏窄 | 10-20BP 中性 | >20BP 偏阔 |

- **利差走阔驱动**：基准上行、信用风险、流动性收紧、供给放量、风险偏好下降
- **利差收窄驱动**：基准下行、资产荒、配置力量强、政策呵护、风险偏好回升
- 阈值需结合当前历史分位数与市场环境校准，不机械套用

## 7. 分析输出格式（报告正文骨架）

一、结论摘要（3-5 条：利差整体状态、核心矛盾、最偏窄/偏阔品种、未来判断）

二、利差温度计（评分 + 分项 + 加权总分与状态）

三、分维度分析（3.1 品种利差表 / 3.2 期限利差表 / 3.3 评级利差表 / 3.4 利差矩阵 / 3.5 驱动归因表）

四、未来推演（1-5 日 / 1-2 周 / 1-3 月 + 关键触发因素）

五、跟踪清单（表）

六、策略建议（久期 / 评级 / 品种 / 曲线 / 杠杆 / 对冲）

七、风险提示（注明"本报告数据来源于 Choice 数据中心等公开渠道，仅供参考，不构成投资建议"）
