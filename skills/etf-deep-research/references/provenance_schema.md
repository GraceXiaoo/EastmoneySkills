# ETF一页纸6.0公开溯源规范

## 目的

公开溯源让读者看到支撑正文数字和图表的源头返回数据表，同时彻底隔离取数实现和失败诊断。公开溯源不是接口日志，也不是执行审计。

## JSON结构

顶层必须为对象并包含 `version` 与 `sources`：

```json
{
  "version": "6.0",
  "sources": [
    {
      "source_id": "数据表-001",
      "title": "基金基本信息原始数据",
      "as_of": "2026-09-23",
      "columns": ["基金简称", "成立日期", "最新规模"],
      "rows": [["示例ETF", "2020-01-01", "100.00亿元"]],
      "used_in": ["二、基金概况"]
    }
  ]
}
```

## 必填与格式

- `source_id`：唯一中文编号，格式 `数据表-001`。
- `title`：面向读者的中文业务名称，不得使用接口英文名。
- `as_of`：数据日期或报告期；未知时可为空字符串，不得猜测。
- `columns`：非空中文列名数组。
- `rows`：二维数组，每行列数必须与 `columns` 相等；保留源头返回值，不做无说明改写。
- `used_in`：至少一个中文章节、图表或关键指标位置。

## 绝对禁止公开的内容

- 接口英文名、报表标准代码、完整或片段报表路径。
- MQL文本、`ReportBlock`、`SetCodes`、`SetReportFilter`、`REPORT_FIELD`、查询脚本和本地命令。
- `execution_id`、`process_id`、本地文件路径、工具名、调用链。
- 机构代码、基金经理代码、证券内码、数据库主键等内部标识列及其值。
- 错误码、失败原因、重试过程、“未发现/未执行/取数失败”等诊断内容。

## HTML实现

触发器使用 `data-source-id` 与数据表绑定。hover 提示仅显示标题、日期、行列数；click 打开 `<dialog>` 或等价的无障碍模态框，并把对应 `columns`、`rows` 渲染为表格。关闭按钮、Esc关闭、焦点样式必须可用。不得把内部审计对象整体嵌入 HTML 后仅靠前端隐藏；进入 HTML 的 JSON 本身必须已经脱敏。

## Word/PDF实现

正文和图表旁使用 `〔数据表-001〕` 编号，文末按同一编号输出原始数据表附录。附录只接受已通过 `provenance-validate` 的内容。PDF必须与Word附录一致。
