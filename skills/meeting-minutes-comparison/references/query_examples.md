# MCP 搜索 Query 示例

使用 **mx MCP** 工具 `mx_finance_search_news`（无需 API Key，由平台 MCP 鉴权）。

## 通用政策会议搜索

```
{用户原始需求关键词} 政策会议 对比
```

示例：

| 用户意图 | query |
|----------|-------|
| 最近三次政治局会议 | `中央政治局会议 2025 2026 政策对比` |
| 中央经济工作会议 | `中央经济工作会议 2024 2025 政策定调` |
| 中央金融工作会议 | `中央金融工作会议 政策` |
| 两会政府工作报告 | `全国两会 政府工作报告 2024 2025` |

## 从搜索结果提炼会议名称（主模型职责）

1. **Read** MCP 返回，Write `search_raw.json`
2. 从标题、日期、摘要中识别**已召开**的标准化会议全称
3. 按时间从近到远排序，最多保留 N 场（默认 3）
4. 不得编造未召开的会议
5. 将提案列表用于 HITL（见 [defaults.md](defaults.md)）

## 重试策略

- 无结果或结果过少：换同义 query 再调一次 MCP（最多 2 次额外重试）
- 每次调用记录到 `mcp_trace.json`
