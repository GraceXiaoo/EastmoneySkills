# 默认会议与维度（HITL 提案）

Agent 在 MCP 搜索后，结合用户 `search_query` 与搜索结果，按下列规则**提案**会议列表与对比维度，并**必须**经用户确认后再继续。

## 默认会议数量

- 默认对比 **3** 场会议（用户可在 HITL 中修改）
- 会议名称格式：`年份+会议全称`，如 `2025年中央经济工作会议`、`2025年12月中央政治局会议`

## 按关键词推断的默认会议（搜索不足时兜底）

| 用户意图关键词 | 默认会议列表（从近到远） |
|----------------|--------------------------|
| 金融 | 2025年中央金融工作会议、2022年中央金融工作会议、2017年全国金融工作会议 |
| 经济 / 中央经济 | 2025年中央经济工作会议、2024年中央经济工作会议、2023年中央经济工作会议 |
| 政治局 / 中央政治局 | 2025年12月中央政治局会议、2025年7月中央政治局会议、2025年4月中央政治局会议 |
| 两会 / 政府工作报告 | 2025年全国两会、2024年全国两会、2023年全国两会 |

> 优先使用 MCP 搜索结果中可识别的会议名称；上表仅在搜索结果无法提炼足够会议时作为兜底提案。

## 默认对比维度

### 有明确维度的场景（用户 query 含「维度」「对比」「财政」「货币」等）

提案维度（可删减）：

1. 经济形势研判与定调
2. 工作总基调
3. 财政政策力度与工具
4. 货币政策信号与路径
5. 重点任务排序变迁
6. 风险防控
7. 改革与开放

### 无明确维度的场景

向用户说明：**将自动提炼 4–8 个维度**（见 [comparison_prompt.md](comparison_prompt.md) §3.2），并在 HITL 中询问是否接受自动提炼。

## HITL 确认话术（必须使用）

向用户展示提案后，使用类似话术：

```markdown
## 请确认比对范围

根据您的需求「{search_query}」及 MCP 搜索结果，拟采用以下配置：

**拟对比会议（{n} 场）**
1. {会议1}
2. {会议2}
…

**拟对比维度**
- {维度1}
- {维度2}
…
（或：自动提炼 4–8 个维度）

以上默认配置是否可用？
- 回复 **「可以」/「继续」/「确认」** → 按上述配置执行
- 如需修改 → 请补充具体会议名称和/或对比维度
```

**在用户明确确认之前，不得调用 `generate_policy_document.py` 或生成最终比对报告。**

确认后 Write `hitl_config.json` 与 `conferences.json`：

```json
{
  "conferences": ["2025年12月中央政治局会议", "2025年7月中央政治局会议"],
  "comparison_dimensions": ["工作总基调", "宏观政策"],
  "auto_dimensions": false
}
```

`auto_dimensions: true` 表示用户接受自动提炼维度，主模型比对时不预填维度列表。
