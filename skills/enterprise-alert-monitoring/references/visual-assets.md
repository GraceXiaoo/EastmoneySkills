# 舆情图表与图文衔接

## 固定图表清单

本Skill仅生成以下明确规定的两图三表，名称、形式和所属模块均按本清单执行：

| 所属模块 | 图表名称 | 形式及生成方式 |
| --- | --- | --- |
| 舆情概览 | 舆情词云 | 内置代码生成交互SVG及同版静态PNG预览，属于同一图形的两种呈现。 |
| 舆情概览 | 舆情数量趋势统计 | `render_static_charts.py volume`生成纯静态SVG（柱形＋单事件类型折线）；禁止依赖平台JS运行时渲染。 |
| 重点事件 | 重点事件 | 固定五列表格，对话为Markdown表格，HTML为原生表格。 |
| 关联主体 | 关联主体 | 固定五列表格，对话为Markdown表格，HTML为原生表格。 |
| 风险发酵链路 | 风险发酵链路 | 固定五列表格（风险源、发酵判断、发酵链路、关键节点、潜在影响），对话为Markdown表格，HTML为原生表格。 |

不自行新增清单之外的图表，不以“按需”“建议补充”等方式扩展，也不将已规定的组合图拆为多张图或改成其它形式。材料不足、来源不合格或所属章节略去时，按本文件对应规则略去该组件，不另选其它图表补位。报告正文与HTML均遵守相同范围，HTML转换不得追加图表。图表的正文后位置、编号及来源按本文件后续规则执行，各章正文遵循对应执行提示词。

两图使用同一最终有效共享资讯集合，但统计单位不同：词云按去重事件“项”计频，趋势图按去重资讯“篇”计数，不能互相代替。有无词云事件标签不决定资讯能否计入数量趋势，两图分别按各自证据条件生成。

## 舆情数量趋势统计

### 静态渲染

本图及预警分布、风险发酵链路图、未来事件时间轴均由`render_static_charts.py`渲染为纯静态SVG（四种模式：volume/distribution/chain/timeline），数据契约与格式规则（声量图图例顶部居中、细柱≤18px、分布图环形且图内字号与正文一致并限宽640px、链路图17px大字且底框自适应高度、无右上角说明框、时间轴上下均匀分层防重叠、徽章按字宽定容、链路图分区标题、时间轴确定性标注用语）固化于[报告结构与格式规范](report-format.md)。平台组合图渲染路径不再使用：JS运行时依赖在离线或受限环境下会导致图区空白。

### 统计与分类

- 统计对象为目标企业在监测期内、截至时点前公开且来源可核验的最终纳入资讯。沿用共享分析的资讯去重口径，同一原文片段、重复返回和同一转载只计一篇；同一事件的不同独立原始报道仍按实际篇数统计，不以事件数、材料ID数或词云标签频次代替。关联主体自身资讯、历史背景、日期不明及无法拆分的聚合回答不计入目标企业趋势。
- 按核验后的原始发布时间分桶，不能用历史发生日、转载日或抓取日代替。横轴覆盖实际监测期并按时间升序排列，根据期间跨度与样本密度选择日、周或月粒度，通常短期按日、数月按周、更长期间按月；用户明确粒度时优先采用。所有系列使用相同的桶边界，图注明示粒度，期首期末不完整桶标注实际起止，不直接与完整桶比较增减。
- 每桶一根柱体表示该桶全部合格去重资讯的总篇数，多条折线分别表示各**事件类型**在同一桶涉及的去重资讯篇数，如“股票停牌”“立案调查”“业绩亏损”“产能不足”。类型从实际资讯提炼，沿用词云的规范类型名称、同义词归并及阶段区分；有据的正面与重要中性类型同样纳入，示例不作为固定词库。按各篇原文在披露时支持的事实及阶段标注，不将历史背景或提及词自动算作该篇类型，不把后来进展倒填到此前报道。正文仍按共享分析判断情感与严重程度，本图折线按事件类型划分。
- 同一篇资讯可以涉及多个有据事件类型，在同一桶的每种对应类型折线中各计一篇；同一篇内同一类型反复提及或包含多个同类事件时，该类型仍只计一篇。该篇在总量柱体中始终只计一次。没有可核验类型的合格资讯仍计入总量，不强行分配类型或为凑折线制造标签。因此各类型折线可能交叠，其篇数之和不能当作总篇数，图注必须说明“一篇资讯可涉及多个事件类型，各类型数量不可相加作为总量”。
- 每个时间桶内任一事件类型篇数不得大于总篇数；逐桶总篇数之和应与正文同口径本期纳入总篇数一致。核对各类型的归类依据、同义归并和篇内去重，不能要求类型篇数相加等于总量，也不能用去重事件项数代替篇数。原始资讯已提供完整、明确且可核验的监测统计时，只在其类别确为事件类型且篇数定义、去重规则与期间覆盖一致时沿用；不同来源的总量和类型数不混加，不能将原披露的情感分类直接当作事件类型折线。
- 至少有两个覆盖和口径可比的时间桶才生成趋势图。对于已完整整理的本次样本，某个已覆盖桶确无纳入资讯时可记0，并明确仅为本次样本数；检索失败、未覆盖日期或原始统计缺口保留空值，折线在缺口处断开，不补0、不插值、不通过平滑造出数据。证据不足时略去本图，保留有据文字与固定清单内其他有效组件。

### 平台图像描述需求

在同一次共享分析中整理逐桶总篇数、各事件类型涉及的篇数及其支持材料，形成小型内部统计数据供平台作图；不重抄资讯全文、不新增资讯包或检索。提交以下图像需求时，须将企业、期间、粒度、事件类型替换为实际值，并一并提供已核验逐桶数据，不能只发空描述让平台估算：

> 生成柱状图和折线图组合图，图名为“舆情数量趋势统计”。展示<企业全称>在<起始日>至<结束日>期间的本次纳入舆情样本。横轴为按<日/周/月>划分且时间升序排列的监测时段，纵轴为舆情数量，单位“篇”，从0起使用同一数量刻度。每个时段的一根柱体表示去重舆情总篇数，多条不同颜色、带数据点的折线分别表示<实际事件类型列表>各自涉及的去重资讯篇数变化。图例清晰区分“舆情总数量”和各事件类型折线，严格使用随附逐桶数据，空值保留缺口，不平滑插值，不添加未提供的数值。图注标明实际监测期、时间粒度、样本及去重口径，说明本图统计本次纳入资讯，不代表全网舆情总量；注明“一篇资讯可涉及多个事件类型，各类型数量不可相加作为总量”。

此图为纯静态SVG，由`scripts/render_static_charts.py`的`volume`模式生成，不依赖平台图形组件或JavaScript运行时。生成器内置固定样式：图例置于无遮挡区域且完整可读、y轴刻度按数据最大值标注、底部注明「统计范围为本次纳入的去重资讯，不代表全网声量」。多事件类型折线退化为单一代表类型（默认回购类）折线，类型名可通过`focus_name`参数调整。输入契约与CLI见`scripts/test_static_charts.py`内示例；数据不足两个时间桶时按原图规则略去。

图注及“来源”标识绑定支持各桶统计的真实原始资讯，若引用完整监测统计则绑定该统计的实际出处。统计数据、来源绑定及平台返回资源内部留存；最终正文和HTML复用同一次成图、数值、系列、图例、编号、图注及来源。HTML使用平台资源的可独立显示输出，嵌入实际图像或其自包含资源，不依赖临时链接，不在HTML转换时重新绘图。来源和样本修正后重新核算受影响桶及类别，并通过平台重新生成对应图形。

## 重点事件表格

表名为“重点事件”，固定以下五列及顺序，不新增序号、来源、风险等级或建议等列。表格放在重点事件完整正文之后，与正文使用同一共享资讯和已核验事件，不另行检索或构造新的事实。

| 字段 | 填写口径 |
| --- | --- |
| 时间 | 优先使用该行本期关键事实或最新实质进展的发生日期；仅能核实披露日时注明“披露”。保留已核验日期精度和年份，不能将转载日或旧事项原始日期冒充本期新增日期。历史事项本期有更新时，以本期进展日期呈现并在简况中保留必要背景。 |
| 事件主体 | 填写实际发生事件的已核验主体名称。涉及子公司、股东等关联方时明确真实主体及必要关系，不将其处罚、冻结或债务改写为目标企业自身事项。 |
| 事件简况 | 简洁概括本期事实、当前阶段及必要进展，保留重要正面进展、澄清、解除和已落实缓释；计划、获批和未决事项不写成已完成事实。沿用正文判断，不在表内扩展未经分析的新事件或推测。该单元格紧随实际支持的原始引用，HTML在相应位置展示可交互“来源”标识。 |
| 事件类型 | 根据原文使用简洁、规范的事件类型，如监管处罚、经营事项、债务融资等；同义表述归一，与本报告词云及趋势图中同一事件的类型含义一致，不用情感方向或来源分类代替事件类型。 |
| 舆情方向 | 按该行实际主体、本期事实及截至时点的状态判断，填写“正面”“负面”或“中性”；无法判定时保留“待判定”，不强行归类。不能仅凭事件类型或标题定方向，也不能把关联主体的方向直接计为目标企业自身情感。 |

同一事项的原文片段、转载及多个阶段归并为一行，简况集中说明截至时点的本期进展；独立事项分别列行，不能为增加条数拆分同一事项。仅汇总本章已核验并分析的重要事件，不要求事件数等于趋势图资讯篇数；保留有据正面、负面及重要中性事项，不固定行数。按表中本期关键事实或进展时间由近及远排列，同日按重要性排序，日期未明确的事项后置并如实标注。

对话直接输出实际填妥的Markdown表格，表头固定为：

```markdown
| 时间 | 事件主体 | 事件简况 | 事件类型 | 舆情方向 |
| --- | --- | --- | --- | --- |
```

表格作为独立组件保存，与本章分析正文分别留档，不要求模型另抄全文JSON。HTML将同一份表头、行序、单元格文字及引用转换为原生`<table>`，配合`<thead>`、`<tbody>`、`<th>`、`<td>`；单元格内容按HTML上下文转义，保持文字可读及必要换行，不以省略号隐藏关键事实。无需调用平台生图或新增绘表代码，不用截图、图片或“见附件”替代表格。逐行来源沿用真实原始引用和URL，并按报告来源规范提供悬浮、点击、键盘及触摸查看。无有效事件时略去表格，不输出空表或虚构示例行；表格随同图形按实际出现顺序连续编号。

## 关联主体表格

表名为“关联主体”，放在关联主体完整正文之后，固定以下五列及顺序，不另加时间、事件类型、来源、风险等级或建议等列。只汇总本章已核验并分析的关联主体、本期事项及有据影响，使用同一共享资讯，不另行检索或补全集团全图。

| 字段 | 填写口径 |
| --- | --- |
| 关联主体 | 填写实际发生事项的关联主体名称，明确其与目标企业是不同主体，不以简称相似、同地域或同一行业推定关联。 |
| 关联关系 | 填写资讯证实且在相关时点适用的关系，如控股股东、实际控制人、核心子公司、参股企业、担保或资金往来对象、重要客户或供应商等。历史关系须核验适用时间，不能将兄弟主体写成母公司或把参股写成控股。该单元格保留支持关系的原始引用。 |
| 事件简况 | 简洁概括该关联主体本期重要事项、当前阶段与最新进展，必要日期写在此单元格；区分旧事项本期更新与旧闻转载，保留重要正面进展及真实缓释，计划、获批和未决事项不写成已完成。事实后保留实际支持的原始引用。 |
| 影响 | 说明该事项通过已证实的控制权、担保、资金往来、业务依赖、经营或声誉联系对目标企业产生的影响或支持。已发生影响须有事实依据，潜在影响须说明成立条件与必要缓释；本次材料不能确认直接影响时如实保留判断边界，不编造损失、代偿义务或风险等级，不把关联方股份冻结写成目标企业资金冻结。 |
| 舆情方向 | 针对本行关联主体的事实和截至状态判断“正面”“负面”或“中性”，无法判断时保留“待判定”。方向不等于目标企业风险等级，也不替代“影响”列对传导的判断，不直接并入目标企业自身情感统计。 |

同一关联主体的同一事项及阶段进展归并为一行；同一主体有多个独立重要事项时可分别列行，不为增加行数重复转载或拆分程序。按对目标企业的重要性排列，同等重要时按本期进展时间由近及远；不固定主体数或行数。与重点事件表重复涉及同一事项时沿用原事实、实际主体和截至状态，本表侧重关系与传导，不由重复出现增加事件数或累计损失。没有已核验关系或有效事项时略去相应行，无有效行时略去表格，不填虚构或示例主体。

对话直接输出实际填妥的Markdown表格，表头固定为：

```markdown
| 关联主体 | 关联关系 | 事件简况 | 影响 | 舆情方向 |
| --- | --- | --- | --- | --- |
```

表格作为独立组件保存，与本章分析正文分别留档。呈现与重点事件表采用相同的Markdown转原生HTML表格、上下文转义、可读换行、逐行引用及交互来源规则；关系、事件和影响依据不同时分别绑定真实来源，不另加来源列。对话与HTML使用同一表头、行序、单元格内容和来源，无需平台生图或新增绘表代码，不用图片或“见附件”替代表格，按固定清单内组件的实际出现顺序连续编号。

## 词云口径

词云展示目标企业本期已核验事件的**事件类型标签**，不是从新闻正文自动分词得到的高频词。模型阅读共享资讯后完成事件归并和标签规范化，程序只做引用、主体、日期及格式校验、计数与绘制，不替代事实核验。

- 只纳入目标企业自身有直接事实依据、存在监测期内公开且不晚于截至时点的原始资讯支持的已核验事件。关联主体单独发生的事项、无日期材料、期间外背景、无法拆分的聚合回答及无真实原文URL的材料不进入词云。
- 同一事项的多个新闻片段、转载和持续更新使用同一`event_id`。同义标签先规范为一个事件类型；同一事件的同一标签只计一次。多个独立事件归属相同类型时，该标签按独立事件项数累计。
- 标签可以是正面、中性或负面类型，以真实事件为准。例如“股票停牌”“立案调查”“业绩亏损”“产能不足”只是类型示例，不是默认词库；不能为匹配参考图片而填入本期未发生的事项，也不能把推测性后果写成已经发生的标签。
- 字号仅表示本次纳入的独立事件频次。配色为排版配色，不表示情感、严重程度或企业风险等级。不以新闻篇数、转载数、检索次数或来源权威度替代事件频次，不从重点样本外推全量舆情。
- 历史事项本期有真实进展时，仍归并到同一事项，只使用本期证据支持的类型；旧闻转载不能制造新增事件。

图注说明监测期间、目标企业、统计单位“去重事件项”和样本边界，注明“字号表示本次纳入的独立事件频次，颜色仅用于区分标签”。词云不增加正文之外的事实。

## 标签交接

使用最终入选、完成来源核验的共享标准资讯包。共享分析任务另外输出以下最小标签文件，原文、URL、标题和引用仍由程序从标准包读取，不要求模型抄写：

```json
{
  "events": [
    {
      "event_id": "语义归并后的稳定事项标识",
      "subject": "已确认企业全称",
      "labels": ["由原文直接支持的规范事件类型"],
      "source_ids": ["共享标准包中已有的材料ID"],
      "verified": true
    }
  ]
}
```

`event_id`由实际阅读和事项归并确定，同一事项不得因新闻标题、报道次数或更新而更换标识；它不要求与可选`news_package.events`的键逐一对应。`source_ids`必须指向同一包已入选材料，不能填引用标记、URL或自造ID。`verified=true`只来自实际核验，不由程序自动赋真；归并是否正确、原文是否支持标签仍由模型负责。

准备器在每条原始材料前提供材料ID，仅用于此文件的来源绑定，不把它当作报告引用。标签文件、ID和绘图审计都是内部资源，不写入报告。

## 词云内置绘制

平台当前不能生成词云，使用`scripts/render_wordcloud.py`实际生成交互SVG、独立HTML预览及同版PNG。该词云使用内置代码绘制，不请求平台图形组件或图像生成模型。只需安装词云脚本依赖；原有资讯处理脚本仍使用Python标准库。

```text
<可用Python> -m pip install -r "<skill目录>/scripts/requirements-wordcloud.txt"

<可用Python> -X utf8 "<skill目录>/scripts/render_wordcloud.py" --news-package "<工作目录>/news_package.json" --labels "<工作目录>/wordcloud_labels.json" --out "<工作目录>/wordcloud" --style "<skill目录>/assets/wordcloud-style.json"

# 自动发现不到可用中文字体时，增加 --font "<可用中文字体文件>"
```

使用Python 3.10及以上和Pillow，依赖清单为`scripts/requirements-wordcloud.txt`。选择当前运行平台实际可用且覆盖全部标签文字的中文字体，不把某台电脑的固定字体路径写进技能，也不打包未经许可的字体。样式统一维护在`assets/wordcloud-style.json`：白色背景、横向布局、全部横排、分散彩色中文标签，字体大小随事件频次变化，接近用户提供的参考样式。

## 展示、来源与冻结

溯源角标：正文引用标记渲染为右上角数字角标「[n]」，按全文出现顺序编号，同一句多个来源合并为一个角标，卡片逐条列示标题、时间、来源与原文链接（头部标「溯源N条」）；事件库条目无URL时如实标注。

固定清单中的组件按 V20 展示顺序放置：1.1 舆情总结先展示词云与周度声量图、后放文字；1.2 事件总结与 1.3 关联主体动态**先表格，表格即全部内容（不重复放文字总结）**；2.1 风险发酵链路**先链路图、再五列表格（不重复放文字总结）**；3.x 章首放预警分布图。图形后放必要图注（**图注不写“来源：××”文字**，归属只经溯源角标承载），表格逐行保留来源角标。清单内图表统一按最终实际出现顺序命名为“图表N 组件名称”，图形与表格跨章连续编号，空组件不占号；五者齐全时依次为“图表1 舆情词云”“图表2 舆情数量趋势统计”“图表3 重点事件”“图表4 关联主体”“图表5 风险发酵链路”。缺少组件时按实际顺序重编，三表不固定占用编号3、4、5。词云和趋势图不能以标签JSON、图像需求、代码、数据表或“见附件”代替成图；重点事件和关联主体展示实际五列表格。

报告HTML直接内联同次清单的`interactive.svg`，保留其样式及每个词的独立交互元素；不能改成`<img src="…svg">`、SVG data URI图片或PNG后宣称仍有逐词悬浮效果。SVG、CSS及来源内容均保存在HTML内，不链接本地文件、不依赖临时外链。保留文字的默认布局和配色，不在HTML转换阶段重新计算标签、计数或排版。

对话支持内联SVG及其CSS时展示同一交互SVG；不支持时展示同次PNG并简洁注明“静态预览，悬浮效果见HTML附件”。PNG只能静态展示，不能声称其支持逐词放大。两种呈现使用相同标签、频次、默认位置、配色、图注、来源与编号；交互仅改变当前词的视觉强调，不改变分析结果。SVG、PNG、词云独立预览HTML和清单均为内部资源，最终只交付完整报告HTML附件。

词云图注后的紧凑“来源”标识从词云清单内有效来源绑定生成，使用原生HTML`details/summary`等可独立工作的交互元素，支持点击、悬浮、键盘聚焦和触摸查看标题、发布时间、机构及真实可点击原文URL。插入标题、机构、时间及链接时按HTML上下文转义，不能拼入未转义原文。词云内文字、内部ID或单独来源清单不能代替HTML的交互来源标识。多个支持来源分别保留；组合图的来源使用其统计记录绑定，呈现同样可交互的来源标识，不从词云清单替取。

冻结前核实原始URL。移除失效来源或事实时，先同步修正共享包、事件标签与前三章正文、样本统计，再汇总修正后的最终正文并更新受影响组件，最后冻结图形、表格、图注、编号和来源。HTML只转换同一份已冻结内容，不能单独增删标签、修改趋势数据或改变表格行。实际打开完整报告HTML，逐词验证词云悬浮放大加粗、移开恢复、键盘聚焦及来源查看，核对PNG与SVG的标签、计数和基础布局一致；核对组合图总量柱、分类折线、时间桶、单位、缺口及来源与正文和统计数据一致；分别核对两表各自固定五列表头、行序、单元格内容及逐行来源，确认关联关系与影响传导边界清楚，下载后所有组件可独立显示。交付核验见[报告输出](report-output.md)。
