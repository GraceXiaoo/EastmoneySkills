# 报告结构与格式规范

本文件固化最终报告的章节结构、预警分级、写作规范与静态图表规范。报告由五任务链路（shared-analysis → risk-fermentation → key-concerns）产出正文后，按本结构重组为四章业务报告交付；各章正文分析规则仍在对应执行提示词维护，本文件只管展示结构、分级口径、语言规范与图表格式。

## 对话交付（V20）

对话回复**只交付目录框架＋核心概要**，不返回整篇报告正文、不返回表格全文、不内嵌图表：

1. 标题＋一行「监测期间：起至止」；**报告标题强制单行**（HTML/Word 按内容宽度自适应调小字号，禁止换行）；
2. 「报告目录」：四章及子节清单（无内容子节略去）；
3. 「核心概要」：5—8 条编号要点（每条≤40字），覆盖本期主线、最重事件、预警档数（如 红0/黄3/蓝2/不设预警1）、关键未来节点与主要待验事项；
4. 免责声明 →「**附件：**」→ HTML 附件卡片（+Word 卡片）。

完整图文（正文、表格、图表、溯源）全部在 HTML/Word 附件中呈现，对话不展开。

## 报告结构

标题为「企业全称预警监测报告」，标题下方仅一行「监测期间：起至止」（**不写「（含两端）」、不列数据截至与样本口径等附加行**；口径说明以一短句并入 1.1 舆情总结文本末尾）。章节固定四章，阅读动线为「本期发生了什么 → 会怎么发展 → 哪些要盯 → 该做什么」：

| 章 | 标题 | 子章节 | 展示顺序 | 内容来源 |
| --- | --- | --- | --- | --- |
| 一 | 监测信息总结 | 1.1 舆情总结｜1.2 事件总结｜1.3 关联主体动态 | 1.1 先图后文（图上文下）；1.2/1.3 **先表格，表格即全部文字内容，不放重复文字总结** | 舆情概览＋重点事件＋关联主体三章正文重组；声量图覆盖近3个月周度（默认监测期） |
| 二 | 风险走势研判 | 2.1 风险发酵链路｜2.2 风险传导｜2.3 未来风险预测 | 2.1 **先链路图、再五列表格，表格即全部内容，不放重复文字总结** | 风险发酵链路章正文拆分 |
| 三 | 分级预警清单 | 3.1 红色预警｜3.2 黄色预警｜3.3 蓝色观察｜3.4 待验证事项 | 3.x 章首放预警分布图，其后分级条目 | 发酵判断＋预警分级重组 |
| 四 | 短期内关注 | 不设子章节 | —— | 重点关注正文重组为观察清单（时间节点＋对象＋关注要点＋基线） |

无有效内容的子章节略去且不占编号；空章从章级整体略去。首期监测在首句注明「首期监测，暂无上期对比」；非首期在 1.2 增加上期流转对比（新增、升级、降级、解除及原因）。

## 预警分级

研判对象（含已发生事件、已存在风险、未来事件节点、关联主体事项）按三档分级，分册写入第三章：

| 等级 | 含义 | 判定条件 | 报告处理 |
| --- | --- | --- | --- |
| 红色 | 必须立即处置 | 风险正在发生（会发酵）且证据链闭合，或7天内存在高确定性重大节点 | 3.1 逐条列示：事项说明、触发依据、建议动作、解除条件 |
| 黄色 | 有风险预期但证据不足 | 存在负面预期但传导链有断点（待观察），影响可控 | 3.2 同上四列 |
| 蓝色 | 持续观察，暂不构成预警 | 方向积极但存续信息缺失，或已部分释放的风险因子 | 3.3 简表：观察项＋情况 |
| 不设预警 | 利好或已解除 | 正面进展、已完成事项 | 不进第三章；仅在 1.2 事件总结以正面性质标注 |

分级依据为发酵链路的判断结果（会发酵→红色；待观察→黄色；不会发酵→利好或不设预警；证据缺失的历史观察项→蓝色），不由数据源风险标注、报道量或金额直接决定。每条预警必须写明**解除条件**或**升级条件**，非首期还需标注状态流转。

## 写作规范（V19：要点化、防密度堆积）

- **术语即界定**：专业术语首次出现时括注定义，后文直接用缩写；使用金融风控通用术语，禁止自造缩略语与口语化表述。
- **语言基调**：除「风险先结论后机制」（结论句加粗）外，所有文字一律收缩为**短句要点**——先一句总述（≤40字），再编号要点，每点 1—2 句、≤60字；禁止长段落堆积。各章字数上限：1.1 文字≤260字（总述＋3—4点）、1.2 文字≤300字（总述＋3—5点）、1.3 文字≤260字（总述＋2—4点）、2.1 文字≤400字（总述＋3—5点）、第四章每点≤60字。
- **渠道名禁入（V19）**：正文、图注、表格、meta 一律**不得出现检索渠道/数据源名称**——如「事件库」「未来事件库」「资讯」「MQL」「检索」等渠道性来源说明；事件条目的预计时间写作「预计2026下半年（以披露为准）」即可，归属只通过右上角溯源角标承载；图注不写「来源：××」文字。
- **预警表述含四要素**：事项说明一句话讲清风险是什么、怎么传导；触发依据给数据；建议动作可执行；解除条件可观察。
- 子章节标题不带括号解释；表格单元格内时间与性质标签不换行（nowrap）。
- **SVG缩放陷阱（V16）**：所有图表 viewBox 宽度应接近渲染容器宽——声量/链路/时间轴 960-1200，分布图 980；HTML 展示时分布图容器上限 640px，与 Word 显示宽 620px 一致，保证两格式图内文字比例相同。
- **字号与行距（V19）**：HTML 正文 **15px**、**行高 1.5**（正文、表格、图注统一 1.5）；Word 正文 **11.5pt（23 半点）**、行距 1.5；图注/索引 HTML 13px/Word 9.5pt；分布图（V19）图内标题/图例/数量字号上调至与正文一致（≥22px 档），杜绝 Word 中"字体过小"。
- **关联主体编号**：1.3 文字各主体用有序列表编号。
- **图表前置**：1.1 词云与声量图紧随小节标题之后，先图后文；1.2/1.3 表格先于一切文字；2.1 链路图先于链路表。
- **去重文字总结（V20）**：1.2、1.3、2.1 的表格（链路表/重点事件表/关联主体表）已完整承载事件信息，**表格下方不再重复输出文字总结**；确有表格承载不了的内容（如上期流转对比、口径说明）并入表格 note 行，不另起文字段。1.1 为图表+文字要点的组合（1.1 无表格），保持不变；2.2/2.3/3.x/第四章照常要点化。
- **标题单行（V20）**：报告标题在 HTML 与 Word 中只占一行，不换行；页面放不下时由构建器按标题字宽自动缩小字号（HTML：`title_font_size()`，Word：`TITLE_SIZE`），不再手动指定字号。
- **字体统一（V20）**：标题（报告标题/章节标题）、正文（段落/表格/图注）、图表内文字（图表标题/图例/轴/图内正文）三档各自统一字号；所有静态图表以**显示宽度 630px 为基准**（HTML 容器上限640px、Word 显示宽620px，两渠道误差<4%）反推 SVG 字号，杜绝“HTML 很大、Word 很小”的缩放漂移。
- **备注唯一（V20）**：图表统计口径等备注一律只写在图下说明（figcaption/Word 图注）中，SVG 内不再绘制备注行；词云图说明与声量图之间保留 ≥26px 间距（figure margin 26/18、figcaption margin-top 10），防止图表与说明粘连。
- **溯源间距（V20）**：HTML「溯源索引」与正文最后一段保持 3 行间距（`.srcidx{margin-top:68px}`）；Word 在溯源标题前已有 3 个空行。

## 静态图表规范

报告全部图表为**纯静态 SVG 内联**，禁止依赖 JavaScript 运行时渲染。固定图表清单：

| 图表 | 所属位置 | 生成方式 |
| --- | --- | --- |
| 舆情词云 | 1.1 舆情总结 | `render_wordcloud.py`（词频为去重事件数） |
| 周度舆情声量 | 1.1 舆情总结 | `render_static_charts.py volume`（细柱＋折线，图例置于图表顶部，近3个月周度≤14桶） |
| 预警分布图 | 三、分级预警清单章首 | `render_static_charts.py distribution`（环形图；**V19：图内标题/图例/数量字号与正文一致**，HTML 容器上限640px、Word 显示宽620px） |
| 风险发酵链路图 | 2.1 风险发酵链路 | `render_static_charts.py chain`（分区链路图；**V19：去掉图片右上角说明框；底框高度按内容行数自适应，任何节点/观察框不越界**） |
| 未来事件时间轴 | 2.3 未来风险预测 | `render_static_charts.py timeline`（7/30/90天窗口，确定性着色） |

图表细节规范（V20，字号按 630px 显示基准反推，括号内为显示效果）：
- **声量图**（viewBox 960×360，基准比 0.66）：图例置于绘图区上方水平居中、**项间距 26 单位（≈17px）防重叠**；标题 20（≈13px）、图例 17（≈11px）、轴/数值 16（≈10.5px）；横轴日期 45°斜排；支持最多14个周桶；**统计口径备注只写在图下说明，SVG 内不再绘制备注**。
- **分布图**（viewBox 980×612，基准比 0.64）：**标题居中**（text-anchor=middle @x=490）；标题26/图例与数量24/含义注16（显示≈17px/15px，与正文一致）；环形半径92/环宽42、path 弧线绘制；HTML 容器上限640px、Word 显示宽620px。
- **链路图**（viewBox 1200×自适应高，HTML 非限宽占满正文宽≈895px，Word 620px 嵌入）：无右上角说明框；面板标题26/列头24/正文22/小字21（HTML 全宽显示≈19/18/16px）；三列内容X=46/408/776，**面板背景贴边 14..1184（左右留白≈1.2%）**、列间留 30/40px 空隙画箭头；第二行基线由第一行面板底自适应（+28），行距 ≥ 同列框高+40（防上下框重叠）；**所有框内文本按列宽自动换行（_wrap，CJK≈1字/ASCII≈0.62字），面板与各框高度随换行行数自适应**；底部说明置于同宽背景条内（不悬空）；测试断言 text 不越框、box 不重叠、box 底≤H。
- **时间轴**（viewBox 1200×自适应高，基准比 0.53）：窗口刻度/事件标题27（≈14px）、说明23（≈12px）、图例23；事件盒 320×66、上下分层步长≥64；图例横向置顶、窗口刻度-60°竖排、底部说明预留自适应高度；事件溢出时自动上下均衡。
- 所有图表右缘距 viewBox 右界 ≥30px；图注说明统计口径与边界（如声量图注明「统计范围为本次纳入的去重资讯，不代表全网声量」），图注不带“来源”文字。

## 溯源样式

正文引用标记渲染为**右上角数字角标「[1][2]…」**，按全文出现顺序连续编号，紧跟被支持的事实句之后；同一句的多个来源合并为一个数字角标，卡片内逐条列示（标题、时间、机构、原文链接），卡片头部标「溯源 N 条」。

**实现硬约束（V11）**：角标用**纯短语内容元素**实现——`<sup class="src"><input type="checkbox" id="srcN"><label for="srcN" class="src-btn">[N]</label><span class="src-card">…</span></sup>`，卡片内只用 span/br/a/b；**严禁在正文中使用 `<details>`**。角标按钮字号 9.5px、line-height:1；卡片 12px、绝对定位悬浮、checkbox 勾选显示（纯 CSS 无 JS）。事件库条目无 URL 时卡片如实标注「该条无原文链接」，但机构字段与正文一律不出现「事件库」字样（用实际发布机构或「公开信息」）。

**HTML 结构验收**：交付前用 html.parser 校验全文标签配对零错误、`<p>` 开闭数相等、无 details 残留。

## 交付边界

报告以免责声明「内容由 AI 生成，仅供研究参考，不构成投资建议。」收尾，不追加「附件：」占位行或制作过程说明。对话仅交付「目录框架＋核心概要」（见上），HTML 与 Word 同源交付：同一份冻结文字、图表数据与来源。各章写作字数、段落形式按对应执行提示词执行；本结构与各章分析提示词冲突时，分析规则以提示词为准、展示结构以本文件为准。
