# 分析架构与维度（按需加载）

> 本文件在组织分析与撰写正文时加载，包含：一页纸结构、A-J 分析维度、品种差异化指令、段落组织逻辑、结构化 JSON 中间结果、写作纪律。

## 一、报告结构（自包含 HTML 一页纸）

按以下顺序组织，构成一份完整的期货合约一页纸（各段按数据可得性增删）：

1. **标题区**：`{合约简称}（{期货代码}）期货一页纸` + 生成时间（精确到秒）+ 一行免责提示
2. **结论摘要**：3-5 条要点，只陈述事实性结论与结构判断（盘面强弱、期限结构方向、基差位置、库存与资金边际变化、技术与关键位、核心矛盾）
3. **合约概况表**：`| 期货代码 | 合约简称 | 所属品种 | 最新价 | 结算价 | 涨跌 | 涨跌幅 | 成交量 | 持仓量 | 成交额 | 合约乘数 |`，并注明数据日期；若入参合约为该品种主力合约（同品种持仓量最大），在表下以一行文字标注「本合约为该品种主力合约」，并给出**交割月提示**（距交割月剩余自然月数），不写操作指令
4. **盘面与量仓（含价格走势图）**：近 N 日收盘/结算走势 + 成交量/持仓量双轴图
5. **期限结构（含曲线图）**：同品种各月份合约价格曲线 + 近远月价差/展期方向
6. **基差与现货（含图/表）**：现货价、基差、基差率及其位置判读
7. **库存与仓单（含图/表）**：注册仓单量及增减、库存周期判断
8. **会员持仓与资金（含图/表）**：前 10~20 家会员多空与净持仓、增减仓与资金倾向
9. **供需基本面（含图/表）**：产量、开工率、进出口、库存、下游需求等产业指标及边际变化（数据取自宏观/行业指标工具，口径见 `mql-spec.md`）
10. **宏观与资金环境**：与本品种相关的宏观指标（如美元指数、汇率、利率、PMI、CPI/PPI 等）及其对价格的传导
11. **外盘与跨市场联动（含图/表）**：境外同品种期货或相关外盘价格、内外价差（有可得数据时展开，无则省略）
12. **技术面（含图/表）**：均线系统（MA5/MA10/MA20/MA60）、MACD（DIF/DEA/柱）、支撑与压力位、形态判读（由价格序列计算，口径见 `mql-spec.md`）
13. **品种逻辑、走势判断与情景推演**：核心驱动、趋势与震荡的定性判断、条件化情景（若……则……）、关键价位/阈值、事件与数据日历
14. **风险提示**：编号列示（3-6 条），覆盖方向性风险、结构反转、政策/供给扰动、流动性与交割等风险
15. **跟踪清单**：表格化呈现关键指标、当前值、阈值、关注方向
16. **参考资料**：编号列出正文引用的新闻/研报/公告（`[1]`、`[2]`……），标注来源类型与材料日期
17. **免责声明**

> 中金所品种（`.CFE`）无仓单，省略第 7 段；无映射现货的品种省略第 6 段；某品种无会员持仓数据时省略第 8 段；无外盘对应品种省略第 11 段。**数据缺失即整体省略对应小节，不写缺口说明。**
> 「走势判断与情景推演」只做**条件化的情形推演与关键价位提示**，不得给出建仓、目标价、止损、仓位、对冲比例等操作指令（详见第六节写作纪律）。

## 二、分析维度（A-J）

每个分析段落从下列维度中选取与当日数据最相关的展开，**段落标题须根据本段实际分析内容二次总结凝练，严禁直接照搬维度名作为标题**。

### 维度 A：盘面表现与量仓结构
- 收盘/结算、日内高低、涨跌与涨跌幅、振幅
- 成交量、持仓量的绝对水平与边际变化；**量仓配合**判断（增仓上涨/增仓下跌/减仓上涨/减仓下跌）
- 成交额与合约乘数（反映合约活跃度与资金体量）
- 当前价格在近 N 日区间中的位置（分位）

### 维度 B：期限结构（月差与展期）
- 同品种各月份合约价格曲线形态：**contango（近低远高/正向）** 或 **back（近高远低/反向）**
- 近月与主力、主力与远月的价差方向与幅度；展期收益（roll yield）方向
- 结构隐含的供需预期（近端紧张/宽松）与库存周期呼应

### 维度 C：基差与现货（期现关系）
- 现货价、基差、基差率；现货升水（back结构常伴）或贴水（contango结构常伴）
- 基差所处的历史位置（偏强/偏弱），期现回归方向
- 现货指标口径（元/吨、元/千克等）须注明

### 维度 D：库存与仓单
- 注册仓单数量及周度/月度增减（去库/累库）
- 仓单变动与价格、基差、月差的相互印证
- 库存周期位置（主动去库/被动累库等）

### 维度 E：会员持仓与资金
- 前 10~20 家会员多头、空头持仓；净持仓（净多−净空）
- 多头持仓增减、空头持仓增减；**资金倾向**（多头增仓/空头增仓/双向减仓）
- 头部会员集中度与边际变化；与价格、量仓方向是否共振

### 维度 F：供需基本面（产业驱动）
- 供给端：产量、开工率、开工负荷、进出口、进口利润、国储/抛储
- 需求端：下游开工率、订单、库存天数、替代品与终端消费
- 库存端：厂库/社会库存/港口库存的绝对水平与环比变化
- 数据口径以产业指标为准，注明频率（周/月）与口径

### 维度 G：宏观与资金环境
- 与本品种敏感度高的宏观变量：美元指数、人民币汇率、利率、PMI、CPI/PPI、社融等
- 宏观变量向价格的传导路径（成本、汇率、需求预期），只做逻辑关联不做绝对因果
- 资金面：股指期货关注分红与对冲成本，国债期货关注资金利率与曲线形态

### 维度 H：外盘与跨市场联动
- 境外同品种期货或高度相关外盘（如 CBOT 大豆、LME 铜、COMEX 金银、NYMEX 原油、BMD 棕榈油）
- 内外盘价差、比价及其近期方向；外盘对内盘的开盘/情绪传导
- 无对应外盘或数据不可得时，整体省略本维度

### 维度 I：技术面（价格结构与关键位）
- 均线系统：MA5/MA10/MA20/MA60 的多空排列与价格相对位置（由近 N 日收盘序列计算）
- 动能：MACD（DIF、DEA、柱状值）的金叉/死叉与背离迹象（由收盘序列计算）
- 关键价位：由近期高低点、均线与成交密集区推导的支撑/压力位
- 形态与位置：区间震荡/单边、突破/假突破、超买超卖的位置描述（不预测点位）

### 维度 J：品种逻辑、走势判断与跟踪清单
- 结构判断（趋势/震荡；期限结构与基差指向）与**条件化情景推演**（若关键位失守则……；若库存延续去化则……）
- 关键价位与阈值（支撑/阻力、基差率阈值、仓单/持仓阈值）
- 事件与数据日历（交割月、库存数据、宏观数据、政策窗口）
- 风险提示（编号列示）与跟踪清单（指标/当前值/阈值/关注方向）
- **仅做情形推演与关键位提示，不给建仓、目标价、止损、仓位、对冲比例等操作指令**

## 三、品种差异化指令

根据合约所属板块，分析侧重相应调整（板块由品种代码判读）：

| 板块 | 代表品种 | 分析侧重 | 主要外盘/宏观参照 |
|------|---------|---------|------------------|
| 贵金属 | AU 沪金 / AG 沪银 | 实际利率、美元指数、避险与地缘、金银比 | COMEX 金/银、LBMA、美元指数、美债实际利率 |
| 有色金属 | CU 铜 / AL 铝 / ZN 锌 / NI 镍 / SN 锡 | 供需与冶炼利润、库存与仓单、进口盈亏、下游开工 | LME 铜铝锌镍、美元指数、内外比价 |
| 黑色系 | RB 螺纹 / I 铁矿 / HC 热卷 / JM 焦煤 / J 焦炭 | 地产基建需求、钢厂利润与铁水产量、原料与成材比价、限产政策 | 普氏铁矿、地产/基建数据、PMI |
| 能源化工 | SC 原油 / TA PTA / MA 甲醇 / PP 聚丙烯 / V PVC | 原油成本传导、开工率与装置检修、季节性、地缘溢价 | NYMEX/Brent 原油、美元指数、装置检修 |
| 农产品 | M 豆粕 / Y 豆油 / C 玉米 / SR 白糖 / CF 棉花 / AP 苹果 | 天气与种植、进出口与关税、养殖需求、季节性、猪周期 | CBOT 大豆/豆粕/豆油、ICE 白糖/棉花、汇率 |
| 股指期货 | IF 沪深300 / IC 中证500 / IM 中证1000 / IH 上证50 | 基差与贴水、分红影响、对冲成本、量化中性、期现套利 | 现货指数、市场情绪与资金面 |
| 国债期货 | T 10年 / TF 5年 / TS 2年 / TL 30年 | CTD 与 IRR、净基差、资金面与政策利率、曲线形态 | 资金利率、政策利率、CPI/PPI、社融 |

差异化要点：
- **股指期货**：以「基差/贴水 → 对冲成本 → 市场情绪与中性策略容量」为主线，用基差率指标而非现货链；技术面主要参考现货指数而非内外盘。
- **国债期货**：以「CTD 券 → 基差/IRR → 资金面」为主线，宏观维度侧重资金利率与政策预期。
- **商品期货**：即使同一品种，近月合约侧重现货/库存/仓单与交割，远月合约侧重预期与月差；有对应外盘的品种应纳入外盘联动维度。
- **外盘联动**：仅对有明确境外对应品种的品种展开；内外价差/比价方向须与结构化数据一致，不得臆造外盘点位。

## 四、段落组织逻辑

- **摘要段**：覆盖核心驱动、最关键矛盾、结构判断、技术关键位；不插入图表。
- **分析段（5-8 段）**：每段由「段落标题（二次总结凝练）+ 图表/表格（若该维度有数据）+ 正文」构成，段落正文重点用 `<strong>` 加粗（同段≤3 处）。全文正文（不含图表与图注）建议 **900-1800 字**。
- **走势判断与情景推演段**：以条件化句式展开 2-3 个情景（如「若……则……」），仅做方向与关键位描述，不给操作指令。
- **风险提示段**：编号列示 3-6 条，每条一句话，可被正文引用编号。
- **跟踪清单段**：表格化呈现关键指标、当前值、阈值、信号。
- **参考资料段**：编号列表，正文用 `[n]` 上标引用，与列表一一对应；标注来源类型与材料日期。
- **免责声明段**：免责说明，数据来源统一表述为「数据来源：Choice数据」。

> 每段图表须贴合正文且「好看」，**每张图表下方须紧跟一行数据来源标注「数据来源：Choice数据」**；若该段核心数据缺失，则该段不插图，直接以正文分析或省略该段。

## 六、写作纪律

- 定量为先：每个判断尽量绑定一个具体数值或结构证据；无数据支撑的判断用「依据不足」表述或省略
- 观点稳定、克制：不因单日涨跌或单日增减仓直接定性趋势反转；技术指标只作辅助印证，不单独作为定性依据
- 使用概率化、条件化措辞；区分「事实 / 数据 / 观点 / 推断」
- 不制造不存在的结论；不把模板示例数值当作当前数据
- 引用新闻/研报观点时标注材料日期与来源类型（新闻/研报/公告），并区分事实与观点；正文引用须以 `[n]` 上标与参考资料列表对应
- 技术指标（MA/MACD/支撑压力）须由取到的价格序列**如实计算**，不得臆造数值；计算口径在报告中简要注明
- **不输出操作指令**：不得给出建仓/加仓/减仓、目标价、止损价、仓位比例、对冲比例等具体交易指令；走势判断只以「可能」「若……则」「需关注」等条件化、概率化语言描述情形与关键位
- 风险提示须独立成段并编号，覆盖方向性、结构、政策/供给、流动性与交割等维度，至少 3 条
