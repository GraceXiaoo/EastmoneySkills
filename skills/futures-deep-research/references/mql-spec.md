# MQL 取数规范（按需加载）

> 本文件在执行 MQL 取数步骤时加载，包含：已验证报表/指标路径、字段映射表、MQL 语法约束、合约存在性校验与六类取数模板、容错降级规则。
> 所有路径与字段均基于实测验证，**禁止臆造或自行修改**。首次使用时仍建议通过 `Search_Context` 复核关键报表路径未变。

## 一、取数总原则

- **第 0 步（硬门槛）：合约存在性校验**。解析出合约代码后，必须先执行「模板 0：合约存在性校验」。若该代码在全合约清单中查无数据，判定为**无效代码**，**立即中断任务并告知用户**，不再进行任何后续取数。详见第四节模板 0 与第五节规则 8。
- 取数锚点是**期货合约代码**（入参）。品种代码、交易所、合约乘数、合约名称等一律由合约取数结果反查，不凭经验臆造。
- 所有 MQL 统一经 `mcp-mql-runtime` 的 `Execute_MQL` 执行；参考信息经 `mcp-mql-tools` 的 `Get_MQL_Reference` / `Search_Context` 获取。
- **每次 `Execute_MQL` 调用中，Block 编号必须从 `#1` 开始连续递增**，不能跨调用延续。分批取数时每次调用都从 `#1` 重新编号。
- 能一次 `Execute_MQL` 完成的多个 Block 应尽量合并提交，减少往返。

### 2.6 宏观与产业指标（供需基本面 / 宏观资金 / 外盘）

宏观、行业与大宗商品指标**不走 MQL**，统一经 `mcp_mx-ds-mcp` 的 `mx_macro_data` 工具查询（仅一个 `query` 字符串入参，用自然语言描述指标名称、品种/行业、地区、时间范围、频率与口径）。该工具覆盖 GDP、CPI、PPI、M2、社融、利率、进出口、工业增加值，以及能源、金属、化工、农产品、新能源等行业的产量/销量/进出口/库存/开工率/价格等量价数据。

> ⚠️ **MQL 的 `EdbBlock` 在当前运行时不受支持**（报「Block 必须使用 CrossSectionBlock、TimeSeriesBlock、GroupBlock、ReportBlock 或 MergeBlock」）。宏观/产业数据**一律改用 `mx_macro_data`**，不要尝试 `EdbBlock`。

**调用方式（query 示例，按品种替换）**：

| 用途 | query 示例 |
|------|-----------|
| 宏观资金 | `美元指数 近一年 走势`、`人民币汇率 中间价 近一年`、`制造业PMI 最新`、`CPI 同比 近一年` |
| 供需基本面 | `{品种名} 产量 近一年`、`{品种名} 进口量 近一年`、`{品种名} 港口库存 周度`、`{品种名} 开工率 最新` |
| 外盘/相关价 | `CBOT大豆 期货 价格`、`LME铜 价格`、`NYMEX原油 价格` |

- 返回结果为结构化数值序列或最新值；**只采用与查询口径一致的数据**，口径不明或与品种不符时不用。
- 外盘品种名须与内盘有明确对应关系时才展开「外盘与跨市场联动」；`mx_macro_data` 与综合查询均取不到时整体省略该维度，不臆造外盘点位。
- 引用宏观/产业指标时注明口径、单位与频率（周/月/季）。

### 2.7 由行情序列派生：主力合约识别与技术指标

以下均**基于 2.1 行情报表返回的价格/持仓序列在内存中计算**，不需要额外 MQL 指标：

- **主力合约识别**：在「同品种期限结构」（模板 3）结果的最新交易日截面里，取**持仓量最大**的合约作为该品种主力合约；若入参合约即为主力合约，则在报告中标注「本合约为该品种主力合约」，并计算距交割月剩余自然月数作为**交割月提示**（只提示不指令）。
- **均线（MA）**：对近 N 日**收盘价**序列计算 MA5/MA10/MA20/MA60（简单移动平均）；比较最新价与各均线位置及均线多空排列。
- **MACD**：以收盘价序列计算 EMA12、EMA26 → DIF = EMA12 − EMA26；DEA = DIF 的 EMA9；MACD 柱 = 2 × (DIF − DEA)。判断金叉/死叉与背离迹象。
- **支撑/压力位**：取近 N 日高低点、整数关口、均线及成交密集区推导；报告只描述位置，不预测突破方向与目标点位。

> 序列长度不足以计算 MA60 或 MACD 时，缺的指标省略，不写「数据不足」；至少需 60 个交易日收盘价方计算 MA60 与 MACD。

## 三、MQL 语法约束（硬性）

- 所有**路径分隔符用单个反斜杠 `\`**；路径放在花括号 `{}` 中，不加双引号、不做字符串转义。
- 指标引用写成 `{Choice指标\...\指标名|指标ID}({参数名} = "值");`；报表路径写成 `ReportBlock(#1, {Choice报表\...\报表名|报表ID});`。
- `ReportBlock` **至少定义一个输出列**（`:` 语句），否则报「每个 Block 至少需要一个输出列」。
- `SetReportFilter`：比较运算符用 `==`（不是 `=`）；范围用 `>=` / `<=`；多条件用 `AND` 连接；**只能用报表的「加载列」（filter 列）**。
- `FILTER_ROWS`：用于按**输出列**过滤（如 `FILTER_ROWS({期货代码} == "CU2611.SHF")`），须放在所有输出列声明之后。
- `Sort({列}, "ASC"|"DESC")` 必须放在所有 `REPORT_FIELD` 声明之后。
- **不支持** `in` 运算符（多值用 `OR` 连接多个 `==`）、`Limit()`、`Top()`。
- `OutputBlock()` 不接受参数。
- `REPORT_FIELD("...")` 中必须使用返回列的**完整中文名（含括号）**。
- `CrossSectionBlock(#1, {EM_CODE});` 中 `{EM_CODE}` 为固定写法；用 `SetCodes(["{代码}"])` 指定证券范围。
- 时间序列读取优先用**报表日期区间过滤**（已验证稳定），不要依赖 `SetWindow`（参数名易错）。

## 四、取数模板（模板 0 存在性校验 + 六类取数）

> 模板中的 `{期货代码}` `{品种代码}` `{期货内码}` `{今天}` `{一年前}` `{起始日}` `{市场编码}` 等为占位符，执行时按实际值替换。存在性校验（模板 0）的 `{一年前}` = 今天往前 365 天；其余取数日期窗口建议 `{起始日}` = 今天前 60~90 个自然日。

### 模板 0：合约存在性校验（前置硬门槛，必须最先执行）

> 用途：确认入参代码被 MQL 的**期货全合约清单**（期货 F10 全合约日行情，等价于「期货数据浏览器」的合约宇宙）识别。空结果 = 无效代码，**立即中断，不重试、不继续取数**。

```text
ReportBlock(#1, {Choice报表\报表指标\服务端\妙想服务\量化查数\期货\期货F10_所有期货合约_日行情|493651603765884});
SetReportFilter({交易日期} >= "{一年前}" AND {交易日期} <= "{今天}");
{期货代码}: REPORT_FIELD("期货代码带后缀");
{交易日期}: REPORT_FIELD("交易日期");
FILTER_ROWS({期货代码} == "{期货代码}");
OutputBlock();
```

**判读与处置（硬性）**：

- 取 `result.output.blocks[0].rows`（或 `total`）：
  - **行数 ≥ 1** → 代码有效，进入后续取数流程。
  - **行数为 0**（或报表虽返回大量行但 `FILTER_ROWS` 后为空）→ 判定**代码无效**，**立即中断本次任务**，按失败话术告知用户，**不做退避重试、不改写代码、不换标的硬凑、不进入后续任何 MQL/RAG 取数**。
- 日期窗口取**近一年**（`{一年前}` = 今天往前 365 天），以兼容近期上市合约；存在性校验**只执行一次**。
- 该报表一次返回全市场约 3 万余行，属正常；判定依据是 `FILTER_ROWS` 过滤后的目标合约行数，不是报表总行数。
- 校验失败即终态：这是**唯一**允许「不重试直接终止」的取数环节。

## 五、容错与降级规则

1. **单 Block 失败不阻断**：任一 Block 报「报表不存在/字段不存在/返回 0 行」时，仅该 Block 对应维度降级或省略，其余维度照常。
2. **路径/字段复核**：出现字段错误或 0 行时，回到 `Search_Context`（`searchIndicator.keys` 传报表名或字段名）复核路径与字段，**不得硬凑或臆造**。
3. **标准代码支持**：`reportStandardCodeSupported=false` 的报表（会员持仓、现货价）**禁止写 SetCodes**，改用 `SetReportFilter` + `FILTER_ROWS`。
4. **维度省略**：某维度 MQL 完全取不到数据（报表缺失、0 行、鉴权/网络失败）时，整体省略该维度与图表，不写缺口说明，不猜测编造；数据不足时用「依据不足」表述。
5. **单位校准**：成交额入库单位为万元，展示换算为亿元；其余数值单位以字段说明与 `宏观指标名称` 口径为准，报告内统一并注明。
6. **时效校验**：确认数据覆盖目标交易日；非交易日顺延至最近交易日并在报告中标注实际数据日期。
7. **宏观/产业降级**：宏观与产业指标经 `mx_macro_data` 获取；若某指标查不到或口径不符，仅省略该指标/维度，不得用 `EdbBlock` 或臆造数值替代。技术指标序列不足则省略对应指标。
8. **存在性校验失败即终态（硬性）**：模板 0 返回 0 行即判定代码无效，**立即中断全部任务**——**不适用**第 1 条「单 Block 失败不阻断」，**也不做**退避重试；按失败话术告知用户代码无效。**严禁**改写代码、替换标的、放宽条件后反复查询来「凑」出数据。
