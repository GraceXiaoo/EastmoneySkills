# 已确认经验

本案例由用户确认为效果达标，可作为同一 PDF 的快速演示样例和同类宏观周报的回归基线。数值、日期、代码和执行结果仅属于本案例。

## 可迁移规则

- 宏观、利率、债券、基金、指数、行业、商品和外汇指标先走 MQL 指标检索与真实执行；代码或路径错误是可纠正错误，不能据此省略对象。
- 全球指数必须使用检索确认的标准代码。结果中同时保留技术代码和可读简称，不能只显示代码。
- 申万一级行业通过正确的板块/指数体系枚举完整集合，不能用个股筛选或其他行业分类替代。
- MQL 方向逐块判断。本案例的指数与行业涨跌幅保持原方向，CPI、国债、商品和汇率块按目标布局转置；不得把这里的 0/1 当成其他研报的默认值。
- `10_研报快照` 中原文截图与同一对象的解析结果相邻。截图范围以接口坐标为初始框，必须经页面视觉核验后收紧到完整图表边界。
- `20_研报底稿` 只包含真实执行成功的可刷新 MQL；未匹配对象保留在快照和日志，不用 PDF 静态值冒充查询结果。

## 本案例覆盖基线

金标准工作簿含五个固定 Sheet、7 个 MQL 锚点和 10 个媒体对象。MQL 覆盖 CPI/PPI、全球主要国债收益率、A 股主要指数、申万一级行业、全球主要指数、主要商品和主要汇率。

## 后续反馈记录格式

新增反馈时追加以下字段，并同步更新 `manifest.json` 中受影响文件的指纹：

- 日期、对象 ID、Sheet/范围；
- 发现的问题与证据；
- 人工期望；
- AI 修正内容；
- `CASE_SPECIFIC` 或 `GENERALIZABLE`；
- 验收方式、验收结果和 `accepted` 状态。
