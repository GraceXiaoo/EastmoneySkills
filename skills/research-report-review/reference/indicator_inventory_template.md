**优先级定义**：
- `P0`：核心财务指标（营收/利润/毛利率/现金流/负债率）

- `P2`：一致预期/估值
- `P3`：主观判断、内部衍生计算或需人工确认项

## 三、来源类型定义

| 来源类型 | 标识 | 说明 | 漏识别风险 |
|---------|------|------|-----------|
| 表格正文 | `TABLE` | markdown表格或docx表格 | 低（肉眼可见） |
| 图片数据 | `IMAGE` | 截图中的数据（需OCR或已有文字版） | 中（依赖图像识别） |
| **正文嵌入** | `TEXT` | **叙述段落中的数字** | **高（最易遗漏）** |
| 脚注/来源 | `FOOTNOTE` | 数据来源说明中的数字 | 低 |

## 四、MQL可行性定义

| 可行性 | 标识 | 说明 | 后续执行方式 |
|--------|------|------|-------------|
| 标准财务指标 | `STD` | Choice指标库直接可取 | CrossSectionBlock |
| 一致预期指标 | `CONSENSUS` | 盈利预测综合值 | CrossSectionBlock(盈利预测) |
| 估值指标 | `VALUATION` | PE/PB/PEG等 | CrossSectionBlock(估值分析) |
| 股本/股权 | `SHARE` | 持股比例/股本 | CrossSectionBlock(股本指标) |
| 分部报告 | `REPORT_SEGMENT` | 按业务/产品/地区分部 | ReportBlock(分部报告) |
| 客户/供应商报表 | `REPORT_CUSTOMER` / `REPORT_SUPPLIER` | 前五大客户/供应商 | ReportBlock(公司资料) |
| 人力/研发 | `HR_RD` | 研发人员/学历/专利 | CrossSectionBlock + 报表 |
| 计算衍生 | `DERIVED` | 需多指标计算组合 | MQL内计算或多Block |
| EDB 指标 | `EDB` | 宏观、行业经济、利率、债券、基金、指数、外汇、商品或高频数据库序列 | 先检索并执行 MQL；完成的MQL检索/查询确认缺指标、缺结果或确认服务故障且满足数据执行协议准入后，由 `mx-ds-mcp` 兜底 |
| 资讯事件 | `INFO` / `NEWS` | 资讯、新闻与事件事实 | `mx-ds-mcp` 资讯新闻接口 |
| 公告 | `ANNOUNCEMENT` | 交易所或公司公告 | `mx-ds-mcp` 公告接口 |
| 研报 | `RESEARCH_REPORT` | 外部研究报告及观点/事实 | `mx-ds-mcp` 资讯检索接口 |
| 非MQL | `NON_MQL` | 无已知数据服务路径 | 先检索 `mx-ds-mcp`；仍无结果再标注原因 |

## 五、口径类型定义

| 口径 | 标识 | 典型场景 |
|------|------|---------|
| 加权 | `WEIGHTED` | ROE(加权) |
| 摊薄 | `DILUTED` | ROE(摊薄)、EPS(摊薄) |
| TTM | `TTM` | PE(TTM)、营收TTM |
| 年化 | `ANNUALIZED` | ROE年化 |
| 滚动 | `ROLLING` | 一致预期FY1/FY2/FY3 |
| 期末 | `END_PERIOD` | 资产负债率期末值 |
| 平均 | `AVERAGE` | 总资产报酬率(平均) |
| 未标注 | `UNSPECIFIED` | 研报未明确口径，需推断或标注待确认 |

## 六、数值性质定义

| 数值性质 | 标识 | 判定规则 | 后续处理 |
|---------|------|---------|---------|
| 历史实际值 | `ACTUAL` | 年度列标为 A，或正文明确已披露历史期间 | 进入数据准确度与口径核验 |
| 分析师预测值 | `FORECAST` | 年度列标为 F，或正文明确为未来年度预测 | 进入预测框架分析，不计入历史准确度 |
| 一致预期比较值 | `CONSENSUS_CMP` | 分析师预测中可与市场一致预期比较的项目 | 进入预测偏离度分析 |
| 分析师判断 | `JUDGMENT` | 目标价、估值倍数、市占率判断或“我们预计/认为”类结论 | 进入逻辑与自洽性分析 |
| 研报内部衍生值 | `DERIVED_RPT` | 上行空间、增长率等可由研报自身数字计算的结果 | 进行内部勾稽校验 |

所有指标必须填写数值性质。财务附表中每一列 F 数据必须逐项入表并标为 `FORECAST`，不得因为未来期间尚未发生而省略。

## 七、来源定位与告警定义

| 字段 | 填写规则 |
|------|---------|
| 来源定位 | 表格指标填写“页码 / 表名 / 行名 / 列头”；正文填写“页码 / 段落名 / 原文句摘录”；图表填写“页码 / 图表名 / 图例或坐标轴” |
| 来源告警 | 无问题填“无”；表格无法还原填 `TABLE_UNPARSED`；图表无法可靠读取填 `IMAGE_UNPARSED`；列头冲突填 `SOURCE_LABEL_CONFLICT` |

带任一来源告警的指标不得直接计入已确认历史准确度，须在后续回读核验中处理。

## 八、图表指标抽取方法与置信状态

| 抽取方法 | 使用条件 | 允许的置信状态 |
|---|---|---|
| `LAYOUT_CONTENT_VERIFIED` | 接口图片块 content 候选表与裁剪截图逐项一致 | `EXACT` |
| `LAYOUT_CONTENT_CORRECTED` | 接口图片块 content 候选表存在错误，按裁剪截图逐项修正并留痕 | `EXACT` / `APPROXIMATE` |
| `EXTERNAL_VERIFIED` | MQL 或 `mx-ds-mcp` 返回同口径数据并留痕 | `EXACT` |
| `VISUAL_ESTIMATE` | 按曲线、柱高或面积估读 | `APPROXIMATE` |

接口识别值带 `~`、只出现于坐标轴刻度或无法从截图定位到具体数据点时，不得标记 `EXACT`。无法可靠读取时保留图表截图与元数据，指标标记 `IMAGE_UNPARSED`，不生成虚构数值。
