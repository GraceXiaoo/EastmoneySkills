# 容差规则与口径检测矩阵

## 一、容差分级（单一真源）

> 阈值与分级**不在本文件重复**。唯一真源为 [tolerance_rules.json](tolerance_rules.json)，由
> `scripts/result_comparison.py:classify` 机械执行：每个 `metric_type` 只声明一种单位，分级有序、
> 无重叠、末级开放（无未覆盖区间）；边界由浮点噪声抹平后按十进制唯一判定。

### 1.1 等级标识

| 等级 | 标识 | 判定 | 备注 |
|------|------|------|------|
| EXACT | ✅精确一致 | PASS | 无需归因 |
| TOLERANCE | ≈口径容差 | PASS | 必须标注实际匹配口径 |
| DRIFT | ⚠️时点漂移 | CONDITIONAL | 仅 `CONSENSUS` 拥有；须方向一致并标注截止日期 |
| SIGNIFICANT | ✗显著偏差 | FAIL | 需调查，不得以扩大容差替代调查 |

### 1.2 单位归属（百分点与相对百分比不混用）

| metric_type | 单位 | 说明 |
|-------------|------|------|
| `MONEY` / `PRICE` | 绝对（报告单位） | 阈值随研报取整精度 `report_rounding_places` 确定，**不是全金额统一 0.01** |
| `RATIO_PERCENT` | 百分点 pp | 小数来源须先 ×100 归一化（见 `normalize_to_unit`） |
| `MULTIPLE` / `SHARE` / `CONSENSUS` | 相对百分比 % | 分母取研报值绝对值 |
| `COUNT` | 个/项 | 整数类 |

## 二、口径自动检测矩阵

### 2.1 常见口径对照

| 指标 | 可能口径 | MQL 指标路径关键词 | 检测方法 |
|------|---------|-------------------|---------|
| ROE | 加权 / 摊薄 / 平均 | `净资产收益率ROE(加权)` / `(摊薄)` / `(算术平均)` | 多口径分别定级后**只产生候选**（`result_comparison.candidates`），不得据误差小者认定研报定义 |
| EPS | 基本 / 稀释 | `每股收益EPS(基本)` / `稀释每股收益` | 同上 |
| 营收 | 营业收入 / 营业总收入 | `营业收入` vs `营业总收入` | 券商/银行/保险等并表金融子公司时两值不同 |
| 净利润 | 归母 / 扣非 / 整体 | `归属于母公司股东的净利润` / `扣除非经常性损益后...` | 研报标注"扣非"时必取扣非值 |
| PE | TTM / 静态 / 动态 / 一致预期 | `PE(TTM)` / `PE(静态)` / `预测PE` | 研报标注"前瞻X年"时用一致预期PE |
| ROA | 总资产净利率 / 总资产报酬率 | `总资产净利率ROA` vs `总资产报酬率` | 名称相近但公式不同 |
| 增速 | 同比 / 环比 / CAGR | `同比增长率` / `环比增长率` / `复合增长率` | 研报标注"近X年CAGR"时用复合增长率 |
| 股本 | 期末 / 加权平均 | `总股本` vs `加权平均股本` | EPS计算用加权，截面展示用期末 |

### 2.2 口径检测流程

```
Step 1: 先执行前置一致性检查（定义/币种/单位/期间/股数时点/调整类型），不一致即停
Step 2: 从指标清单读取研报标注的口径（若有）
Step 3: 若口径未标注，同时取多个口径的 MQL 值
Step 4: 分别定级并输出**候选排序**；`closest` 仅为候选，不认定研报定义
Step 5: 结合原文口径标注与前置检查结果，由人工确认匹配口径并留痕
Step 6: 若无候选通过，标记"口径待确认"
```

### 2.3 双口径自动检测示例（ROE）

```mql
// ROE 双口径同时取数，用于自动匹配研报口径
{ROE加权_2025}: {Choice指标\...\净资产收益率ROE(加权)}({报告期} = "2025-12-31");
{ROE摊薄_2025}: {Choice指标\...\净资产收益率ROE(摊薄)}({报告期} = "2025-12-31");
```

**检测逻辑**（本地推理，非MQL内；由 `result_comparison.candidates` 产出候选，人工确认）：
- 研报 image_05 值 14.00 → 与加权 14.03 误差 +0.03pp（TOLERANCE）→ **列为候选**，仍须人工确认
- 研报 image_06 值 13.15 → 与摊薄 13.15 误差 0（EXACT）→ **列为候选**，仍须人工确认
- 同一公司两张表用不同口径，必须分别标注，不得混用，也不得据误差最小直接认定

## 三、差异归因框架

对非精确一致的比对组，按以下框架归因：

| 归因类别 | 典型表现 | 处理方式 |
|---------|---------|---------|
| 口径差异 | TOLERANCE 级（多个口径中存在候选） | 标注实际匹配口径，通过 |
| 四舍五入 | EXACT 级且研报保留位数少于MQL | 标注四舍五入，通过 |
| 时点漂移 | DRIFT 级（`CONSENSUS`，方向一致） | 标注截止日期差异，有条件通过 |
| 数据修订 | 历史财务数据被重述，MQL取最新修订值 | 标注修订版本，需确认研报版本 |
| 指标路径错误 | SIGNIFICANT 级且所有口径均无候选 | 回本 Skill 的数据核验阶段重新检索 |
| 研报笔误 | MQL值与公告原文一致，研报值不同 | 标注研报可能笔误 |
| 非MQL指标 | 研报值为主观判断或计算值 | 标注不可比对 |
