# 未匹配项归因规则

## 目的

将未能直接形成核验结论的指标转化为用户可理解、可复查的说明。最终用户报告不得出现 `NON_MQL`、`STD`、`CONSENSUS`、`VALUATION`、`SHARE`、`REPORT_SEGMENT`、`REPORT_CUSTOMER`、`REPORT_SUPPLIER`、`HR_RD`、`DERIVED`、`MQL可行性` 等内部标签。

## 判定顺序

1. 未来期间数据尚未发生。
2. 分析师主观判断。
3. 研报内部衍生计算。
4. 口径定义不一致。
5. 底层数据未收录或无对应明细。
6. 原文疑似笔误或标注错误。

若同时具有多种特征，主结论按上述顺序确定，其他特征写入补充说明。证据不足时写“需人工确认”，不得猜测。

## 用户视角结论与依据

| 用户视角结论 | 适用情形 | 必须提供的依据 |
|---|---|---|
| 未来期间数据尚未发生 | 报告期晚于核验基准日 | 报告期、基准日及预测性质原文 |
| 分析师主观判断 | 目标价、估值倍数、评级或“预计/认为”类表述 | 原文摘录、页码、判断类型 |
| 属研报内部衍生计算 | 可由研报内部数字还原 | 公式、所有输入、还原值、研报值和差异 |
| 口径定义不一致 | 近似口径均无可通过候选 | 候选口径、候选值、差额和排除理由 |
| 底层数据未收录或无对应明细 | 已完成近义词、期间、单位和口径检索仍无候选 | 检索词、日期、结果摘要和排除理由 |
| 疑包含其他项（保留待确认） | 折旧摊销、经营性应付、减值、营运资本、资本开支等按来源定义存在包含关系差异 | 来源定义原文、已比对候选、未澄清项；结论写“需人工确认”，不得写成已核实 |
| 原文疑似笔误或标注错误 | 表格/正文矛盾，或与可靠原始来源冲突 | 冲突位置、原文值、对照值和对照来源 |

## 通用映射检查

目标价、估值倍数、评级和明示预测类表述优先检查分析师判断；上行空间、增长率和合计值优先检查研报内部还原；市场价格、历史财务和股本数据在归为底层缺失前，必须先核对日期、单位和候选口径。这些是判定顺序，不是预设结论。

## 质量检查

- 每项有且仅有一个主结论。
- 每个主结论有可审查依据。
- 衍生计算项列出公式、输入和还原结果。
- 口径不一致项列出全部已比较候选口径。
- 最终报告不出现内部标签。
