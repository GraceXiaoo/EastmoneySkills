# 通用防漏检查清单

本清单不预设公司、行业或固定指标。它用于发现“表格已抽取，但表外数字或表内特殊行被遗漏”。

## 表格内

- 多级表头、单位、脚注和口径说明。
- 首行、末行、合计、小计、其中项、缩进子项和重复行名。
- 所有历史期、预测期、同比/环比、余额/发生额和比例列。
- 空白、破折号、0、N/A、负号和括号负数的区分。
- 表后紧邻的资料来源、计算公式和定义。

## 正文和图表外

- 标题、摘要、投资要点、正文段落中的数字+单位/百分比/倍数/日期。
- 评级、目标价、目标市值、基准价、上行/下行空间和目标期限。
- 分析师预测调整、市场一致预期对比、估值倍数和可比公司数据。
- 产销量、价格、市占率、产能、客户/供应商、人员、研发、股权、订单和项目节点。
- 图中标注数值、坐标轴单位、图例和时间范围；无法准确读取时列为待人工确认。

## 分类检查

每个数字项都必须具有时间、单位、原文位置和数值性质。不确定时标记待确认，不得猜测。
