# 报告框架与撰写规范

> 本文件定义两类异动分析报告（**盘后复盘 / 盘中快报**）的模块框架、内容要求与撰写规范。依据已验证的样例报告提炼（盘后归因精简版、盘中快报）。两类框架均同时适用于上涨与下跌方向的异动归因；输出格式默认 HTML，用户要求 Word 时按对应模式的模块结构产出 DOCX（内容框架不变，排版遵循 Word 文档规范，不追求 HTML 版的视觉复杂度）。

## 0. 撰写总则

1. **结论先行**：第一模块即给出归因结论，先答案后论证；
2. **量化优先**：用数字说话（涨跌幅、超额收益 pct、净流出金额），避免"大幅""明显"等无锚定形容词单独出现；
3. **标签体系**：证据等级 A/B/C（+D 情绪/E 待核验）、可信度 高/中/低、异动等级 红>橙>黄>蓝（按涨幅×换手×板块偏离综合判定）；
4. **涨红跌绿**：A股口径下上涨用红色（#d92d20 系）、下跌用绿色（#027a48 系），与模板一致；
5. **每份报告必须包含**：信息截止时间、主要信源清单、研究局限说明、"不构成投资建议"声明；
6. **图表必配解读**：任何图表（ECharts/SVG）必须紧跟文字解读（读什么、说明什么、对归因的支持/削弱），禁止交付无解读的裸图；
7. **信息架构三段式**：上段=结论/置信度/交易含义；中段=证据/时间轴/反事实；下段=跟踪清单/失效条件/风险。投研读者要的是"可证伪、可跟踪、可决策"，不是页面炫技——装饰性元素为内容服务，能减则减；
8. **买方视角收尾**：报告须以组合经理视角收尾（已持仓/未持仓/做空对冲三类持有状态的操作含义），定位为解释性归因而非看多/看空建议；
9. **模块字数软性上限（控制输出 token）**：各模块设软性上限，超限时优先压缩修饰语、套话与重复表述，**不得以删减证据、反证、数据口径为代价**；确因归因复杂需超限的模块允许上浮 50%，交付前自查：

| 模块/条目 | 软性上限 |
|---|---|
| 结论先行（模块一） | ≤ 300 字 |
| 证据矩阵每行（模块四） | ≤ 100 字 |
| 异动画像分时表"盘面解读"每格（模块二） | ≤ 50 字 |
| 归因拆解每个因子条目（模块三） | ≤ 150 字 |
| 多空博弈每条（模块六） | ≤ 60 字 |
| 买方视角结论（模块八） | ≤ 250 字 |
| 盘中快判（盘中模块一） | ≤ 200 字 |
| 交付回复中的要点摘要 | 200–300 字；须使用加粗结构化标签：**直接催化剂**、**传导链条**、**主因**、**辅因**、**背景（非原因）**、**关键分歧**、**下一步盯** |

## 1. 盘后异动归因报告（HTML，默认形态）

适用于盘后对单票异动做深度归因，共九模块：

### 头部（Hero）
- 标题格式：`{公司名}（{代码}）{异动概括}：{核心归因一句话}`
- 异动区间、信息截止时间、免责声明
- 关键指标 chips：累计涨幅/跌幅、涨跌幅偏离值（若触发异常波动）、归因等级（主题驱动型/业绩驱动型/板块共振型/资金博弈型）、证据置信度（高/中高/中/低）

### 模块一：结论先行（ONE-SENTENCE VERDICT）
- 一段话概括驱动逻辑（含传导链条的一句话版本）；该传导链条须在对话正文要点摘要中**加粗展示**，并统一使用结构化加粗标签：**直接催化剂**、**传导链条**、**主因**、**辅因**、**背景（非原因）**、**关键分歧**、**下一步盯**
- 四个要点：直接催化剂、基本面底色、估值状态、核心风险

### 模块二：异动画像（PRICE ACTION PROFILE）
- 异动区间逐日表格：日期、涨跌幅、盘面特征、归因指向
- **当日分时异动表（分钟级，必做）**：异动当日关键时点（集合竞价、首个异动时点、放量/加速时点、消息发布时点、尾盘）的时间、涨跌幅、量能、盘面解读；并与催化发布时点逐一对照——**催化晚于启动的消息只能解释其后的放大段，不能解释启动本身**；无法获取分时数据时在方法与局限中声明"时间轴仅到日级"
- 分时解读须覆盖：量能集中时段、大单/主动性买卖方向、与指数的同步性（个股独涨 vs 随指数）
- KPI 卡片：收盘价、总市值、估值（PB/PE）、换手率
- **量价行为判定**（按 `analysis-playbook.md` 第 1 节）：放量形态（持续型/脉冲型）与量价配合度、位置含义（低位/高位/突破/冲高回落）、跳空性质（事件驱动/情绪强化/补涨补跌/技术触发四型标签）
- **双图要求（单日分析场景必做）**：模块二须同时包含——①**近期走势图**：近 5–10 日收盘价折线（或日K）+ 成交量，定位本次异动在近期趋势中的位置（突破/冲高回落/趋势延续）；②**日内分时图**：当日分时价格线 + 成交量（双轴），**标注催化发布时点**（markLine/markPoint）；图表规范按 `analysis-playbook.md` 第 6 节，每图紧跟文字解读（读什么、说明什么、对归因的支持/削弱）；无法获取分时数据时，日内分时图降级为分时表并在方法与局限中声明
- 必须判断：是"单日孤立事件"还是"多日趋势的一环"（附近 5 日行情）

### 模块三：归因拆解（ATTRIBUTION BREAKDOWN）
- **分层式归因（默认）**：因子按 **主因（必要且充分）/ 辅因（放大幅度与速度）/ 背景（不是原因）** 三层组织，每层标注证据等级与传导链条（细则见 `attribution-method.md` 第四步）
- 贡献度百分比（合计 100%）为**可选项**，仅作排序参考且必须标注"研究判断值，非模型输出"；并注明若需严格量化应采用事件窗口 CAR（T-1/T+0/T+1 累计超额收益）+ 板块/可比公司对照 + 分钟级成交集中度
- 归因判定 callout：哪些因子是必要且充分条件、哪些决定幅度与速度、哪些仅是情绪底座/背景

### 模块四：证据矩阵（EVIDENCE MATRIX）
- 表格：渠道（公司公告/互动平台/定期报告/MQL 或妙想 MCP - 行情数据/券商研报/公众号社群/海外原始信源）、关键事实、可信度、对归因的支持
- **反证与反例行（必做）**：矩阵须包含"可能证伪本次归因的信号"与"与归因矛盾的数据"（口径冲突、同期同题材未涨的反例、数据缺失项），不能只罗列正面/中性证据——可证伪性是投研报告与宣传稿的分界线
- 海外原始信源标注"需逐条核验"

### 模块五：基本面—估值—股价三角错位（FUNDAMENTAL-VALUATION MISALIGNMENT）
- 股价与基本面显著背离时**必须单列本模块**（不得塞进风险附注），结构：
  - **已验证**：市场定价中哪些已有数据/事实支撑（业务能落地、有客户/传播量、有法定披露佐证）；
  - **未验证**：哪些关键假设尚无口径（收入占比、单价、利润率改善、拐点时点）；
  - **结论**：定性本轮是"利润表未验证的商业模式重定价 / 预期差行情"还是"业绩驱动行情"；指出股价是否跑在财报前面，**下一份财报是证伪/确认点**。
- 若股价与基本面同向且无显著背离，可简要说明后并入结论先行，不单列。

### 模块六：博弈结构（BULL VS BEAR）
- 左右双栏：多头可验证的支点 ▲ / 空头未计价的风险 ▼
- 各 3–5 条，逐条可核查
- 资金流与价格的背离信号（如融资净流出但股价上涨）正面呈现、不弱化，作为短线情绪驱动证据

### 模块七：后续跟踪清单与归因失效条件（MONITORING CHECKLIST）
- 表格：维度（海外主线/公司管线或业务/资金面/基本面/交易信号）、验证信号、含义
- **归因失效条件（必做，置于情景推演之前）**：列出"出现什么信号即说明本次归因错误或失效"（例：核心产品数据低于预期 → 主题溢价回撤；财报仍无相关收入口径 → 市场退回概念定价；板块续跌但个股靠资金硬拉 → 拥挤度风险上升；龙虎榜纯游资席位次日无承接 → 高位派发）——具体的失效条件比主观情景概率更有用
- 情景推演 callout：乐观 / 中性 / 悲观三情景（概率标注为主观研究判断，仅作排序参考）
- 市场环境与情绪背景：个股异动的持续性预期须放在市场环境四档（进攻/精选/控制/观望）里校准；题材类异动标注四种热度分级（真主线/次级热点/脉冲题材/跟风分支）与板块交易位置，情绪温度计（连板高度、炸板率、涨停/跌停数、高位股次日溢价）给出量化证据（按 `analysis-playbook.md` 第 3 节）

### 模块八：买方视角结论（PM TAKEAWAY）
- 面向组合经理收尾（区别于卖方科普式结尾）：
  - **已持仓**：趋势/仓位管理建议（关键位得失、加减仓触发条件，"不追高"式表述）；
  - **未持仓**：入场的验证点等待建议（先看什么数据落地，再判断"商业模式切换 vs 主题脉冲"）；
  - **做空/对冲**：是否适合裸空、对冲结构建议（如个股拥挤但板块 β 弱时用 ETF 多空配对）；
- 定位声明（必写）：**本研究结论是对本次异动的解释性归因，不是对该股的看多/看空建议**。

### 模块九：方法说明与局限（METHODOLOGY & LIMITATIONS）
- 归因方法（分钟级时间轴对齐 + 反事实检验 + 证据分级 + 分层归因）
- 数据口径说明：数据来源口径标注（如"Choice数据，数据日期 XXXX-XX-XX"）、时间轴粒度声明（分钟级 / 仅日级降级及原因）、资金流等口径限制对结论的影响——**不含数据通道审计表与任何内部取数链路信息**（审计表只留工作记忆，见 `data-sources.md` 第 3.3 节与 SKILL.md 2.4 节）
- 涉及资金推动归因时，注明"资金推动指大单主导的边际定价，不等同于机构共识形成"
- 局限：无法获取逐笔资金与完整机构持仓、海外信源需二次核对、公众号仅情绪指标、事后分析不预测短期股价

### 尾部
- 核心结论一句话（主因/辅因分层表述，点明"预期差行情 vs 业绩驱动行情"之类的本质定性）
- 主要信源列表 + 免责声明

## 2. 盘中异动快报（HTML，盘中形态）

适用于盘中（如午间休市时点）对正在异动的个股做决策支持，共七模块。与盘后版的本质差异：**不预设结果、明确标注待核验项、结论当日有效**。

### 头部（Hero）
- 标注"盘中实时异动监测 · INTRADAY FLASH"
- 观测窗口（如 09:30—11:30）、前一交易日表现、"数据以实际通道（MQL / 妙想 MCP - 行情数据）为准"
- chips：时段涨跌幅、最高价、振幅、半日换手、封板时长（若涨停）、异动等级、等级口径说明

### 模块一：盘中快判（FLASH VERDICT）
- 盘中状态定性（如"连板高位 + 情绪加速 + 筹码剧烈交换"）
- 走势分段 flow 图（时间轴上的 3–4 段关键走势）
- 午间/时段结论：三句话结构——趋势状态、筹码状态、胜负手在哪里

### 模块二：分时关键节点还原（TICK RECONSTRUCTION）
- **日内分时图（必配）**：截至观测时点的分时价格线 + 成交量（双轴），标注催化发布时点与关键转折时点；图表规范按 `analysis-playbook.md` 第 6 节，图后紧跟文字解读；无法获取分时数据时降级为纯表格并声明
- 表格：时间（含集合竞价）、价格/涨跌幅、成交量（手）、盘面解读
- 解读须含盘口语言：封单厚度与变化、开板时点与量能、均价线得失、主动性买卖占比
- 半日合计行：与前一交易日全天量能对比（如"半日量能已达前日 88%，放量滞涨初现"）

### 模块三：驱动归因·盘中可验证版（INTRADAY ATTRIBUTION）
- 表格：因子、贡献度、**可验证性标签**（已发生/待核验/已公告/可计算/无新增）、盘中表现
- KPI：相对板块超额收益、量比、委比、5 日均线偏离
- 归因要点 callout：说明盘中归因与事后归因的差异（无法确认当日新增催化时，盘口可观测事实优先）

### 模块四：盘口语言解读（ORDER-FLOW READ）
- 左右双栏：空头信号（已出现）▼ / 多头信号（仍在）▲
- 每条信号须具体：封单变化、大单净额、均价线、委比、融资盘拥挤度

### 模块五：情景推演与操作阈值（SCENARIOS）
- 表格：情景（3–4 个）、概率（主观判断）、触发条件（可盯）、应对
- 硬阈值 callout：3 条具体价位/换手率阈值（如均价线、昨收、关键换手率）

### 模块六：盘中必须核验的信息清单（REAL-TIME CHECKLIST）
- 公司层面（公告/互动平台有无**新增**）、行业层面（海外今日新动态，以时间戳为准）、板块层面（同概念是否同步，防对倒）、资金层面（龙虎榜预告/融资变动）、监管层面（交易所盘中提示/媒体质疑）
- 信息甄别红线 callout：小作文一律按假处理，直至法定渠道确认

### 模块七：方法、数据口径与局限（METHODOLOGY）
- 盘中性质声明（结论当日有效、隔夜失效、不预设结果）
- 数据口径（封单/委比/DDE 各终端有差异，仅作方向参考）；资金面表述纪律同盘后版：主力/大单为算法分类而非真实账户身份，禁止写成"机构买入"，涉及资金推动须注明"大单主导的边际定价，不等同于机构共识形成"
- 局限 + 收盘回填约定

### 尾部
- 一句话操作要点（如"不追高、减获利、守阈值"）
- 观测标的/日/时点、信息来源、免责声明

## 3. 质量自检清单（交付前逐项核对）

- [ ] 第一模块是否直接给出归因结论（不用读完全文才知道答案）
- [ ] 资讯/公告检索是否遵守检索降噪三规则（时间窗异动日±7天、只要标题+摘要+日期+链接、公告类型白名单、超 20 条截为最相关 10 条，见 `data-sources.md` 第 4 节）
- [ ] 榜单类查询是否使用固化问句模板（跌幅榜含"剔除上涨和平盘股票"）；返回结果是否做了方向性校验
- [ ] 各模块是否在字数软性上限内（或允许上浮 50% 以内），压缩是否未牺牲证据与口径（撰写总则第 9 条）
- [ ] **两场景是否默认产出 HTML 产物**：场景一（双榜，`top_movers_template.html`）与场景二（`post_close` / `intraday_template.html`）是否均生成 HTML 文件、写入后校验非空、调用 present_files 呈现成功后才结束回合（SKILL.md 第六步"产物交付可靠性纪律"）
- [ ] 对话交付（场景一对话内表格 / 要点摘要 / 盘中快评）是否无数据通道清单、口径校验的过程性说明**与取数执行偏离说明（降级/通道替代/预算受限/补取建议）**，仅保留一句话口径标注（SKILL.md 硬性规范第 12 条"对话层降噪"）
- [ ] 每个关键事实是否可溯源（信源 + 日期）
- [ ] 归因是否按主因/辅因/背景分层（而非裸百分比贡献度）；若给出百分比，是否标注研究判断值并说明严格量化路径（事件窗口 CAR）
- [ ] 时间轴是否到分钟级；催化晚于启动的消息是否只用于解释放大段；若降级为日级是否已在局限中声明
- [ ] **MQL 优先是否落实**：所有结构化数据维度（行情/榜单/资金/龙虎榜/估值/财务/板块/可比公司）是否先尝试 MQL；MQL 可用时是否未绕过；若因单轮取数预算受限降级，是否已先做合并取数降耗、是否在工作记忆审计表注明预算去向（`data-sources.md` 第 3.4 节）
- [ ] **交付物是否零内部链路**：报告是否不含数据通道审计表、逐维度通道清单与"预算受限/未走 MQL/妙想补齐"类执行表述；数据口径（来源 + 数据日期 + 粒度）与溯源（信源 + 日期 + 链接）是否完整清晰，未使用"交易所行情""行情数据"等模糊表述
