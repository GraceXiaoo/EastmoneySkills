# 归因方法论：证据分级、归因四步法与交叉验证

> 本文件定义异动归因的核心方法。所有场景二单票复盘必须按此执行，确保结论可验证、可溯源、可复现。

## 1. 证据分级体系

| 等级 | 定义 | 典型来源 | 使用规则 |
|---|---|---|---|
| **A（直接/法定）** | 法定信息披露、交易所数据 | 公司公告、交易所行情、异常波动公告、监管披露 | 可单独作为归因依据 |
| **B（可证/半官方）** | 可独立验证的第三方数据 | 资金流向、龙虎榜、融资余额、调研纪要、互动平台答复 | 需与 A 级或其他 B 级交叉 |
| **C（参考/叙事）** | 专业机构观点 | 券商研报、专业媒体深度报道 | 提供叙事素材，不能单独定论 |
| **D（情绪/传播）** | 自媒体与社群内容 | 公众号推文、社群截图、股吧热帖 | **仅作情绪放大器证据**，证实传播路径，不得作为因果证据 |
| **E（待核验）** | 无法溯源的传闻、"小作文" | 盘中流传的收购/数据传闻 | 一律按未经证实处理，直至法定渠道确认 |

降级规则：任一关键结论至少需要 1 个 A/B 级证据支撑；仅有 C/D 级证据时，结论必须标注"原因未完全确认"。

## 2. 归因四步法

### 第一步：时间轴对齐（Timeline Alignment）

将候选催化事件的发生时点与股价启动时点逐一对齐，**时间轴必须精确到分钟级**（至少对异动当日做分时还原；只到日级的归因属于"事后解释"，不足以支撑因果结论）：

- 催化发布时间 **早于** 股价启动 → 可作为驱动候选；
- 催化发布时间 **晚于** 股价启动 → 只能算"流量放大器"，不是第一推动力；**晚于启动的消息只能解释其后的放大段，不能解释启动本身**（例：早盘 09:35 已 +2.42%、午间 12:53 媒体才确认催化 → 早盘上涨须由"公司层预期 + 既有筹码结构先行定价"解释，午间媒体只是确认与放大）；
- 分时证据须覆盖：关键时点（集合竞价、首个异动时点、放量/加速时点、消息发布时点、尾盘）的涨跌幅与量能、大单/主动性买卖方向、**与指数的同步性**（个股独涨 vs 随指数）；
- 确实无法获取分时数据时，归因降级为日级，须在"方法与局限"中明确声明"时间轴仅到日级，盘中归因能力受限"；
- 海外信源以原始平台发布时间戳为准（注意时区换算），不以国内媒体转述时间为准；
- 盘中模式特别地：**无法确认信源是否为当日新增**时，须明确标注"待核验"，并将盘口可直接观测的事实（连板惯性、量价结构）列为优先因子。

### 第二步：反事实检验（Counterfactual Test）

- **板块对比**：同期所属行业/概念指数涨跌幅 → 计算个股相对板块的超额收益；
- **可比公司对比**：3–5 只可比公司同期表现 → 判断"板块共振"还是"个股独立行情"；
- **板块侧判定细则**（见 `analysis-playbook.md` 第 3 节）：所属板块的交易位置（低位预热/启动确认/主升/高位拥挤/退潮修复）、四种热度分级（真主线/次级热点/脉冲题材/跟风分支）、个股在梯队中的位置（龙头/中军/补涨/后排）——板块侧定位决定个股异动的含义与持续性预期；
- 判定规则示例：个股跌幅与板块基本一致 → 板块共振型（主因在板块）；个股显著跑赢/跑输板块 8pct 以上 → 存在个股特异性因子（须找到公司层面证据）。

### 第三步：证据矩阵交叉验证（Cross-Validation）

构建"渠道 × 事实 × 可信度 × 归因支持方向"矩阵（模板见报告框架），逐条检验：

- 各信源之间是否互相印证或矛盾；
- 公告是否排除了某些假说（如异常波动公告"无应披露未披露事项"可排除内幕利好假说）；
- 空头逻辑是否同样有据可查（多空双向都要验证）。

### 第四步：归因分层（主因 / 辅因 / 背景）

将候选因子按因果角色分三层组织，**不再默认输出"40%/25%/20%…"式整数贡献度**——无统计检验支撑的精确数字容易被读者误读为精确归因：

| 层级 | 定义 | 写法要求 |
|---|---|---|
| **主因**（必要且充分） | 剔除后当日异动难以发生；有 A/B 级证据支撑 | 指明传导链条，并说明为何"必要且充分"（用反事实数据佐证：同期板块/可比公司表现） |
| **辅因**（放大幅度与速度） | 决定异动的振幅、速度与持续性，但不构成独立原因 | 逐条说明各自放大了什么（情绪、资金、被动买盘、技术位） |
| **背景**（不是原因） | β 环境、板块底色、估值基数等 | 明确写"不是当日上涨/下跌的原因"，防止读者误读为因果 |

- 每个因子标注：层级、证据等级（A/B/C）、传导链条（事件 → 传播/映射路径 → 股价影响机制）；
- **贡献度百分比降级为可选项**：仅作排序参考时可用，且必须标注"研究判断值，非模型输出"；并注明**若需严格量化，应采用事件窗口 CAR（T-1/T+0/T+1 累计超额收益）+ 板块/可比公司对照 + 分钟级成交集中度，而非整数百分比**；
- 给出"归因判定"：哪些因子是必要条件、哪些决定幅度与速度、哪些仅提供情绪底座/背景。

## 3. 典型归因因子库（按需取用）

| 因子类型 | 识别特征 | 常见证据 |
|---|---|---|
| 海外映射/主题驱动 | 海外竞品/巨头事件 → A股概念普涨，个股因"标签"承接资金 | 板块整体上涨 + 公众号集中传播 + 公司互动平台确认布局；映射真伪与强度判定见 `analysis-playbook.md` 第 2.4 节 |
| 公司基本面事件 | 订单、获批、业绩预告、定增、回购 | 公司公告（A级）；时序先行与事件强度分级见 `analysis-playbook.md` 第 2.3 节 |
| 资金筹码驱动 | 连板惯性、小自由流通盘、游资接力、融资盘 | 龙虎榜、封单/开板数据、融资余额；资金行为性质按 `analysis-playbook.md` 第 4 节区分（趋势布局/事件交易/被动配置/避险）；**表述纪律见 playbook 4.4（禁止"主力净流入=机构买入"式断言）** |
| 板块共振 | 个股与板块同向同幅度 | 板块指数与可比公司数据；板块交易位置与热度分级见 `analysis-playbook.md` 第 3 节 |
| 估值/情绪修复 | 超跌反弹、估值切换叙事 | 估值分位、历史复盘；情绪温度计（连板高度+炸板率+涨停/跌停数+高位股次日溢价）见 `analysis-playbook.md` 第 3.4 节 |
| 政策驱动 | 行业政策、监管动态、贸易政策 | 官方发布；政策增量识别、级别强度与交易阶段判定见 `analysis-playbook.md` 第 2.2 节 |
| 技术面突破 | 趋势线、均线、MACD/RSI、关键位、跳空缺口 | 可计算，但只作辅助因子；放量形态与跳空四型判定见 `analysis-playbook.md` 第 1 节 |

## 4. 多空博弈结构（双向验证）

报告必须同时给出：

- **多头可验证的支点**：技术/基本面/资金面上有数据支撑的逻辑，逐条列出；
- **空头未计价的风险**：阶段错配、盈利未验证、主题依赖、筹码结构、竞争格局等；
- 空头逻辑缺失时须自问："这个结论的证据链是否有 survivorship bias？"——只找涨的理由不找跌的风险是复盘报告最常见的错误。

## 5. "原因未完全确认"的判定规则

出现以下任一情况，归因结论必须标注"原因未完全确认"：

1. 无任何 A/B 级证据指向明确催化；
2. 各信源给出的原因互相矛盾且无法裁决；
3. 仅有 D/E 级（情绪/传闻）证据；
4. 催化时间与股价启动时间无法对齐。

此时报告应：列出已排除的假说、说明缺失的证据类型、给出后续可验证的观察点，**不得强行编造归因**。

## 6. 盘中模式专项规则

1. **不预设结果**：盘中报告严禁"事后诸葛"式确定性表述，用"截至 HH:MM 观测"限定所有结论；
2. **可验证性标签**：每个归因因子标注 可验证性（已发生 / 已公告 / 待核验 / 可计算 / 无新增）；
3. **操作阈值**：给出具体价位/换手率的硬阈值（均价线、前收、关键换手率），而非模糊建议；
4. **情景推演**：给出 3–4 个情景 + 主观概率 + 触发条件 + 应对思路（概率标注为主观研究判断）；
5. **收盘回填约定**：报告须注明"收盘后须用实际收盘价、全日换手、龙虎榜、资金流回填检验午间判断命中率"。

## 7. 情景推演规范（盘后/盘中通用）

- 三个基础情景：乐观 / 中性 / 悲观（盘中可拆为 4 个含具体操作含义的情景）；
- 每个情景给出：触发条件（可盯的具体信号/价位/事件）、含义、应对思路；
- 跟踪周期默认 T+1 至 T+20，覆盖：海外主线、公司管线/业务、资金面、基本面（下份财报）、交易信号五个维度。
