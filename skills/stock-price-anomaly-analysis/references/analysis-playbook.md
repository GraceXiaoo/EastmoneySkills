# 分析判定手册（Analysis Playbook）

> 本手册是异动归因的**判定细则层**：`attribution-method.md` 规定"按什么流程归因"（时间轴对齐 → 反事实检验 → 交叉验证 → 分层归因），本手册回答每个关键环节"**怎么判**"。全篇按投研分析的对象维度组织为四个判定域——**盘面行为**（价格与量能的语言）、**催化剂**（驱动的类型与成色）、**市场结构**（板块、梯队与情绪环境）、**资金行为**（性质、背离与能力边界）——并以**论证纪律**与**输出纪律**收束。各判定域相互独立、按需取用：归因拆解时按本次异动涉及的维度加载对应小节，无需全篇常驻。

## 0. 结构总览（按分析对象定位）

| 判定域 | 回答的问题 | 主要服务环节 |
|---|---|---|
| §1 盘面行为判定 | 这是不是真异动？量价结构说了什么 | 模块二 异动画像 |
| §2 催化剂判定 | 驱动属于哪一类？成色与可持续性如何 | 模块三 归因拆解 |
| §3 市场结构判定 | 个股处在什么板块位置、梯队与情绪环境 | 模块三 辅因定位 / 模块七 持续性校准 |
| §4 资金行为判定 | 资金在做什么？哪些能说、哪些不能说 | 模块三 资金因子 / 模块六 多空博弈 |
| §5 论证纪律 | 统计与历史对照类论断的红线 | 全文通用 |
| §6 输出纪律 | HTML 报告交付的强制红线 | 第五步 产出报告 |

## 1. 盘面行为判定：价格与量能的语言

### 1.1 异动确认：先确认"偏离常态"

分析放量类异动前，先量化确认这是不是真异动：

- 成交额/成交量 vs 近阶段常态水平（量比 ≥ 2 或明显抬升为有效信号）；
- 换手率是否同步显著变化；
- 量能集中时段：开盘（隔夜信息定价）/ 尾盘（资金抢筹或出货）/ 中段（盘中消息驱动）。

### 1.2 放量质量：形态与量价配合

- **放量形态**：**持续型**（多时段连续放大，信息含量高）还是**脉冲型**（单一时点冲击，可能是程序交易/期权对冲，与基本面无关）；
- **量价配合**：价格是否顺放量方向推进。放量+大涨（顺向）> 放量+滞涨（分歧）；**"只放量不走价"通常是分歧信号**——高位尤甚；
- 放量后带来**结构重估**（估值锚切换）还是**一天脉冲**（回吐风险）；
- 当前市场环境是否支持延续（结合 §3.5 市场环境四档）。

### 1.3 位置含义：同一形态在不同位置意义相反

| 位置 | 放量含义 |
|---|---|
| 低位放量 | 吸筹 / 启动信号 |
| 高位放量 | 可能出货（**不能把所有放量都等同于利好**） |
| 突破放量 | 有效突破信号 |
| 冲高回落放量 | 诱多 / 兑现 |
| 下跌放量 | 恐慌 / 趋势加速 |

### 1.4 跳空归因四型

| 类型 | 特征 | 判定 |
|---|---|---|
| 事件驱动型 | 扎实催化（公告/政策/订单） | 跳空相对可持续 |
| 情绪强化型 | 市场过度反应、缺硬催化 | 跳空易回补 |
| 补涨补跌型 | 相对强弱调整（同板块已先行） | 跳空有结构意义 |
| 技术位置触发型 | 止损踩踏 / 多头止盈 | 观察关键位得失 |

**避坑**：历史统计上大部分跳空缺口在数周内被回补——缺口本身不是趋势证据。

### 1.5 次日验证四问（放量/跳空通用的次日检验）

次日是否承接、关键位置是否站稳、题材热度是否延续、成交回落后价格是否维持强势。这四问直接对应报告的"后续跟踪清单"。

## 2. 催化剂判定：驱动的类型与成色

### 2.1 驱动排查框架（先定类型，再查成色）

| 驱动类型 | 识别特征 | 对应归因因子（`attribution-method.md` 因子库） |
|---|---|---|
| 事件驱动 | 公告 / 新闻 / 政策 / 财报 / 产品 / 订单 | 公司基本面事件、政策驱动 |
| 板块驱动 | 同行集体异动 / 题材发酵 / 龙头带动 | 板块共振、海外映射 |
| 技术驱动 | 关键位突破 / 跌破 / 止损踩踏 | 技术面突破（辅助因子） |
| 资金驱动 | 情绪抢筹 / 游资接力 / 博弈换手 | 资金筹码驱动 |

### 2.2 政策类判定细则

政策作为候选催化时，按以下顺序拆，**不复述政策原文，抓增量**：

**（1）政策"增量"识别（真增量决定交易价值）**

依次检查：是否**首次提出的新口径** / 是否**强度提升**（鼓励→强制）/ 是否**范围扩大** / 是否**执行工具明确**（财政补贴、税收、专项贷款、采购支持、准入放松）。四者皆否 = 旧口径重复，交易价值有限。

**（2）政策级别与执行强度**

顶层文件（国务院/中央）力度大但执行慢；部委政策相对落地快；地方试点覆盖面有限（**全国推广存在不确定性，不能简单放大**）；监管指导/协会倡议约束力弱。配套工具是否明确决定真实力度——**"产业鼓励"与"产业补贴"力度完全不同**。

**（3）受益链条与标的分层**

直接受益（政策直接作用的产业/企业）→ 间接受益（需求扩散/资本开支/订单外溢）→ 概念映射（市场愿意交易但业绩关联弱）。标的分核心受益龙头 / 容量中军 / 高弹性小票 / 概念映射标的——**必须讲清"为什么这家公司在这政策下最受益"，不能把所有相关公司都定义为受益股**。

**（4）市场交易阶段（政策已走到哪一步）**

催化初期（可参与）→ 已提前预期（**兑现风险，政策预期常在发布前就被定价**）→ 利好兑现中（边走边看）→ 等待实施细则（观望）。政策价值与政策热度可能背离——脱离市场位置判断就是追高。

**（5）双向评估**

监管政策同时有受益方和受损方——归因时必须双向评估；**非正式表述（新闻吹风）不算政策出台**。

### 2.3 公司事件类判定细则

**（1）时序先行判定**：公告/事件发布前，股价是否已提前反应（前日尾盘抢筹、集合竞价跳空、盘前放量）——提前反应提示预期抢跑或信息提前泄露，事件落地时警惕"利好兑现/利空出尽"（事件催化常在发布前已被定价）。

**（2）事件强度分级**：硬事件（订单金额、获批、业绩预告超预期等**可量化口径**）可作主因候选；软事件（表态、合作框架、调研纪要、战略合作等**无量化口径**）通常只能作辅因，须标注证据等级。

**（3）可持续性判定**：事件是否改变收入/利润口径（结构重估）还是单日情绪（一天脉冲）——前者看下一份财报验证，后者回吐风险高。

**（4）排除性检验**：异常波动公告"无应披露未披露事项"可排除内幕利好假说（进入证据矩阵，见 `attribution-method.md` 第三步）。

### 2.4 海外映射/主题类判定细则

**（1）传导链条**：海外原始事件（以原始平台时间戳为准，注意时滞与隔夜定价）→ A股标签映射 → 板块普涨 → 个股承接资金。

**（2）映射真伪**：公司互动平台/公告确认实际业务关联 = 真映射（可入归因）；纯概念标签、无可验证业务口径 = 弱映射（易退潮，通常只作辅因/背景）。

**（3）强度佐证**：板块内部分化度与扩散方向反映映射强度——龙头明确且扩散有序为强映射；普涨一日即分化为弱映射。公众号/社群集中传播仅作 D 级情绪佐证，证实传播路径而非因果。

## 3. 市场结构判定：个股异动的环境坐标

### 3.1 板块共振 vs 个股独立（反事实检验的判定细则）

判定个股异动属于板块共振还是独立行情时，对板块做四维横向比较（不是把板块单独写一遍）：

- **核心逻辑**：板块当下市场为什么买、未来靠什么继续涨；
- **交易位置**：低位预热 / 启动确认 / 主升演绎 / 高位拥挤 / 退潮修复——同样的逻辑在不同位置性价比完全不同；
- **催化强度**：硬催化（业绩/政策/订单）vs 软催化（情绪/海外映射）；哪个方向催化更连续、更容易扩散；
- **拥挤度**：逻辑好但过度拥挤的板块短期风险反而大。

个股归因结论中须写明：所属板块处于什么交易位置、本次异动是跟随还是引领。

### 3.2 四种热度分级（判断题材是哪种）

真主线（连续性强、龙头明确、扩散清晰）/ 次级热点（当日强势但持续性待验证）/ 脉冲题材（一日游、缺乏龙头）/ 跟风分支（主线带动、独立性弱）。**一日脉冲 ≠ 主线，不要把所有涨停都说成机会**。

### 3.3 梯队识别

龙头 / 中军 / 补涨 / 后排——个股在梯队中的位置决定其异动的含义（龙头异动=题材信号；后排异动=扩散后期信号）。**新老龙头切换时分歧最大**。

### 3.4 情绪周期与温度计

情绪周期五阶段：冰点 / 修复 / 主升 / 高位震荡 / 退潮。

**情绪温度计**（量化组合，不用形容词）：连板高度 + 炸板率 + 涨停数 + 跌停数 + 高位股次日溢价。情绪周期判断必须给出这些证据，不能只用形容词。

### 3.5 市场环境四档

强势（进攻）/ 震荡（精选）/ 弱势（控制）/ 退潮（观望）——看指数强弱、涨跌家数、成交额、情绪股表现。个股异动的持续性预期必须放在对应的市场环境里校准。

## 4. 资金行为判定

### 4.1 不孤立看单日

**单日资金数据无法改变配置判断**。必须检视：连续性（连续多日同向？）、集中度（抱团权重龙头 vs 分散流入）、与指数/情绪的共振。区分"单日信号"（多数是噪音）与"阶段信号"（才有配置意义）。

### 4.2 四种资金行为性质

| 性质 | 特征 | 归因含义 |
|---|---|---|
| 趋势性布局 | 连续多日同向、分布广泛 | 配置信号，支撑趋势归因 |
| 事件性交易 | 聚焦特定标的/板块、伴随消息 | 事件驱动的资金证据 |
| 被动配置 | 指数扩容 / 调样 / ETF 申赎 | **"净流入"≠利好**，剔除后再看真实资金 |
| 短期避险 | 风险事件期间回流 | 扰动，不改变结构判断 |

### 4.3 资金流与价格背离 = 反向信号

流入但股价跌 / 流出但股价涨——须在报告中明确指出并追问哪边更值得相信。这是多空博弈模块的重要素材。

### 4.4 能力边界与表述纪律（强制）

- 主力资金流（大单/中单/小单拆分）是**算法分类，不是真实账户身份**——无法识别公募、私募、游资、量化、通道账户。参考意义有限，只作方向参考不作精确证据；
- **表述红线**：禁止把"主力净流入"写成"机构买入""机构积极介入""机构建仓"等账户身份断言；正确写法是"大单/超大单净买入占优"；
- 涉及资金推动的归因，报告须包含固定声明：**"本报告的'资金推动'指大单主导的边际定价，不等同于机构共识形成"**；
- 资金流与价格的**背离信号（如融资净流出但股价上涨、散户净流出但股价大涨）不得删除或弱化**，应作为"短线情绪驱动"的证据正面呈现，并列入多空博弈与跟踪清单；
- 外资偏好在风格切换时反转极快，警惕拐点信号；资金偏好不直接等于基本面支持，需结合盈利验证。

## 5. 论证纪律：统计与历史对照类论断的红线

涉及"历史上同类异动的后续表现"（缺口回补率、放量后次日承接率、板块轮动规律）等统计性论断时：

1. **用数据计算，不用记忆编数**——历史统计必须基于实际取数或注明出处，禁止凭印象给出"历史数据表明…"；
2. **样本纪律**：说明样本区间与样本量；样本不足 5 个标的/时段的统计不得作为论断依据；
3. **前向口径**：统计"异动后表现"时，收益必须从异动确认日之后起算（防前向偏差/事后诸葛）；
4. **不做样本外过度推断**：历史规律给概率提示，不给确定性预测；回测规律在实盘会被滑点、成本、择股偏差侵蚀；
5. **警惕幸存者偏差**：复盘"涨了的票"时主动寻找同期同类但没涨/跌了的反例（与多空双向验证呼应）。

## 6. 输出纪律：HTML 报告交付（强制红线）

> 完整规范见各模板注释，此处为强制红线。本节适用于在本技能两个模板基础上**新增图表**的场景。

1. **交付前 JS 语法自检（最高优先级）**：HTML 内含手写内联 `<script>`（尤其 ECharts option）时，交付前必须把 script 体抽出存为 .js 用 `node --check` 校验（或等价方式），改到通过为止。**一处括号/引号失配 = 全页图表空白**。没有 node 时人工逐个 `setOption({...})` 数括号配平，重点查箭头函数 `=>({...})` 和多层 `series:[{...}]`；
2. **套骨架不手敲**：复杂图（多图/双轴/K线/雷达）优先套用已验证的 option 骨架只替换 data，不从空白手写嵌套结构；ECharts 用 CDN 引入 `<head>`；
3. **图表分工**：有数值轴的数据图（趋势/对比/占比/分布）用 ECharts，不堆长串趋势型表格；产业链图谱/传导链/关系拓扑用 SVG 或 HTML+CSS 盒子（不依赖 JS，天然规避括号失配）；查阅/多维对照型数据仍用表格；
4. **双轴量级**：同一图里量级差很大的两个序列不共用一根轴（小的会被压成贴地条），用双轴或把小序列改折线；
5. **空值不入图**：完全无数据的区间不硬塞占位，让 x 轴从有数据处起；做同比/环比趋势时优先多取一个完整周期消除前段空值；
6. **图/表可切换**：数字密集的趋势数据块做"图/表切换"（默认看图、一键切表查精确值）；
7. **每图必配解读**：任何图表（ECharts/SVG）必须紧跟文字解读——读什么、说明什么、对归因的支持/削弱；禁止交付无解读的裸图。投研读者要的是"可证伪、可跟踪、可决策"，不是页面炫技：装饰性元素（渐变头图、KPI 卡片、tag 配色）为内容服务，能减则减；
8. **整体风格**：浅底深字研报风、首屏结论先行、A股口径红涨绿跌——与现有模板一致，新增区块不得破坏。
