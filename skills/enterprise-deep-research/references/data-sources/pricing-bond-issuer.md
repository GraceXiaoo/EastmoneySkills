# 定价分析（债券发行人）数据源

仅非城投且发债人标记为 true 时使用。状态：债券类型下拉框、样本关系及样本估值已返回数据；完整拟合曲线链路、发行人行情及宏观背景未完成验证。见 [MQL核验记录](mql-verification.json)。

## MQL 数据集与真实依赖

| 数据集 | 函数 | 本轮核对结果 |
|---|---|---|
| pricing_issuer_bond_types | RPT_BOND_ISSUERCURVE_LIKEBOND | 只返回东财债券分类2021、东财债券分类编码2021，不能当作样本券明细 |
| pricing_issuer_curve / 样本关系 | RPT_CUSTOM_BOND_ISSUERCURVE_LIKEBOND | 返回样本券代码、样本券类型；需要原始发行人代码和定价日 |
| pricing_issuer_curve / 样本估值 | RPT_BOND_ISSUERCURVE_VALUE | 以样本券代码、对应类型、交易日期取剩余期限(中债)、中债估值(推荐)等 |
| pricing_issuer_curve / 市场补点 | RPT_BOND_ISSUERCURVE_FULLMARKET | 以定价日取剩余期限、平均收益率、样本类型编码 |
| pricing_issuer_curve / 拟合 | RPT_BOND_ISSUERCURVE | 入参是期限、收益率、样本类型序列；仅返回期限和收益率，不含发行人行情 |
| pricing_market_context | 待定的独立 MQL 指标/报表 | DR007、R007、OMO、MLF、周/月净投放 |
| 发行人行情子集 | 尚未确认承载表 | 1/7/30/90 日成交笔数、成交量、偏离和利差等统计 |

## 已验证的债券类型下拉框

```mql
ReportBlock(#1, {Choice报表\报表指标\Choice金融终端\企业F9\发行人曲线\条件筛选-债券类型下拉框\条件筛选-债券类型下拉框|RPT_BOND_ISSUERCURVE_LIKEBOND});
SetCodes(["<ORG_CODE>.FXR"]);
SetReportFilter(({到期日} >= "<定价日 YYYY-MM-DD>") AND ({样本类型编码} == "1"));
{东财债券分类2021}: REPORT_FIELD("东财债券分类2021");
{东财债券分类编码2021}: REPORT_FIELD("东财债券分类编码2021");

OutputBlock();
```

按类型编码去重形成 `type_options`。此报表元数据没有 `ORG_CODE` 加载过滤列，也没有债券代码、余额或到期日期返回列；MQL 用发行人标准代码，不得将 REST 明细字段硬塞进该报表。

## 曲线链路

必须按以下依赖顺序执行，不得跳过上游并构造假样本：

1. 样本关系：正式业务路径仍为 `Choice报表\报表指标\Choice金融终端\企业F9\发行人曲线\样本券对应关系\发行人曲线_样本券`，函数 `RPT_CUSTOM_BOND_ISSUERCURVE_LIKEBOND`。本轮成功绑定使用末尾 ID `|873037266287012`；加载 `原始发行人代码=<ORG_CODE>.FXR`、`定价日`，不另加 `SetCodes`。模板 `curve_samples` 用民生银行 2026-09-18 返回 19 组样本券代码及样本类型。保留历史失败证据，不再据此判定本路径当前不可用。
2. 样本估值：完整路径 `Choice报表\报表指标\Choice金融终端\企业F9\发行人曲线\条件筛选-债券列表\发行人曲线_相似债_估值|025324135305196`，函数 `RPT_BOND_ISSUERCURVE_VALUE`。`SetCodes` 使用上一步样本券代码，`交易日期` 对应 TradeDate，`通用类型1` 对应 Type1。将代码与类型作为成对记录去重并按代码排序，类型串必须逐券逐项对应，不能只传去重后的 `1,2`：这种错误也可能执行成功，但类型会错配。模板 `curve_valuation` 已执行返回 19 行、19 列，逐券比对类型零错配；两券期限/收益率为空，不能补值用于拟合。完整样例见 [固定模板](mql-templates.md)。
3. 全市场补点：路径 `Choice报表\报表指标\Choice金融终端\企业F9\发行人曲线\全市场明细(页面不展示但需要调用将其结果作为入参)\发行人曲线_全市场明细|RPT_BOND_ISSUERCURVE_FULLMARKET`，加载 `定价日`。本轮报“报表字段返回值不是字符串：剩余期限”，属于元数据/返回类型不一致。
4. 拟合：路径 `Choice报表\报表指标\Choice金融终端\企业F9\发行人曲线\拟合曲线\发行人曲线|RPT_BOND_ISSUERCURVE`。Term/`期限`、Yield/`收益率` 来自样本估值与市场补点，Type1/`通用类型1` 对应同顺序样本类型；元数据说明要求逗号拼接序列，但 Term/Yield 声明为 double，序列绑定方式尚待验证。不接受直接按 ORG_CODE 查询曲线。
5. 所有样本时点一致后才可拟合；保留实际定价日、期限和收益率单位，按期限排序。不得用固定期限点、其它板块存续债清单或资讯收益率冒充拟合结果。

## 行情与市场背景

发行人行情另找承载报表：经纪商成交笔数、CFETS/交易所成交量、成交天数、平均偏离、最大负偏/正偏及日期、平均/最大/最小利差及日期；保留 1/7/30/90 日窗口和实际单位。拟合报表不提供这些字段。

宏观背景单独核对 DR007、R007 及两者利差、7 天 OMO 净投放、6 个月 MLF 操作量、1 年 MLF 到期量、全周和当月累计净投放。当前未通过完整验证；不得填入示例值，也不得从其它板块混传。

## 发行人监控图表

债券发行人定价分析正文后可生成“图表N 发行人监控”统计表。该图表只取本板块独立 MQL 数据包中的发行人行情监控统计，按统计窗口（如 1/7/30/90 日）及实际返回指标列示成交笔数、CFETS/交易所成交量、成交天数、平均/最大偏离和利差等指标，并保留相应日期和单位。当前发行人行情监控数据的承载表尚未确认，`pricing_issuer_curve` 拟合结果也不提供这些监控字段；因此在实际 MQL 监控数据源及字段未确认、未返回前，不生成该表，不能用拟合期限收益率、债券明细或资讯填充。

## 整理与 Python 兜底

脚本固定模板键 `curve_types`、`curve_samples`、`curve_valuation` 已验证可用。`curve_fullmarket` 因“剩余期限”返回类型与元数据不一致而失败；拟合多点参数及发行人行情监控承载报表尚未验证，不能把样本估值通过当作整条曲线或监控表通过。

各子集只进入当前板块独立数据包、分别登记来源。正式 MQL 路径失败后先尝试已登记或动态发现的同业务 MQL 候选；全部候选失败后，Python 也必须满足同一上游依赖和定价日要求。旧 `RPT_BOND_ISSUERCURVE + ORG_CODE` 直连模板撤销，本地脚本在上游未就绪时返回明确阻塞状态，不发送无效拟合请求。债券类型的 REST 明细若可取得，必须保留其真实来源和参数，不能把该明细结构反推成 MQL 下拉框结构。

当前不把下拉框单步通过算作定价模块通过。缺失曲线、行情或宏观字段逐项记录，不补造。
