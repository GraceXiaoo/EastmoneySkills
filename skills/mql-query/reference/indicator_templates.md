# MQL 指标 / 板块 / 报表 / EDB / 脚本 模板库

> **本文件是「MQL问数」Skill 的权威模板库**，登记"已验证可用"的指标路径、板块路径、报表、EDB 引用与成段脚本，供后续任务**优先复用、跳过全量检索**。
>
> **使用边界（与 G2 协调）**：模板库提供"候选路径与已知兼容性"，**不是本次任务的查询结果**。命中模板后仍须做一次**收窄的存在性校验**（见 SKILL.md 模板使用门禁），确认路径在当次运行时仍有效；校验失败则重新检索并回填本库，同时把旧条目标记为 `已废弃`。
>
> **硬性纪律**：
> 1. 路径必须**逐字完整**（含括号、来源说明、`|指标ID`），禁止按语义重写或照抄 JSON 中的转义双反斜杠（路径边界只用一个实际反斜杠 `\`）。
> 2. **禁止登记任何具体结论数值**（如"某指数周跌 1.51%"）；只登记路径、元数据、参数与脚本。
> 3. 验证状态必须三值之一：`已执行验证` / `已确认路径未验证` / `已废弃`。
> 4. 每条须带：用途、完整路径、返回形态、值类型与单位、参数名与枚举、适用 Block、验证状态、验证日期、验证用例。

## 维护机制

1. **每条模板必须带"首次验证日期 + 验证用例（标的、日期、返回值形态快照）"**，便于后续复核；验证用例只记录返回形态与字段，不记录具体结论数值。
2. **每季度复核一次**：失效条目移入 `已废弃` 并注明替代路径；长期未用条目降级标注，避免"看似可用实则过时"。
3. **新增条目必须先真实执行成功**（Execute_MQL 返回 ok=true）才可标记为 `已执行验证`；仅检索确认路径但未跑通的，标记为 `已确认路径未验证`。
4. **本库只登记路径、元数据与脚本**，禁止登记任何具体结论数值（如涨跌幅、价格、市值的历史值），防止被误当默认答案复用。

### 1.1 财务报表与财务分析指标（一般企业口径）

> 同一只财务指标存在**两种形态**，路径不同、适用 Block 不同，不得混用：
