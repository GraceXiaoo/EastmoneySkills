# MQL 标准模板索引（导航速查）

> 所有模板已抽取为独立 .mql 文件，位于 `mql/` 目录下，按证券种类分类。
> 每个 .mql 头部含结构化注释（@标签），代码内含行内正例/反例注释。
> 模板含教学注释，MQL 支持 `//`/`/* */` 可保留执行（注释权威说明见 [syntax.md §1.2](syntax.md)），模板可原样复制。
> 本表**只做导航**：按问句模式定位该打开哪个 .mql。定位后直接打开对应文件，其 `@pattern/@replace/@must/@note` 标签与行内 `✅/❌` 已自给自足，无需回读本表。
> 全部路径仍须以当次 Search_Context 返回为准（G2）。

## 模式速查表

| 问句模式 | 打开文件 | 关键判据 |
|---|---|---|
| 单证券截面单值（茅台前收盘价 / 最新涨跌幅） | `mql/股/个股行情/贵州茅台_前收盘价.mql` | CrossSection 单实体；指标带 `()`；用 `:` 才输出 |
| 板块池排序截前（A 股涨幅 Top10 / 市盈率最低 20） | `mql/股/TopN排序/全部A股_涨跌幅Top10.mql` | GetSectors + Sort + Head；数值刻度以指标 `unit` 为准 |
| 按分类字段分组聚合（按上市地点 / 行业统计只数或均值） | `mql/股/分组聚合/按上市地点统计股票只数.mql` | 上游 `:` 输出分组键 → 下游 GroupBlock 聚合 |
| 时序窗口 + 时序函数（收盘价与 5 日均线 / 区间最高） | `mql/股/时序行情/贵州茅台_收盘价与5日均线.mql` | 需 EM_DATE 轴或 MA 等；是否时序只看 `indicatorTimeShape` |
| 报表明细 + 补指标列（限售解禁 + 前收盘价） | `mql/股/报表明细/贵州茅台_限售解禁_Merge补列.mql` | Report → CrossSection 补列 → Merge；SetReportFilter 只认加载列 |
| 报表分组后补列（按证券汇总 + 补简称） | `mql/股/报表明细/贵州茅台_限售解禁_Group后Merge简称.mql` | Report → Group 唯一右键 → CrossSection → Merge |
| 债券板块 TopN（国债到期收益率 Top10） | `mql/债/行情指标/国债_到期收益率Top10.mql` | 债券 EM_CODE 纯数字无后缀；排前先 `NOT IS_NULL` |
| 少量固定报告期宽表（一季报 + 中报各一列） | `mql/股/财务指标/贵州茅台_多报告期归母净利润_宽表.mql` | CrossSection 多期多列；无 EM_DATE，不能用时序函数 |
| 连续报告期长表（2024Q1~2025 年报逐行） | `mql/股/财务指标/贵州茅台_多报告期归母净利润_长表.mql` | ReportBlock 一期一行；无时序函数 |
| 财务时序需 EM_DATE 轴（近三年单季度营业收入） | `mql/股/财务指标/东方财富_近三年单季度营业收入_时序.mql` | `time_series`、`_s` 后缀；SetWindow 用"季"，不写市场类型 |
| 一般企业三大报表 / 每股 / 比率年度时序 | `mql/股/财务指标/比亚迪_近两年{资产负债表\|利润表\|现金流量表\|每股指标与财务比率}时序.mql` | K/L/M/N；前缀 `Choice指标\序列函数\...\一般企业`；周期"年" |
| 主营构成按产品/行业/地区（A股/港股/美股） | `mql/股/财务指标/比亚迪主营构成_按产品_按行业_按地区.mql`（A股）· `腾讯控股主营构成_按产品_按地区.mql`（港股）· `AAPL苹果主营构成_按产品_按地区.mql`（美股） | ReportBlock；**三市场结构不同**：A股单报表+分布类型返回中文词（产品/行业/地区）+无加载列用本地 FILTER_ROWS；港股单报表+分布类型为码值（1产品/2地区）+有加载列用 SetReportFilter 远端过滤；美股按产品/地区是**两张独立报表**、无分布类型列靠换报表。报告期类型含正常报告期与单季度两套行须剔除，否则行数翻倍。详见 `indicator_templates.md` §6 与 `traps.md` 陷阱 18/19 |
