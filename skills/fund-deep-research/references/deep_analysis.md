场外基金一页纸 深度分析方法

用途

本文件用于约束单只场外公募基金研究的分析深度。它解决“章节齐全但只复述数据”的问题，不规定固定结论，也不要求为凑字数扩写。仅在结构化取数和资讯检索完成后读取，与写作规范共同使用。

一、总原则

1. 报告不是数据摘要。每个结论必须回答“发生了什么、为什么重要、可能由什么驱动、风险边界在哪里”。
2. 只围绕目标基金形成判断。引用基准、宽基和同类仅用于建立相对位置，不扩展为其他基金研究。
3. 先完成章节事实卡和交叉分析，再写正文。禁止一边浏览原始数据一边直接拼接段落。
4. 字数规定是上限，不是压缩目标。数据充分时应写到结论成立所需的完整程度；数据不足时缩短或删除，不用泛化语言补足篇幅。
5. 区分事实、解释和推断：
   - 事实：由结构化数据或完全匹配目标基金的公开资讯直接支持。
   - 解释：由多个事实共同支持的合理归因，应使用“主要反映”“可能与……有关”等审慎表达。
   - 推断：涉及未来资金、行情或产业变化时，必须说明条件和不确定性，不写成既定事实。

二、写作前的章节事实卡

每个拟保留章节先生成内部事实卡，事实卡只用于写作，不进入最终报告。至少包含：

1. 核心事实：本章节最重要的3至8个数据或事件。
2. 时间变化：起点、终点、峰值、低点、拐点及变化幅度。
3. 相对位置：相对业绩基准、宽基、同类或自身历史区间的位置。
4. 异常与矛盾：例如收益领先但夏普偏低、规模增长但份额变化有限、短期流入但中期仍流出。
5. 驱动假设：能够被持仓、行业、资金、市场或管理人观点支持的原因。
6. 风险含义：该事实可能放大的波动、回撤、流动性或策略失效风险。
7. 后续验证：未来最值得跟踪的1至3个指标或条件。
8. 数据边界：哪些结论不能由当前数据确认，正文不得越界推断。

若事实卡不足以支持至少“事实＋比较＋解释”三层分析，则该章节缩短为事实说明或直接删除。

三、单章节深度分析链

核心章节原则上按照以下六层链条组织。不是每层都必须单独成段，但不得只停留在第一层。

第一层 数据事实

明确时间、口径、数值和方向，指出最重要的变化，不机械罗列全部指标。

第二层 历史位置

判断当前状态处于自身历史的高位、低位、恢复期、恶化期还是拐点附近。长序列优先识别峰值、低点、持续时间和变化速度。

第三层 相对比较

与口径一致的业绩基准、宽基或同类比较，说明领先或落后的幅度、稳定性和代价。禁止只写排名而不解释排名代表的产品特征。

第四层 驱动拆解

结合资产配置、行业、重仓、风格、资金行为和管理人观点解释可能来源。驱动至少由两个相互独立的数据证据支持；证据不足时不得强行归因。

第五层 风险与边界

说明优势在哪种市场环境下成立，在哪些条件下可能失效。高收益必须同时检查波动、回撤、Beta、集中度和资金稳定性；低回撤必须检查是否以低仓位或风格错配为代价。

第六层 后续观察

提出可验证的观察项，例如资本开支、订单兑现、行业权重变化、超额回报恢复、资金方向转正或回撤收敛。不做无条件预测。

四、跨章节交叉验证

完成各章节事实卡后，至少执行以下六组交叉检查。存在数据时必须检查，不要求每组都在正文单独列标题。

1. 收益与持仓
   - 阶段收益是否与主要行业、重仓股和资产仓位变化一致。
   - 收益是来自广泛持仓贡献，还是少数行业和个股集中驱动。

2. 收益与风险
   - 超额收益是否伴随更高Beta、波动率和最大回撤。
   - 夏普、Calmar、胜率与绝对收益是否给出一致结论。

3. 超额与市场环境
   - 超额在哪些月份或市场阶段加速、停滞或回撤。
   - 信息比率变化是持续改善还是由少数强势阶段集中贡献。

4. 规模与业绩
   - 规模变化由份额申赎还是单位净值变化驱动。
   - 规模扩张发生在上涨前、上涨中还是上涨后，是否存在追涨特征。

5. 资金与净值
   - 大涨、大跌与净申购、赎回压力是否同步。
   - 短期流入是否与30日、90日方向一致，避免把短期修复写成趋势反转。

6. 持仓与市场展望
   - 市场催化是否真正作用于主要持仓和行业暴露。
   - 风险因素是否能通过集中度、估值、订单、汇率、久期或信用路径传导到基金净值。

若不同指标出现冲突，不得选择性忽略。正文应明确写出“优势与代价并存”的结构，并解释冲突可能来自时间区间、统计口径或市场阶段差异。

五、各章节的最低分析要求

1. 核心投资逻辑

全文完成后提炼。至少包含产品定位、主要收益来源、差异化特征和风险边界。结论必须能由后文章节共同支持，禁止使用正文未论证的新观点。

2. 基金概况与管理人

不只写履历和公司规模。应判断经理管理连续性、研究经历与当前持仓风格是否匹配；公司资源只能作为能力基础，不直接推导基金未来业绩。

3. 规模与份额

至少区分净值增长和份额变化对规模的贡献。数据期数充分时分析扩张、缩水、拐点和持续性；期数不足时明确仅能判断区间变化，不扩展为长期趋势。

4. 业绩表现

至少使用三个不同期限或三个历史阶段，分析收益路径而不是只写期末回报。必须包含一项相对基准或同类比较，并说明近期变化是否改变中长期结论。

5. 超额回报

分析超额的规模、持续时间、波动和回撤。信息比率或超额曲线应识别加速期、峰值、回落和修复，不得只引用最新值。

6. 风险收益

至少联合解释收益、波动、最大回撤及一项风险调整指标。数据存在时进一步结合Alpha、Beta、上下行捕获和胜率，判断收益来源及回撤控制能力。禁止用单一夏普或单一回撤给出整体评价。

7. 资金行为与流动性

分别判断短期、中期和历史分位。分析净值变化与申赎行为是否同步，说明资金是追涨、逆势流入还是趋势撤离。估算指标只能写成压力信号，不写成确定的未来赎回金额。

8. 投资组合

从资产仓位、前十大集中度、行业集中度和产业链位置四个层面分析。重仓股不能逐只复述，应归纳共同产业逻辑、收益传导路径和共振风险。存在历史持仓时必须说明增减持方向及风格变化。

9. 同类比较

至少覆盖收益、风险、风险调整收益和规模四个维度。排名必须转换为产品特征，说明领先是否以更高波动和回撤为代价，以及适配何种风险预算和配置角色。

10. 投资价值与市场展望

使用“持仓暴露—产业变量—传导路径—潜在催化—失效条件”的结构。资讯必须完全匹配目标基金或其管理人公开观点。行业观点只有能够作用于基金实际持仓时才能进入正文。

六、长序列分析方法

对日频、周频或月频长序列，不把全部原始行送入写作上下文。先在本地计算并形成摘要：

1. 最新值、期初值、区间变化。
2. 最大值、最小值及日期。
3. 主要拐点和连续上升、下降区间。
4. 月末或周末抽样序列。
5. 大涨、大跌、净流入和赎回压力异常日。
6. 与基准、资金或回撤序列的同步和背离。

正文只引用能改变判断的节点，完整原始数据进入公开溯源，不重复占用写作上下文。

七、证据密度与篇幅控制

1. 核心章节每个主要判断原则上至少有两个数据证据，其中一个应体现时间变化、相对比较或历史位置。
2. 一段通常围绕一个中心结论展开，包含2至5个关键数据；禁止连续堆砌无解释指标。
3. 数据充分时，核心章节正文不得只有一句图表复述。建议范围：
   - 业绩、风险、同类比较：180至350字。
   - 资金行为、规模、组合总览：150至300字。
   - 投资价值与市场展望：300至600字。
4. 建议范围不是凑字数要求。若新增文字不能增加事实、关系、解释或边界，应删除。
5. 图表负责展示趋势和结构，正文负责解释原因、比较和含义。正文不得逐项朗读图表。

八、专属化检查

交付前逐章检查：

1. 将基金名称替换成另一只基金后，段落是否仍然成立。若成立，说明内容过于模板化，必须重写。
2. 是否至少引用了目标基金专属的期限、持仓、行业、风险或资金数据。
3. 是否解释了该基金与同类产品相比最突出的优势和代价。
4. 是否说明了结论成立的市场条件和可能失效的条件。
5. 是否存在没有证据支持的“前瞻布局”“精准把握”“风险可控”“机构认可”等评价。存在则删除或补充证据。

九、交付验收门槛

任一核心章节出现以下情况时，退回重写：

1. 只有数据复述，没有历史位置、比较或解释。
2. 只有方向判断，没有具体时间和数值证据。
3. 结论可无差别套用于多数基金。
4. 收益分析未同时讨论风险代价。
5. 市场展望未与实际持仓建立传导关系。
6. 指标相互冲突但正文未解释。
7. 使用数据中不存在的事实或把估算写成确定事实。
8. 图表与正文表达相同信息，正文没有提供新增判断。

十、执行顺序

1. 完成基金分类、条件判断和结构化取数。
2. 对长序列执行本地压缩和异常点识别。
3. 为拟保留章节生成内部事实卡。
4. 执行跨章节交叉验证，标记一致、冲突和不可确认项。
5. 先写各章节正文，再写核心投资逻辑和投资价值总结。
6. 执行专属化检查、证据检查和风险边界检查。
7. 通过后再进入图表、排版和多格式交付阶段。

本方法的目标不是把报告写得更长，而是让每一段都包含更高的证据密度、基金专属性和可验证的分析关系。
