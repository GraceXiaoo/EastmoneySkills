# 章节 1 催化事件时间表 · 事件库取数规范（`mx_api_invoke` 通道）

> 本文件定义章节 1「公司近况跟踪」中**催化事件时间表**的两个专用取值来源：**已发生事件库**与**未来事件库**。
> 章节 1 的近况文字段仍由资讯检索场景 `1` 供数（见 [资讯检索-取数规范.md](资讯检索-取数规范.md)）；
> 事件库通道**只服务催化事件时间表**，不服务任何文字段。
> 事件筛选标准、合规用词、零幻觉原则与 `prompts/01-公司近况跟踪.md`、`资讯检索-取数规范.md` §8 完全一致，本文件不放宽。

## 1. 接口清单

| 通道（业务名） | apiId（接口英文标识） | 接口中文名 | 接口英文名 | 调用方式 |
|---|---|---|---|---|
| 已发生事件库 | `newsEventSearch` | 事件大全搜索 | News Event Search | `mx_api_invoke(apiId=newsEventSearch)` |
| 未来事件库 | `futureEventSearch` | 未来行动事件搜索 | Future Event Search V2 | `mx_api_invoke(apiId=futureEventSearch)` |

> 本表与 `SKILL.md` 通道表、[数据通道与来源对应.md](数据通道与来源对应.md) §1 逐项对应，**改动须多处同步**。

## 2. 调用规则

1. 调用方式：本会话 Agent 直接调用 MCP 工具 `mx_api_invoke`，以 `apiId` 指定接口；检索主体为公司名称（用证券简称，**不得**带交易所后缀或证券代码）。
2. 两个接口相互独立、可并发调用；单接口失败或返回为空**不影响**另一个。
3. 超时与重复调用约束与 `SKILL.md` 一致：单次调用最长等待 1200 秒；同一调用累计不超过 2 次；超时或失败即停止本轮，禁止改写参数或更换标的重试、禁止后台执行。
4. 返回结果由 Agent 结构化落盘：`raw/事件库_已发生.json`（newsEventSearch）、`raw/事件库_未来.json`（futureEventSearch），保留接口原始返回供溯源；**不经 `scripts/news_api.py` 归一化**（该脚本只处理资讯检索 11 个场景，`raw/事件库_*.json` 不影响其场景注册表）。

## 3. 取值映射（催化事件时间表）

| 时间表行 | 主供数来源 | 取用内容 |
|---|---|---|
| 已发生的事件（≤4 行，倒序） | 已发生事件库（`newsEventSearch`） | 事件时间 + 事件内容 |
| 预计发生的事件（≤4 行，正序） | 未来事件库（`futureEventSearch`） | 预期时间 + 事件内容 |
| 补足与交叉验证 | 资讯检索场景 `1`（`showTime` + `chunk`） | 仅用于补足行数与交叉验证；补充行的时间只能来自 `showTime` |

- **「预期影响」列**：事件库未返回影响信息时，按 `prompts/01-公司近况跟踪.md` 使用统一降级文本「事件影响待后续披露」（唯一允许的占位）；禁止符号占位与留空。
- **跨接口去重**：事件库与场景 `1` 召回同一事实时**只算一条**，取信息最完整、量级最明确的一条。
- **事件筛选标准**（纳入/剔除类型）与 `prompts/01-公司近况跟踪.md` §二、`资讯检索-取数规范.md` §8 一致；纯股价波动 / 纯交易类 / 纯情绪类条目同样不得纳入表格。
- 行数不足照实输出（表格上方加「（已发生事件共 N 条）」「（预期事件共 N 条）」注释），**严禁复制/变体重复凑数**。

## 4. 零幻觉与合规（继承，不放宽）

1. 事件内容与时间**只能来自对应接口本次返回**，禁止补充接口未返回的事件、金额、订单量、产能数字、客户名或机构名。
2. 研报类内容只可提取基本面事实，**机构名、评级、目标价、投资建议一律不得进入输出**。
3. 低可信来源（自媒体 / 百科 / 非持牌资讯聚合）条目**不得单独成行**，须与交易所公告或主流财经媒体报道交叉验证一致后才可使用（分级见 `资讯检索-取数规范.md` §8）。
4. 事件库**不得**用于近况文字段或任何其他章节（通道边界见 `数据通道与来源对应.md` §4）。

## 5. 失败与降级

文字段与催化事件时间表**分通道独立降级、互不牵连**：

| 情形 | 处理 |
|---|---|
| 已发生事件库失败/为空、未来事件库可用 | 已发生行照实输出（可为 0 行，注明「（已发生事件共 0 条）」），预期行照常；不足不凑数 |
| 未来事件库失败/为空、已发生事件库可用 | 对称处理；预期行不足不凑数 |
| 两库皆失败/为空 | 表格回退资讯检索场景 `1` 供数：已发生行取 `showTime` ≤ 系统日的条目，预期行取正文中带明确未来时间节点的条目；场景 `1` 亦无可用事件 → 整表不渲染（一级章标题由渲染器保留） |
| 表格可用但近况文字段无事实支撑 | 只渲染催化事件时间表，文字段不渲染 |
| 文字段与表格皆无事实支撑 | 章节 1 只保留一级章标题「1 公司近况跟踪」，不输出任何解释性空状态 |
