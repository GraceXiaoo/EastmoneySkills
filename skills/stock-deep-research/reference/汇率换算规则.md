# 港股汇率换算规则

> 适用：港股链路中所有"原币种非人民币"的金额字段（章节 4.2 主营构成、章节 7 财务分析）。章节 8 一致预测**服务端已换算人民币**，**不再二次换算**。
> 取数通道 = MQL。

## 1. 汇率数据源

| 项 | 内容 |
|---|---|
| 对象类型 | 报表 |
| 基线路径 | `Choice报表\报表指标\Choice金融终端\企业F9\企业一页纸\主营构成\港股汇率|RPT_HK_HISTORY_EXRATE` |
| 检索词 | 港股汇率、历史汇率、港币汇率 |
| 读取方式 | 用 `REPORT_FIELD` 读"交易日期 / 原币种 / 目标币种 / 汇率"对应的中文返回列 |
| 口径 | 历史汇率（报告期末），**非**当前即期汇率 |

```mql
ReportBlock(#1, {Choice报表\报表指标\Choice金融终端\企业F9\企业一页纸\主营构成\港股汇率|RPT_HK_HISTORY_EXRATE});
SetReportFilter(
    {<原币种加载列中文名>} == "USD"
    AND {<目标币种加载列中文名>} == "CNY"
);
{交易日期}: REPORT_FIELD("<交易日期返回列中文名>");
{原币种}: REPORT_FIELD("<原币种返回列中文名>");
{汇率}: REPORT_FIELD("<汇率返回列中文名>");
Sort({交易日期}, "DESC");
OutputBlock();
```

> `SetReportFilter` 只能用候选 `reportFilterColumns[].column_name_cn`；若该报表未提供可用的加载列，则不做远端过滤，先全量读列再用本地 `FILTER_ROWS` 过滤（`FILTER_ROWS` 位置在输出列之后）。
> 汇率批次**必须先于**章节 4/7 的取数批次执行。

## 2. 换算时点选择（按报告期取历史汇率）

| 数据类型 | 取汇率的交易日期 | 说明 |
|---|---|---|
| 年报金额 | 报告期末日（如 2025-12-31）；非交易日取**之前最近交易日** | 与"历史汇率口径"一致 |
| 最新报告期金额 | 该报告期末日同上 | — |
| 比率类（毛利率/净利率/ROE/资产负债率/占比） | **不换算** | 比率无量纲 |

## 3. 执行顺序

1. 从章节 4.2 / 7 返回结果中的**币种列**判定原币种；
2. 原币种为人民币（CNY/CNH）→ 跳过换算，直接输出；
3. 原币种非人民币 → 按上表取该报告期末 `汇率`，`人民币金额 = 原币金额 × 汇率`；
4. 金额统一格式化为人民币亿元、保留 2 位小数；表格/图表标注"（人民币口径，历史汇率）"。

## 4. 校验样例

- 09992.HK 泡泡玛特：原币种人民币 → 不换算。2025 年营收 37,120,052,000 元 → 371.20 亿元。
- 09901.HK 新东方：原币种美元 → 需按各报告期末美元兑人民币汇率换算后输出。

## 5. 异常处理

- 汇率结果无该币种/该报告期记录 → 回退取该币种**最近可得交易日**汇率，报告中不额外说明（口径已在数据层固化）；
- 仍无法取得 → 该金额单元格按零幻觉降级策略处理（删除或标注），**禁止**用近似汇率估算后冒充精确值；
- 汇率批次检索/执行失败 → 章节 4.2 / 7 的金额维度整段降级。
