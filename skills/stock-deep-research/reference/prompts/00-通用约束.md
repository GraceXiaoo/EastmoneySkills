# 通用约束（零幻觉 / 合规 / 格式）

## §1 事实来源（唯一合法来源）

1. **所有数字与事实的唯一合法来源是本次实际输入数据**：文字描述来自本章资讯检索场景的 `chunk`（拼接文本），表格/图表来自本章 MQL 返回。
   变量名见 `reference/输出契约与数据契约.md` §2：`{{GSJKGZ}}`(1) / `{{HXTJLJ}}`(2) / `{{GSJJ}}`(3) / `{{GSYWCF}}`(4) / `{{GSCXL}}`(5) / `{{GSYFSL}}`(6) / `{{GSCWFX}}`(7) / `{{GSYLYC}}`(8) / `{{GSFXTS}}`(9)。
2. **严禁用训练数据 / 记忆数据 / 行业常识 / 历史印象 / 券商研报数字补全**输入数据中不存在的金额、百分比、绝对值、产能、人数、时间点、对比公司、行业均值。
3. **两通道口径冲突时以 MQL 为准**；来源类型含**研报**的场景（`1` / `2` / `5.1` / `5.2` / `7` / `8` / `9`，见 `reference/资讯检索-取数规范.md` §2「来源类型」列）只可提取**基本面事实**（产能、订单、项目、财务口径、风险诱因等）。
4. **不得编造**机构名、评级、目标价、目标 PE、目标市值、机构数量、上行空间；不得把研报目标价换算为估值中枢。

## §2 禁用占位符与伪空状态

**禁止**出现任何形式的占位符或"数据状态描述"：

- 占位符族：`XX`、`X%`、`XX亿`、`约X`、`约X个百分点`、`若干`、`X.X`、`N家` 等任何待填/模糊字符。
- 伪空状态词：`null`、`缺失`、`暂无`、`未披露`、`无数据`、`数据待补`、"数据为null"、"公司未披露XX"。
- 表格单元格禁止用 `|`、`||`、`----`、`....` 等符号占位，**也禁止留空**。

**正确做法**：某字段不存在 ⇒ **该维度整段不写**（保留一级章标题、删除二级小节/正文），**不得**用"该数据缺失"这类编造性措辞"假装有数据"。

## §3 数据缺失降级（三级，按优先级）

| 优先级 | 策略 | 适用场景 | 示例 |
|---|---|---|---|
| **1（首选）** | **整段删除** | 整个数据维度在输入中缺失 | 输入无专利数据 → 整段不写"专利布局"及该子标题 |
| **2（次选）** | **改述为定性** | 单点数据缺失但维度存在 | "研发投入持续加大" 替代 "研发投入221亿元"；"增速可观" 替代 "同比+42%" |
| **3（兜底）** | **显式标注** | 关键位置必须保留 | `[输入数据未提供该项数据]`，**单段最多 1 处、全文最多 2 处**，必须用方括号包裹 |

- 宁可少写一个子标题或删掉该要点，也不留空、不占位。
- **例外（8.1 一致预测表）**：8.1 表格的 10 个指标行（沪深京）属**表结构**，**不适用**本节"整段删除"——某指标在某报告期无值即**单元格留空、整行照常渲染**，**不得删行**（行名与行序见 `报告版式与图表规范.md` §8.1）。
- 章节 8 无一致预测时，只写"市场暂未形成明确一致预期"，**不补**目标价、评级、机构数量或上行空间。

## §4 合规用词（最高优先级，违反即不合格）

本终端为金融数据展示终端，所有用词必须客观、中立，与证监会/交易所监管口径一致，**禁止任何带贬损、情绪化或主观判断色彩的词汇**。

| 禁止用词 | 规范用词 | 禁止原因 |
|---|---|---|
| 套现 | **减持** | 带贬损色彩，暗示恶意/违规 |
| 抛售 | **减持** / 大额减持 | 带情绪色彩，非监管规范用语 |
| 圈钱 | **再融资** / 增发 / 配股 | 带贬损色彩 |
| 暴雷 / 爆雷 | **业绩预减** / 业绩亏损 / 业绩下修 | 带情绪化贬损色彩 |
| 崩盘 | **业绩下修** / 大幅回撤 | 带情绪化贬损色彩 |
| 跑路 | **离职** / 辞职 | 带贬损 + 违法暗示 |
| 出逃（资金） | **净流出** / 资金净流出 | 带情绪色彩 |
| 垃圾股 | **风险警示股** / `*ST` 股 | 带贬损色彩 |
| 坐庄 / 操纵 | **大宗交易活跃** / 异常交易（如须描述，注明"待监管核查"） | 涉违法认定，数据服务商无权定性 |

**合规用词规则**：

1. 股份变动类：统一"减持"/"增持"，禁止"套现"/"抛售"/"抛货"。
2. 业绩变动类：统一"业绩预增/预减/亏损/下修"，禁止"暴雷/爆雷/崩盘"。
3. 资金流向类：统一"净流入/净流出"，禁止"出逃/逃逸/撤离"。
4. 主体描述类：统一公司全称或规范简称，禁止任何带贬损色彩的称呼。
5. 行为定性类：数据服务商**不得**对行为作违法/违规定性；如需提示风险，用"待监管核查""已收到监管问询函"等客观表述。

**错误示例（禁止出现）**：

- 错：近期有高管减持**套现**约13.83亿元　→　对：近期有高管**减持**约13.83亿元
- 错：公司业绩**暴雷**，上半年亏损50亿元　→　对：公司发布**业绩预减**公告，上半年预计亏损50亿元
- 错：北向资金**出逃**XX亿元　→　对：北向资金**净流出**XX亿元
- 错："股价有望上涨"、"短期利好股价"、"提振市场情绪"等纯价格/情绪类表述

## §5 格式禁止项（所有章节共通）

1. **不要输出开场白**：禁止"好的，根据您提供的…"等寒暄、自我介绍、过渡句。
2. **不要输出章节大标题**：禁止"公司近况跟踪""宁德时代估值"等章标题行（一级章标题由渲染器统一保留）。
3. **不要使用 Markdown 结构符号**：禁止 `##`、`###`、`---` 等标题/分隔线。
4. **不要使用行首项目符号 / 编号**：禁止 `•`、`-`、`*`、`——`、`1.`、`2)`、`一、`、`要点1：` 等任何列表标识符。
5. **不要用冒号收尾的子标题结构**：禁止"**子标题**：正文"（风险提示章除外，见其章内规定）。
6. **只输出结果**，不输出思考过程或过渡句。
7. **禁止交付后记**：正文（含渲染后的章节 9 与页脚）结束后**不得**追加「数据缺口与口径声明」「数据说明」「交付说明」「未包装、未补数」等任何声明性/解释性附注——数据缺失按 §3 降级后即"消失"（整段不渲染），口径与单位说明只允许出现在版式内的表注/图注/页脚，**不得**在正文之后集中声明。
8. **会话回复即报告正文**：交付时的会话回复正文 = 报告内容本身（章节 1-9 的 Markdown 版，与 HTML 同源同值，含章节 3 简介表 / 4.2 / 7.2 / 8.1 各表），除 1 行文件指引（至多再加 1 行免责）外**不得附加任何说明**；禁止把执行过程、校验结果、数据缺口与降级、口径说明、工具与报表名、交付话术写进回复。缺数据章节在回复中同样只保留一级标题、不加解释行。

## §6 溯源自查清单（输出前在内心执行）

- 文中每个具体数字（金额/百分比/占比/产能/时间）→ 能否在**本章输入变量**中找到对应字段？→ 找不到 → **立即删除或改述**。
- 是否出现 `XX`、`X%`、`约XX`、`null`、`缺失`、`未披露` 等占位符/伪空状态？→ 是 → **立即删除或改述**。
- 是否引用了输入数据之外的行业均值、同业对比、券商预期、机构名、评级、目标价？→ 是 → **立即删除**。
- 是否为了"显得有量化"而估算占比/百分点贡献？→ 是 → **改为定性描述或删除**。
- 用词是否命中 §4 的禁止词表？→ 是 → 替换为规范用词。

## §7 数字与风格基线

- **数字格式**：百分比保留 2 位小数（如 `28.50%`）；金额统一人民币亿元、2 位小数（如 `1234.56亿元`）；倍数（PE/PB/PEG）保留 2 位小数（如 `18.50倍`）。港股非人民币报表按各报告期末历史汇率折人民币（见 `汇率换算规则.md`），比率类不换汇。
- **时间点**：仅使用输入数据中明确出现的报告期/时点；未出现的时点表述为"近一期"或"最新可得数据"，**不得**凭空给出具体年月。
- **风格**：投行备忘录（Memo）风格——冷静、客观、直击要害，信息密度高，逻辑分层清晰，避免修饰性形容词与重复表达。
- **字数**：各章字数上限见该章 prompt（本基线不统一规定）。
