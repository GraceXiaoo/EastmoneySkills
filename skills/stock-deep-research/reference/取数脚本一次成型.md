# 取数脚本一次成型（Block 编号连续 + 参数顺序固定）

> 目标：**不再手写 MQL Block**。脚本按批次一次产出整段可执行 MQL，从源头消除两类高频返工——
> ① Block 编号跳号 / 重号（规程 §7.9：编号唯一递增，只能引用更小编号）；
> ② 加载列 `SetReportFilter` 条件顺序随手写导致的漏参、错引号、错字面量类型。
>
> 机器可读定义：`scripts/mql_api.py` 的 `SCRIPTS`（脚本名 → 报表清单）、
> `PINNED_REPORTS[...]["params"]`（加载列声明顺序）、`MqlScript`（编号分配器）、
> `check_mql_script()`（自检）。本文件与这三处**必须同步维护**。

## 1. 三条硬规则

| 规则 | 机读实现 | 说明 |
|---|---|---|
| **Block 编号连续** | `MqlScript` 内部 `next_block_id` | 编号在 `add_report()` 里按追加顺序自动分配为 `1..N`，调用方**不得手写** `#1` / `#2`；不存在跳号、重号、引用更大编号的可能 |
| **参数顺序固定** | `PINNED_REPORTS[...]["params"]` 的声明顺序 | 同一报表的全部加载列条件写进**同一个** `SetReportFilter`，顺序即声明顺序；`AND` 语义与顺序无关，固定顺序只为消除返工、便于逐字比对 |
| **不猜值、不生成非法 Block** | `build_script()` 的跳过逻辑 | 取值缺失的**可选条件自动省略**并记入提示；返回列中文名未采集（`fields_pending`）的报表**直接跳过**并给出补录指引，绝不产出 `REPORT_FIELD("<占位>")` 之类非法语法 |

补充口径：**证券范围一律由 `SetCodes` 表达**，不重复写进 `SetReportFilter`
（`SECUCODE` 同时是该报表的返回列，按实测返回列中文名取用）。

## 3. 生成产物样例（沪深京 · 批次3）

```mql
ReportBlock(#1, {Choice报表\报表指标\Choice金融终端\A股F9\公司一页纸\公司产销链分析\主要客户情况和主要供应商情况|464277271454376});
SetCodes(["300476.SZ"]);
SetReportFilter({IS_MAXREPORTDATE} == 1
    AND {REPORT_DATE} == "2025-12-31"
    AND {TYPE} == "客户");
{客户名称}: REPORT_FIELD("客户名称");
{销售额}: REPORT_FIELD("销售额");
{占比}: REPORT_FIELD("占比");
{排名}: REPORT_FIELD("排名");
OutputBlock();

ReportBlock(#2, {…同一路径…});
SetCodes(["300476.SZ"]);
SetReportFilter({IS_MAXREPORTDATE} == 1
    AND {REPORT_DATE} == "2025-12-31"
    AND {TYPE} == "供应商");
{…同字段…}
OutputBlock();
```

- 两个 Block 编号 `#1` / `#2` 由脚本分配，天然连续；
- `SetReportFilter` 条件顺序固定为 `IS_MAXREPORTDATE → REPORT_DATE → TYPE`；
- `--report-date` 未给时该条件自动省略（不猜日期），只保留 `IS_MAXREPORTDATE == 1`（即"最新报告期"）。

## 4. 自检项（`--check`）

| 检查 | 判据 |
|---|---|
| Block 编号连续 | 声明出现的编号序列必须等于 `1..N`（不重、不漏、不跳） |
| 每块有输出列 | 每个 Block 到 `OutputBlock()` 之间至少一个 `REPORT_FIELD("…")` 或指标调用（规程 §7.9） |
| `OutputBlock` 配对 | `OutputBlock();` 数量 == Block 声明数量 |
| 路径单反斜杠 | 全文不得出现 `\\`（规程 §7.1） |
| 括号配平 | `(` / `)`、`{` / `}` 数量各自相等 |

任一不通过即返回非 0 退出码，并把问题打到 stderr——**先修脚本再 `Execute_MQL`**，不要带着语法错去试。

## 5. 与「固化表待补项」的关系

`build_script()` 会跳过 `fields_pending` 的报表（固化表 §4.1 的已知缺口，当前为
沪深京的 `主营构成` / `研发支出` / `员工构成` / `专利信息` / `财务摘要报告期` / `客户供应商`）。
补录方式（两步，缺一不可）：

1. 用一次 `Search_Context` 拿 `reportFields[].column_name_cn`；
2. **同时**写入 `scripts/mql_api.py` 的 `PINNED_REPORTS[...]["fields"]` 与
   [MQL-报表路径固化表.md](MQL-报表路径固化表.md) §4.1 对应行（两处必须一致）。

补录完成后，`--script` 会自动把这些报表纳入对应批次，无需再改任何代码。
