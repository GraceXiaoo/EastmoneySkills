|参数编号|英文简称|中文说明|取值范围|默认值|
|---|---|---|---|---|
|1|ReportDate|报告期||2025-12-31|
|2|Type|报表类型|1 合并报表<br>2 母公司报表<br>3 合并报表(调整)<br>4 母公司报表(调整)<br>5 合并报表(更正前)<br>6 母公司报表(更正前)|1|
|3|CurType|币种|1 原始币种<br>2 人民币<br>3 美元<br>4 港元<br>5 英镑<br>6 欧元<br>7 日元|1|
