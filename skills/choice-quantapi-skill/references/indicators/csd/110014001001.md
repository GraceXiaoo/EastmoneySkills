## 指标说明

下表是每个指标特有参数的说明，公共参数参见[csd函数说明文档]<!-- agent only: (./../../functions/csd.md)-->【3. 公共参数】部分。

|中文简称|英文简称|参数1|单位|精度|释义|
|---|---|---|---|---|---|
|基金公司管理规模_序列|FUND_SCALE||元|0.0000|基金公司旗下所有在管公募基金在截止日期前的资产净值的合计值(剔除ETF联接基金公告投资基金的资产，如ETF联接当期未公告相应投资比例，则按其最新基金类资产配置比例计算)。 其中，对于全流通上市的ETF基金，基金规模计算值=份额*单位净值； 对于其他基金，截止所选日期，基金最新公告公布的基金资产净值。 *将基金规模统一转换为人民币计价。<!-- 目录：发行人 / 金融机构指标 / 基金公司指标 -->|
|基金公司旗下基金数量_序列|FUND_NUM||只|0|基金公司旗下所有的基金总数。<!-- 目录：发行人 / 金融机构指标 / 基金公司指标 -->|
