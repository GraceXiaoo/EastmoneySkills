# MQL 取数映射与模板（verified 2026-09-29）

本文件是宏观资金面一页纸技能的数据获取权威参考。所有报表路径、过滤字段、返回字段均经 `Execute_MQL` 实测验证。

## 1. 数据源与 MQL MCP 工具

- 数据源：Choice 数据中心 HTTP API（基地址 `https://datacenter-choice.eastmoney.com/api/`），MQL 是其上的取数语义层
- 涉及的 MCP 工具：

| 用途 | MCP Server | 工具名 |
|------|------|------|
| 工作流/语法参考 | mcp-mql-tools（远程） | `Get_MQL_Reference` |
| 业务知识检索 | mcp-mql-tools（远程） | `Search_Business_Knowledge` |
| 报表/字段/指标定位 | mcp-mql-tools（远程） | `Search_Context` |
| 数据取数 | mcp-mql-tools（远程） | `Execute_MQL` |

- 取数顺序约束：首次生成 MQL 前必须依次完成 `Get_MQL_Reference` → `Search_Business_Knowledge` → `Search_Context`；后续补查可直接调用。`Execute_MQL` 仅接受完整 MQL 脚本，不接受自然语言。

### 2.1 资金面利率明细 `利率类型` 取值（实测）

`利率类型` 过滤字段实际取值覆盖：
- 银行间质押式回购：`DR001` `DR007` `DR014` `DR021` `DR1M` `DR2M` `DR4M`；`R001`(部分) `R007` `R014` 等，实测含 `R007`
- Shibor：`Shibor_O/N` `Shibor_1W` `Shibor_2W` `Shibor_1M` `Shibor_3M` `Shibor_6M` `Shibor_9M` `Shibor_1Y`
- 交易所回购（GC）：`GC001` `GC002` `GC003` `GC004` `GC007` `GC014` `GC028` `GC091` `GC182`
- 银行间买断式（FR/FDR）：`FR001` `FR007` `FR014`；`FDR001` `FDR007` `FDR014`
- **利差（直接提供，单位 bp）**：`R007-DR007`（实测值如 0.78、3.76、4.8）
- 其他：`DRO/N` 等以实际返回为准

> 注：`利率日报_资金面`（利率品种截面数据路径 Shape 口径）经实测返回 0 行，不可用；资金面利率一律使用上面已验证的 `利率日报_资金面_明细` 路径。

### 2.2 资金日历报表说明（gth 周报·本周关注）

- 同一公布日期可能对应多个 `业务名称`（如"缴准日""LPR公布日""美联储议息会议""中央政治局会议"等），各业务名称为独立行；`业务名称` 为空的行仍有发行/缴款/到期数据
- 数值列在重复行中重复出现，聚合时需按日期去重（如按日期 Group 取 MAX）
- 该报表同时覆盖：税期/缴准日标注、政府债发行额与缴款额、存单发行与到期、央行逆回购投放到期，是资金日历维度的主数据源

## 3. 日期窗口（agent 基于报告日 today 计算）

- `today` = 报告日（YYYY-MM-DD）
- `start45` = today - 44 天（近 45 个自然日，资金面利率明细折线图，覆盖约 30+ 交易日）
- `start30` = today - 29 天（近 30 个自然日，OMO 日度明细、回购成交统计、IRS、资金日历）
- `start60` = today - 59 天（近 60 个自然日，公开市场操作周度统计窗口，覆盖近 8 周）
- `start14` = today - 13 天（近 14 个自然日，短期窗口）

## 4. MQL 脚本模板（基线参考，已验证）

以下模板的报表路径、过滤列、返回列均已通过 `Execute_MQL` 实测。直接替换日期占位符即可执行。

**关键语法约束**：`SetReportFilter` 比较运算符用 `==`（非 `=`）；多条件用 `AND` 连接；路径内分隔符用单个反斜杠 `\`；`REPORT_FIELD("...")` 用返回列中文名（含括号全名如 `"利率(%)"`、`"成交金额(亿元)"`）。

```text
// ===== Block #1 央行公开市场操作日度明细（柱状图源，近30日）=====
ReportBlock(#1, {Choice报表\报表指标\Choice金融终端\活跃券F9\公开市场操作统计\公开市场操作情况});
SetReportFilter(
    {发生日期} >= "{start30}"
    AND {发生日期} <= "{today}"
);
{发生日期}: REPORT_FIELD("发生日期");
{业务类型}: REPORT_FIELD("业务类型");
{期限}: REPORT_FIELD("期限");
{利率}: REPORT_FIELD("利率");
{投放量}: REPORT_FIELD("投放量");
{回笼量}: REPORT_FIELD("回笼量");
{净投放量}: REPORT_FIELD("净投放量");
{资金流向}: REPORT_FIELD("资金流向");
{发行到期}: REPORT_FIELD("发行到期");

// ===== Block #2 按日汇总净投放（柱状图数据）=====
// 说明：#1 中同一交易日有"发行/到期"多行，每行的净投放量字段为当日全量净值，取 MAX 即可还原当日值；SUM 会重复放大。
GroupBlock(#2, #1.{发生日期});
{发生日期}: MAX(#1.{发生日期});   // 保留日期键（输出名不能与 GroupBlock 保留键冲突）
{净投放}: MAX(#1.{净投放量});
{投放}: MAX(#1.{投放量});
{回笼}: MAX(#1.{回笼量});
Sort({发生日期}, "ASC");

// ===== Block #3 公开市场操作周度统计（跨周节奏，近8周）=====
ReportBlock(#3, {Choice报表\报表指标\Choice金融终端\债券专题\央行动态\中国央行公开市场操作\货币投放(回笼)统计\货币投放(回笼)统计_周期统计});
SetReportFilter(
    {日期类型} == 2
    AND {开始日期} >= "{start60}"
    AND {截止日期} <= "{today}"
);
{现金流发生日期}: REPORT_FIELD("现金流发生日期");
{频率}: REPORT_FIELD("频率");
{逆回购}: REPORT_FIELD("逆回购");
{中期借贷便利}: REPORT_FIELD("中期借贷便利");
{净投放量}: REPORT_FIELD("净投放量");
{合计投放}: REPORT_FIELD("合计(投放)");
{合计回笼}: REPORT_FIELD("合计(回笼)");

// ===== Block #10 资金面利率明细（折线图源：DR007/GC 等，近45日）=====
ReportBlock(#10, {Choice报表\报表指标\Choice金融终端\利率与曲线\利率日报\资金面\三月均价走势\利率日报_资金面_明细});
SetReportFilter(
    {发生日期} >= "{start45}"
    AND {发生日期} <= "{today}"
);
{发生日期}: REPORT_FIELD("发生日期");
{利率类型}: REPORT_FIELD("利率类型");
{利率}: REPORT_FIELD("利率(%)");

// ===== Block #20 质押式/买断式回购成交统计（近30日）=====
ReportBlock(#20, {Choice报表\报表指标\Choice金融终端\债券专题\资金日历\资金面一页纸\质押式/买断式回购成交统计});
SetReportFilter(
    {开始日期} >= "{start30}"
    AND {结束日期} <= "{today}"
);
{传入日期}: REPORT_FIELD("传入日期");
{品种名称}: REPORT_FIELD("品种名称");
{加权平均利率}: REPORT_FIELD("加权平均利率(%)");
{成交金额}: REPORT_FIELD("成交金额(亿元)");
{成交量}: REPORT_FIELD("成交量(亿元)");
{成交笔数}: REPORT_FIELD("成交笔数(笔)");

// ===== Block #30 利率互换 IRS（近30日）=====
ReportBlock(#30, {Choice报表\报表指标\Choice金融终端\利率与曲线\利率日报\衍生品\利率互换\利率日报_衍生品_利率互换});
SetReportFilter(
    {发生日期} >= "{start30}"
    AND {发生日期} <= "{today}"
);
{发生日期}: REPORT_FIELD("发生日期");
{FR0071Y}: REPORT_FIELD("FR0071Y利率(%)");
{FR0075Y}: REPORT_FIELD("FR0075Y利率(%)");
{Shibor3M1Y}: REPORT_FIELD("Shibor3M1Y利率(%)");

// ===== Block #40 本周资金日历：国债/地方债发行缴款、存单发行到期、逆回购到期与投放（近30日）=====
ReportBlock(#40, {Choice报表\报表指标\Choice金融终端\债券专题\国泰海通周报\宏观市场\本周关注\宏观市场-本周关注});
SetReportFilter(
    {公布日期} >= "{start30}"
    AND {公布日期} <= "{today}"
);
{公布日期}: REPORT_FIELD("公布日期");
{业务名称}: REPORT_FIELD("业务名称");
{国债发行额}: REPORT_FIELD("国债发行额");
{地方政府债券发行额}: REPORT_FIELD("地方政府债券发行额");
{地方政府债缴款额}: REPORT_FIELD("地方政府债缴款额");
{同业存单发行额}: REPORT_FIELD("同业存单发行额");
{同业存单到期额}: REPORT_FIELD("同业存单到期额");
{逆回购到期额}: REPORT_FIELD("逆回购到期额");
{7天逆回购投放额}: REPORT_FIELD("7天逆回购投放额");
{14天逆回购投放额}: REPORT_FIELD("14天逆回购投放额");
{1个月逆回购投放额}: REPORT_FIELD("1个月逆回购投放额");
```

> 任一 Block 失败或为空时，对应维度标记"数据不可得"，跳过该维度分析与文字；不要硬凑报表。

## 5. 后处理逻辑与容错规则（agent 在内存中完成）

### 5.1 后处理逻辑

1. **政策利率提取**（`policy_rate`）：从 #1 OMO 日度明细取 `业务类型=="逆回购"` 且 `期限=="7天"` 且 `资金流向=="投放"` 且 `利率` 非空的最新行利率（即 7 天逆回购中标利率）。**禁止硬编码政策利率。** #1 不可得时，政策利率维度整体省略。
2. **按日汇总**（`daily`）：取 #2 按日汇总数据（净投放/投放/回笼），供柱状图（近 15 个自然日）。
3. **利率序列**（`rates`）：取 #10 资金利率明细中按 `利率类型` 过滤的序列：
   - `DR007`：当日值用于锚点对比，近 20-30 交易日序列用于折线图与 20 日均线
   - `R007`：用于 R007-DR007 分层判断；或直接取 `R007-DR007`（单位 bp，直接可用）
   - `GC001/GC007/GC014/GC028`：交易所维度
   - `Shibor_O/N` `Shibor_1M` `Shibor_3M`：Shibor 维度与期限利差
4. **周度数据**（`weekly`）：直接取 #3 公开市场操作周度统计（近 5-8 周），无需自行聚合。
5. **资金日历**（`cal`）：取 #40 数据，按日期去重（数值列取 MAX），识别：
   - 缴准日/税期：`业务名称` 含"缴准""税"标识的行
   - 政府债发行额/缴款额：逐日 `国债发行额` + `地方政府债券发行额`（发行），`地方政府债缴款额`（缴款）
   - 同业存单发行/到期：逐日 `同业存单发行额`/`同业存单到期额`
   - 逆回购到期/投放：`逆回购到期额`、`7天/14天/1个月逆回购投放额`（与 #1 交叉验证）
   - 时点事件：`业务名称`（如"LPR公布日""缴准日""中央政治局会议"等）
6. **参考结构**：

```json
{
  "as_of": "<today>",
  "policy_rate": null,
  "daily": [],
  "rates": null,
  "irs": null,
  "weekly": [],
  "cal": []
}
```

任一 Block 失败或为空时，对应维度标记为"数据不可得"，跳过该维度分析与文字。

### 5.2 容错与降级规则（§5 数据缺口处理）

取数原则：**MQL 为第一优先级；某维度 MQL 无法获取时降级引用权威外部数据（须标注来源与日期）；MQL 与外部均不可得才省略该维度。**

| 场景 | 处理 |
|------|------|
| 单个 Block 报"报表不存在/字段不存在/字段名错误" | 回到 §2 参考查询重新定位报表与字段；确认仍不可用则该维度启用外部兜底（见下表） |
| 单个 Block 成功但返回 0 行 | 该维度启用外部兜底（`WebSearch`/`WebFetch` 检索权威来源），取不到时整体省略 |
| 部分字段非空、部分为空 | 使用已有字段，空字段对应内容省略；可选择用外部数据补充空字段 |
| 整个 MQL 调用失败（鉴权/网络/连接器错误） | 降级为外部数据源取数（`WebSearch`/`WebFetch`/其他已授权 API），在头部 meta 与页脚注明"数据来源：公开渠道"，并提示用户检查 MQL MCP 配置（`em_api_key` 与连接器信任状态） |
| 政策利率取不到（#1 不可得） | 优先用外部公开数据（央行公告的 7 天逆回购利率）补齐；取不到则不硬编码，相关判断改用历史均值或省略 |
| 外部数据与 MQL 数据冲突 | 以 MQL 数据为准，冲突内容省略，不在正文展示矛盾数据 |

**外部数据兜底来源（优先权威）**：
- 中国人民银行官网/公告（逆回购、MLF、LPR、政策利率）；财政部/中债登（国债、地方债发行）；中国货币网（银行间拆借与回购利率 DR/FR/Shibor）；交易所（GC 回购）；公开财经媒体（资金面综述、税期/缴准时点、跨季预测）
- 引用时在正文或图表图注标注确切来源名称与数据日期，例如"（据中国人民银行公告，2026-09-2x）"

- **禁止**：将多个 Block 报错后硬用近似报表/字段替代；把未经核实的新闻/研报资料混入；用示例数据冒充当日数据。
