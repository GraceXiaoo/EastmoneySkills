# 报告格式规范（地方化债skill）

> 本文件由 `SKILL.md` 按需引用。**仅在准备生成报告时读取**（取数阶段无需加载）。
> HTML 可视化模板与示例见 `references/report_templates.md`；深度分析维度与测算公式见 `references/analysis_dimensions.md`。

## 一、报告结构（严格按此顺序）

最终输出必须是完整 HTML 报告，正文穿插可视化图表（可用内联 SVG 或 ECharts CDN）。

```html
<html>
  <head>  内部样式 + 可选 Charts 引入（可自行选择主题色）</head>
  <body>
    <h1>{地区名称}地方化债研究</h1>
    <p class="meta">生成时间：{YYYY年MM月DD日 HH时mm分ss秒} · 数据来源：东方财富Choice</p>

    <section class="abstract">
      <h2>摘要</h2>
      <p>{摘要：150~250 字，概述该地区化债画像、核心结论与关注点}</p>
    </section>

    <section>
      <h2>{维度标题1：由维度内容二次总结}</h2>
      <div class="chart">{可视化图表}</div>
      <p>{维度正文，重点加粗}</p>
    </section>

    <section>
      <h2>{维度标题2}</h2>
      <div class="chart">{可视化图表}</div>
      <p>{维度正文}</p>
    </section>
    ...（共 4~7 个维度，每个维度 = 维度标题 + 可视化图表 + 维度正文）

    <section>
      <h2>免责声明</h2>
      <p>{免责声明}</p>
    </section>
  </body>
</html>
```

## 二、各部分要求

- **标题**：格式为 `<地区名称>地方化债研究`。
- **生成时间**：精确到时分秒，格式 `YYYY年MM月DD日 HH时mm分ss秒`。
- **摘要**：开头陈列，约 150-250 字，概括该地区债务压力、隐性/城投债务体量、财政内生偿债能力、化债进度与手段、前景研判及关注点。
- **维度段落**：共 **4~7 个**；每个维度 = `<维度标题 + 可视化图表 + 维度正文>`；维度标题根据内容二次总结（不得照搬原始栏目名）；重点内容适当 `**加粗**`（同一自然段不超过 3 处）；图表须贴合维度内容且美观，类型可选折线 / 柱状 / 柱状堆叠 / 饼图 / 雷达 / 仪表盘 / 散点 / 矩阵气泡 / 热力图等。
- **正文从简（重要）**：每个维度正文控制在 1~3 个自然段，只保留结论与关键数据；**不得出现"本维度回答……""本维度聚焦……"等元表述**；**不单列"解读一/解读二""解读要点"等小节**，解读内容直接融入正文段落。
- **表格从简**：除风险名单等必要小表外，不渲染宽表/长表；"政府债发行节奏与计划执行"维度只出折线图与热力图，**不渲染"各省分券种季度计划发行额明细表"**。
- **结尾**：免责声明。
- **图表**：模板与写法见 `references/report_templates.md`。

## 三、维度 → 图表建议

1. 债务绝对压力与结构 → 堆叠柱/饼图（三层债务结构）+ 条形（广义债务率、城投债务同比变动）
2. 政府债发行节奏与计划执行 → 折线（新增一般/专项债全年额度累计落地进度）+ 热力图（省份×券种季度计划发行额）；**不出明细表**
3. 偿债洪峰与流动性 → 堆叠柱状（地方债偿还 vs 城投债偿还）+ 覆盖倍数标注
4. 财政内生偿债能力 → 仪表盘/条形（本息覆盖率、收支缺口）+ 折线（商品房价格环比）
5. 化债进度与执行强度 → 事件卡片 + 条形（动作强度信号计数）
6. 化债方式与政策工具 → 饼图/条形（六类工具使用频次）+ 摘要文本
7. 风险等级与前景研判 → 气泡矩阵（压力×能力×强度）+ 红橙黄绿名单表

正文始终以真实数据支撑，若某数据缺失则如实暂缺措辞，不编造。

## 四、图表规范（性能优化：轻量优先）

- **优先使用轻量内联 SVG**（或简单柱状/饼图 SVG），一次生成、无外部依赖、打开即显；仅在图表较复杂（散点/矩阵气泡/多轴）时才用 ECharts CDN，且需带 SVG 降级。
- **图表数量控制 4~7 张**：原则上每个分析维度 1 张，与维度数一致；不为"每段一图"而多渲染图表。
- 图表需贴合维度，颜色、标签、单位服务于金融报告阅读，不过度装饰；数据不足或缺失的图表不渲染，以文字说明代替。
- 中国市场配色约定：**涨用红、跌用绿**。
- 中文字体：图表/正文中文字体优先使用系统 `Microsoft YaHei`（Windows 默认）/ sans-serif，避免乱码。
- 所有图表必须与正文结构化数据一致，使用真实接口数据（或按其测算）生成，不得用虚构数值。

## 五、数值与格式约定

- 日期统一 `YYYY-MM-DD`；生成时间含时分秒。
- 金额单位按接口原始单位换算（亿/万元），统一到"亿元"，保留 2 位小数。
- 比例/利率/覆盖率/债务率保留 2 位小数。
- 负值（负缺口、负增速）如实展示，不自动转正。
- 测算指标须标注"测算"并说明公式；**公式、脚注与备注一律使用中文口径名称，严禁出现报表名（`RPT_...`）与字段英文名**（如"计划执行偏差 = 累计实际发行 ÷ 同期计划发行 − 1"，不得写成接口字段）；"政府债发行节奏与计划执行（含执行偏差）"部分尤其不得带出任何报表名或英文列名。
- 数据缺失用"—"，不编造数值，不用模型常识替换接口数据。
- **所有数字一律来自接口返回或由接口字段测算**：接口未返回的数值不出现；禁止用新闻/研报/广告等文本材料补数字或"发挥"成具体数值。
- **数据来源字段固定输出"东方财富Choice"**：报告 meta 行、图表底部数据源标签、表格备注行、事件卡片来源处，凡标注数据来源处一律统一写"数据来源：东方财富Choice"；**不附加接口名/报表名、参数、口径说明或括号解释**（如"（RPT_xxx）""（来源：xx 接口）"一律不写）。

## 六、措辞纪律（重要）

- 措辞专业严谨，尽量规避极端观点；**在中国市场区域内，"唱空/看空/断言"属高度敏感表达，必须杜绝。**
- 严禁使用"崩盘""暴雷""必然违约""资不抵债""债务危机爆发"等极端或唱空词汇。
- 使用"可能""需关注""若……则""或""综合来看""边际变化"等概率化、条件化、中性表达。
- 禁止"买入""卖出""持有""必定""稳赚""失控"等操作指令或绝对化表达。
- 区分事实、官方披露与市场观点；数据缺失时省略相应表述，不写"暂无数据/无数据"。
- 不编造缺失数值，不对接口未返回的数据做主观臆测。

## 七、免责声明模板

> 本报告由 AI 基于公开数据与第三方信息自动生成，仅供专业研究与参考，不构成任何投资建议、要约或承诺。
> 报告中的数据可能存在滞后、错误或遗漏，分析结论基于特定假设与模型，不保证准确性与完整性。
> 债券与地方政府债务市场有风险，投资需谨慎。投资者应独立判断并自行承担投资风险，必要时应咨询持牌专业机构。
> 本报告不代表开发者或数据源的立场。

## 八、质量检查清单

输出前必须自检：

1. 是否已解析地区名称并映射为正确 AREA_CODE。
2. **报告是否围绕「地方化债」主题**：正文是否以化债主线指标（最新化债情况/本息覆盖率/专项债余额/未来偿债/商品房销售/政府化债动态）为主，是否已弱化无关指标（二级市场、利差、就业等）。
3. **分析维度数量是否为 4~7 个**，且每维度含标题、图表与正文；底线维度（债务压力与结构、财政内生能力）是否保留。
4. 派生指标（广义债务率、到期覆盖倍数、三层结构占比等）是否由接口字段测算并标注"测算"与公式。
5. 是否按「取数编排」只调用核心接口、总调用次数控制在 10 次以内（未被 9501/9201 拖入多次无效重试）。
6. 是否按文本检索服务完成 4 个化债合并维度的检索（未拆成 7+ 次查询）。
7. 结构化数据字段是否与 `interface_catalog.md` / `frontend_indicators.md` 一致，未自造字段。
8. 正文与图表中的**所有数字是否 100% 来自接口返回或其测算**，是否存在用新闻/研报/模型常识补充的数值。
9. 正文分析字数是否达到 **800 字以上**（不含图表）。
10. 措辞是否中性专业，无唱空/极端/买卖指令表述。
11. 是否包含生成时间（精确到秒）与免责声明，且未泄露任何 API Key、密钥或敏感配置。
12. 最终输出是否为 HTML 且可独立打开，图表数据真实、数量合理（4~7 张，与维度数一致）。
13. 正文是否**未出现"本维度回答/本维度聚焦"等元表述**、**未单列"解读/解读要点"小节**，且维度正文精简。
14. 数据来源标注是否**一律为"东方财富Choice"**，未附加接口名、报表名、参数或口径说明等解释性文字。
15. 正文、图表标签与脚注是否**未出现报表名（`RPT_...`）与字段英文名**（测算公式一律用中文口径名称）；
    **"政府债发行节奏与计划执行"维度中的"执行偏差"（计划执行偏差）部分尤其不得带出任何报表名或英文列名**。
