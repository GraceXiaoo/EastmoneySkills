# 深度分析维度框架与测算规则（地方化债 2.0）

本文件是 2.0 版报告的**分析骨架**：给出 4~7 个推荐维度的解读逻辑、派生指标公式、阈值分档与深挖点。
所有数值（含派生指标）必须来自报表接口字段或其测算，示例中的具体数字仅用于说明解读方法，
**不得直接写入报告**，报告一律以接口最新值重算。

## 维度一 债务绝对压力与结构 —— 债有多重、是什么债

**对应数据**：最新化债情况（`HIDDENDEBT_BALANCE` 最新隐债规模、`IMPLICIT_DEBT` 城投及地方国企债务、
`IMPLICIT_DEBT_CHANGE` 债务变动百分比）、专项债余额（`BALANCE` / `RELATIVE_SCALE`）。

**解读要点**

1. 把债务拆成三层：
   - **显性**：政府债券/专项债（限额内、利率低，风险相对可控）；
   - **隐性**：`HIDDENDEBT_BALANCE`（最新隐债规模）；
   - **经营性**：`IMPLICIT_DEBT`（城投及地方国企债务）。
   真正的压力不在显性层，而在隐性与经营性债务的体量，及其与显性债务的比例。
2. **广义债务率（测算）** =（专项债余额 + 隐债规模 + 城投及地方国企债务）÷ GDP × 100%。
   比单看法定债务率更能识别隐性压力集中在哪。`RELATIVE_SCALE`（专项债余额/GDP）已 >1 的地区，
   再叠加隐债与城投债务，广义口径往往显著抬升，是化债主战场。
3. **深挖点**：`IMPLICIT_DEBT_CHANGE`——化债期内城投债务仍高速扩张（正增长且幅度大）的地区，
   说明“边化边增”，化债成果可能被新增融资侵蚀；负增长的地区则体现融资收缩。

## 维度二 政府债发行节奏与计划执行 —— 新增额度用得快不快、供给压力大不大

**对应数据**：地方债计划发行限额（省级×月度，四类券种——新增一般债 / 再融资一般债 / 新增专项债 /
再融资专项债——的“计划值/实际值”与全年新增限额）、地方债一级市场（单券明细：招标日、类型、性质、
期限、发行量、票面利率、全场倍数、募集资金用途）。

**预处理**：限额表为**两级表头**，单元格形如“计划值/实际值”（如 `177.31/-`），需拆分；`-` 按空值处理；
全年限额含千分位逗号需清洗；sheet 名含季度标识，需**动态匹配最新季度**。

**解读要点**

1. **新增 vs 再融资结构**：季度新增债计划（新增一般 + 新增专项）与再融资债计划（再融资一般 +
   再融资专项）的比例，反映“扩张型”与“周转型”供给的相对强弱。
2. **计划执行偏差（测算）** = 累计实际发行 ÷ 同期计划发行 − 1。正值＝超前发行（供给前置），
   负值＝发行滞后（推后至后续月份）；据此识别供给回补的主力省份。
3. **全年额度累计落地进度（测算）** = 累计实际发行 ÷ 全年新增限额 × 100%。进度偏慢说明
   四季度存在集中发行压力。
4. **一级市场温度佐证**：招标全场倍数、票面利率与加点，作为供给节奏的一级市场印证（仅定性佐证，
   不并入额度测算）。

> **正文表述约束（重要）**：本维度「计划执行偏差」与「全年额度累计落地进度」的正文、图表标签、
> 脚注与备注，一律使用**中文口径名称**（如“累计实际发行”“同期计划发行”“全年新增限额”“全年新增一般债/专项债限额”），
> **严禁出现报表英文名（如 `RPT_CUSTOM_BOND_PLAN_AREAISSUEQUTA`）与字段英文名**；
> 计划值/实际值、四类券种等口径也用中文表述（如“新增一般债计划值/实际值”），不得带出任何英文列名或报表标识。

**图表**：新增一般债 / 新增专项债“全年额度累计落地进度”折线图 + 省份×券种“季度计划发行额”热力图。

> **本维度仅输出上述 2 张图与正文，不渲染“各省分券种季度计划发行额明细表”**（避免冗长）；正文从简，
> 不单列“解读”小节。

## 维度三 未来 1~2 年偿债洪峰与流动性风险 —— 什么时候最难熬

**对应数据**：未来偿债（`REPAY_AMT_DFZ` 地方债偿还、`REPAY_AMT_CTZ` 城投债偿还），
联立维度四的 `LOCAL_FUND`（可供还债的地方财政资金）。

**解读要点**

1. 化债痛点不是总量，而是**期限错配**：把“未来到期本金”与当年“可供还债财政资金”对比，
   得到**到期债务覆盖倍数（测算）** = `LOCAL_FUND` ÷（`REPAY_AMT_DFZ` + `REPAY_AMT_CTZ`）。
   **小于 1** 的地区意味着必须依赖再融资“借新还旧”，对政策与市场敏感度极高。
2. 区分**地方债偿还 vs 城投债偿还**的结构：
   - `REPAY_AMT_CTZ` 远大于 `REPAY_AMT_DFZ` → 风险点在城投公开市场债券，受债市行情与再融资政策影响大；
   - 以 `REPAY_AMT_DFZ` 为主 → 风险点更偏财政内生。
3. **深挖点**：识别“城投债集中到期省份”——这类地区一旦出现技术性违约，冲击的是整个区域的信用定价。

## 维度四 财政内生偿债能力 —— 靠自己还不还得起

**对应数据**：本息覆盖率（`REEX_GAP` 收支缺口、`LOCAL_FUND` 可供还债资金、
`BOND_BALANCE` 专项债还本付息支出、`COVERAGE` 覆盖率）、商品房销售
（`PRICE_COMHOUSE_MOM` 环比、`PRICE_COMHOUSE` 价格）。

**解读要点**

1. 核心指标 **`COVERAGE` 本息覆盖率**：分档参考——
   `<30%` 严重不足（必须靠外部输血）；`30%~60%` 偏紧；`60%~100%` 基本平衡；`≥100%` 相对充裕。
   低覆盖率地区自身财力对专项债本息的覆盖严重不足。
2. **`REEX_GAP` 收支缺口为负且绝对值大**的地区，财政“造血”能力弱，化债资金更多依赖转移支付与资产盘活。
3. 把**商品房销售**当作**土地出让收入的前瞻指标**：地方政府性基金收入（化债重要财源）高度依赖卖地。
   `PRICE_COMHOUSE_MOM` 停滞甚至下行的地区，意味着未来 1~2 年基金收入继续承压，“以地化债”空间收窄。
   这是把“本息覆盖率表”与“商品房销售表”联动才能看到的逻辑。

**图表**：覆盖率仪表盘/条形 + 收支缺口条形 + 商品房价格环比折线。

> 口径提示：`COVERAGE` 为专项债本息口径；`到期债务覆盖倍数` 为地方债+城投债口径，两者不同，
> 报告中须分别标注，不可混用。

## 维度五 化债进度与执行强度 —— 化得快不快、真不真

**对应数据**：政府化债动态（`DEFUSE_DEBT_PROCESS` 化债进度）、最新化债情况
（`HIDDENDEBT_BALANCE`、`INVEST_INDEX`）。

**解读要点**

1. 从动态文本中**提取可量化信号**，构建省级“化债动作强度”画像：
   - 再融资债券发行额（如“自治区代发行再融资债券 XX 亿元”）；
   - 置换隐债金额、隐性债务化解进度（如“化解进度超 140%”）；
   - 债务率及风险等级（如“债务率 112%（属绿色，债务率<120%）”）；
   - 融资平台压降/整合数量（如“平台数量压降进度位居全区第二”）；
   - 融资成本下降幅度（如“加权平均利率较上年下降 XX 个基点”）。
   信号密度越高、可量化程度越高，化债执行强度越强。
2. 对比两类画像：
   - **积极化解型**：隐债存量大 + 化债动作密集；
   - **风险淤积型**：隐债存量大 + 动作模糊。
3. **深挖点——警惕“口径美化”**：有的地区只强调“余额控制在限额以内”，这仅是法定债务合规，
   不代表隐债与城投压力缓解。要区分**合规叙事**（限额内、零违约）与**实质降债**（置换额、
   进度%、平台压降、成本下降）。

**图表**：事件卡片（公告标题+进度摘要+来源）+ 动作强度信号计数条形。

## 维度六 化债方式与政策工具使用 —— 用什么手段化

**对应数据**：政府化债动态（`DEFUSE_DEBT_PROCESS` 文本挖掘）。

**解读要点**：从官方表述归纳**六类工具**的使用频率与组合：

| 工具类别 | 典型表述/来源 | 性质 |
|---|---|---|
| 再融资债券置换 | “发行再融资债券偿还到期本金/置换隐性债务” | 最主流（借新还旧＋置换） |
| 特殊再融资债 / 拖欠企业账款专项债 | “发行用于化解政府拖欠企业账款专项债券” | 化解政府欠账，兼顾稳营商环境 |
| 资产盘活 | “闲置土地、基础设施、国有经营性资产盘活” | 内生财源 |
| 城投平台整合转型 | “331 口径”“瘦身健体”、平台退出 | 结构性降债 |
| 展期降息、政银企协调 | “展期降息”“争取金融支持” | 金融化债（政策性让利） |
| 向上争取 | “转移支付、超长期特别国债、中央预算内投资” | 中央资源依赖 |

**深挖点**：区分**财政主导型**（自己增收节支、资产盘活）与**政策依赖型**（靠中央额度与金融让利）——
后者在再融资政策边际收紧时最脆弱。

**图表**：六类工具使用频次饼图/条形 + 工具组合摘要。

## 维度七 风险等级与前景研判 —— 未来往哪走

**对应数据**：政府化债动态（`DEFUSE_DEBT_OUTLOOK` 化债展望）+ 全部结构化数据交叉。

**解读要点**

1. **区域化债风险矩阵（测算）**：横轴 = 偿债压力（维度一、三：广义债务率、覆盖倍数），
   纵轴 = 内生能力（维度四：本息覆盖率），气泡大小 = 化债强度（维度五、六）。
   把地区划入象限：高压高能力（可控）/ 高压低能力（重点关注）/ 低压低能力（平稳）等。
2. **官方情绪信号**：从 `DEFUSE_DEBT_OUTLOOK` 提取极性——
   - 示警词：“任务依然艰巨”“空间可能收紧”“压降非刚性支出”“偿债压力逐月上升”；
   - 乐观词：“超额完成”“良性循环”“风险总体可控”“零逾期零违约”。
   官方自己示警的地区，需重点关注。
3. **输出落地**：形成“红橙黄绿”区域名单 + 每省 3~5 条核心结论，可直接作为研究报告骨架。

## 派生指标与测算规则汇总

| 指标 | 公式 | 数据来源字段 | 说明 |
|---|---|---|---|
| 广义债务率 | （专项债余额 + 隐债规模 + 城投及地方国企债务）÷ GDP × 100% | `BALANCE`,`HIDDENDEBT_BALANCE`,`IMPLICIT_DEBT`,`GDP` | 测算口径，非法定债务率 |
| 三层债务结构占比 | 各层 ÷ 三层合计 | `BALANCE`/`HIDDENDEBT_BALANCE`/`IMPLICIT_DEBT` | 显性/隐性/经营性 |
| 显性债务率 | 专项债余额 ÷ GDP（或 `RELATIVE_SCALE`） | `BALANCE`,`GDP`,`RELATIVE_SCALE` | 直接取 `RELATIVE_SCALE` 即可 |
| 到期债务覆盖倍数 | 可供还债的地方财政资金 ÷（地方债偿还 + 城投债偿还） | `LOCAL_FUND`,`REPAY_AMT_DFZ`,`REPAY_AMT_CTZ` | <1 需借新还旧 |
| 专项债本息覆盖率 | 直接取 `COVERAGE` | `COVERAGE` | 接口已给 |
| 城投债务变动幅度 | 直接取 `IMPLICIT_DEBT_CHANGE` | `IMPLICIT_DEBT_CHANGE` | 正=扩张（边化边增） |
| 城投债集中到期 | `REPAY_AMT_CTZ` 显著大于 `REPAY_AMT_DFZ` 且绝对额居前 | `REPAY_AMT_CTZ`,`REPAY_AMT_DFZ` | 信用定价敏感区 |
| 化债动作强度 | 动态文本信号密度计数 | `DEFUSE_DEBT_PROCESS` | 定性→半量化 |
| 官方情绪极性 | 展望文本示警词/乐观词计数 | `DEFUSE_DEBT_OUTLOOK` | 定性 |
| 发行计划执行偏差 | 累计实际发行 ÷ 同期计划发行 − 1 | 地方债计划发行限额表（计划值/实际值） | 正=超前发行、负=发行滞后 |
| 全年额度累计落地进度 | 累计实际发行 ÷ 全年新增限额 × 100% | 同表（全年新增一般/专项债限额） | 进度偏慢→四季度集中发行压力 |

> 所有测算指标须在报告中标注“测算”并给出公式；**公式、脚注与备注一律使用中文口径名称，严禁出现报表名（`RPT_...`）与字段英文名**（如“计划执行偏差 = 累计实际发行 ÷ 同期计划发行 − 1”，不得写成接口字段或报表标识）；测算值不得与法定口径混称。

## 维度取舍与数量约束

- 正文维度数 **4~7 个**（含），不得超出。
- **底线维度**：维度一（债务压力与结构）、维度四（财政内生能力）必须保留。
- 维度二（政府债发行节奏与计划执行）按数据可得性输出；限额/一级市场数据缺失时省略或并入维度一。
- 数据缺失时**合并相邻维度**（如缺城投债偿还则维度三并入维度一并弱化城投债部分），
  不得为凑数而硬造维度，也不得因合并而少于 4 个维度。
- 每个维度配 1 张图表，图表数 = 维度数（4~7 张）。
