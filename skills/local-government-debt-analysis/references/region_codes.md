# 地区编码映射表（省级 + 规则）

地方化债各报表数据接口以六位行政区划代码（GB/T 2260 口径）作为 `AREA_CODE` / `REGION_CODE` /
`PROVINCE_CODE` 筛选依据。收到地区名称后，先按下表解析为编码；**全国口径统一用 `100000`**。

## 行政区划代码规则

- 六位编码：前两位 = 省/自治区/直辖市，前四位 = 地级市，六位 = 区县。
- 省级编码末四位为 0000（如 320000=江苏省）；市级编码末两位为 00（如 320100=南京市）。
- 多数地方化债报表以**省级口径**为主体：
  - 用户给省级 → 直接用下表编码。
  - 用户给市级/区县 → 优先向上解析到省级编码用于省级主体报表，同时保留市级编码（如 320100）用于市县级报表（`RPT_DEBTREMOVE_AREA_PLATFORM`、`RPT_BOND_CITYBOND_MAP` 等）。
  - 用户给“全国”/“汇总” → 用 `100000`，并配合 `AREA_TYPE=3` 或 `AREA_CODE_F="100000"` 类写法（见 `interface_catalog.md` 各报表）。
- 若用户输入地区不在下表（如县级市/新增开发区），用宏观数据检索或行政地图接口确认其上级行政区划代码后再继续，不得编造编码。
