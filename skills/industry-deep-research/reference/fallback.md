# 降级 · 错误处理 · 重试规则

> 报错、需要重试、或不确定某步骤是否可跳过时读本文件。

## 1. 依赖分级

| 依赖 | 级别 | 缺失时行为 |
|---|---|---|
| MQL 工具链（报表取数） | **刚性** | 不可用则停止，提示用户检查工具链连接，不进入后续流程 |
| 三张指数报表 + 产业链搜索报表 | **刚性** | 缺一不可，取不到即报告失败原因 |
| 妙想 MCP 搜索（研报/资讯/公告） | 可降级 | 跳过 Step 3.4 / 3b.6，用已有数据生成报告，交付说明中注明 |
| 对话内交互预览（ECharts/SVG） | 可降级 | 跳过，不影响交付 |
| 分享链接发布 | 可降级 | 先交付本地三份，询问是否发布 |

**原则：绝不因可降级项缺失而中断或反复重试。**

## 2. 错误话术

| 场景 | 话术 |
|---|---|
| MQL 执行失败 | 「MQL 查询失败：[错误信息]。请检查产业代码是否正确，或稍后重试。」 |
| 无匹配产业/指数 | 「未找到与 {关键词} 相关的分析。」 |
| 数据接口失败 | 「数据获取暂时不可用，请稍后重试。」 |
| 其他异常 | 「报告生成服务暂时不可用，请稍后重试。」 |
| 用户选择编号非法 | 「请选择列表中的编号。」 |

## 3. 重试与放弃规则

1. **同类错误重试上限 2 次**：同一段 MQL / 同一脚本连续 2 次报同类错误，立刻停手，改用预案（换字段名 / 换路径 / 走兜底）；仍不行则向用户明确报告失败原因，**不得无限循环**。
2. **报错即查根因，不改了就重试**：报语法/编号错误时先按下面「自查清单」修正再重试。
3. **可降级项失败不阻塞**：跳过并在交付说明中注明。
4. **空集是终态**：同一组参数返回空集，不得用同义改写反复试探；重试必须改变候选路径、字段、过滤条件或查询方法。
5. **MQL 累计修改 ≥3 次仍失败 → 停止重试**，输出诊断结论。

### MQL 报错自查清单

| 症状 | 检查 |
|---|---|
| 报「先调用 MQL 生成参考」 | 补一次 `Get_MQL_Reference` 后重试 |
| 报「X 是报表返回列，不是加载列」 | `SetReportFilter` 只能用 `reportFilterColumns[].column_name_cn`；把该条件改成 `REPORT_FIELD` + `FILTER_ROWS` |
| 报字段不存在 | `REPORT_FIELD("中文名")` 必须与 `reportFields[].column_name_cn` **完全一致**（含括号、单位、空格） |
| 报表取回 0 行 | ① 成分股详情是否漏了 `SetReportFilter({交易日期} >= ...)`；② 该报表是否本身不可用（如指数F9成分行业）；③ 是否选到了 `reportStandardCodeSupported=false` 的同名变体 |
| 报 Block 编号 / 语法错误 | Block 编号从 `#1` 起连续递增；`OutputBlock()` 不带参数；每条语句 `;` 结尾；路径单反斜杠 |
| 报「未写 SetCodes」 | 指数三报表必须 `SetCodes(["XXXXXX.EI"])` |

## 4. 脚本角色（避免误调用）

| 脚本 | 角色 | 是否参与执行 |
|---|---|---|
| `scripts/save_report.py` | **唯一输出出口**：读 Markdown → md/docx/pdf/html | ✅ 必须 |
| `scripts/get_data.py` | 报表路径常量、`build_*` 脚本生成、`format_*` 格式化参考；不直接拉数据 | ⚠️ 参考，可取可不用 |

> 数据获取一律由 Agent 经 MQL 工具链完成；正文组装在上下文完成；最终只调 `save_report.py`。

## 5. 已知陷阱（实测）

1. **产业搜索路径选择**：`329428787766940` 可用「产业类型」做加载列过滤；旧路径 `564217624877789` 不行（会报 `MQL_PLAN_ERROR`）。
2. **成分行业分布报表已不可用**：`指数F9成分行业|828709189779714` 实测 6 组参数全 0 行 → 直接用成分股「行业」字段聚合兜底，不要再试参。
3. **估值通道周频单指数 346 行**：4 指数全量 ≈ 1,384 行 × 6 列 ≈ 8,304 单元，放大约 15 倍。必须 `Sort({周交易日},"DESC") + Head(N)` 限定窗口。
4. **`REPORT_FIELD("指数代码")` 不带后缀**：返回 `8880781`；带后缀的是「指数代码带后缀」。
5. **`API专题报表函数\...` 变体 `reportStandardCodeSupported` 多为 false**：一旦选中就不能写 `SetCodes`，成分股详情会整段取不到数。
6. **`LIKE` 是字符串包含匹配**：产业搜索过滤直接写 `FILTER_ROWS(LIKE({产业名称}, "<关键词>"))`。
7. **同名报表变体多**：指数基本信息有 4 个同名变体，默认恒选 `指数F9\一页纸\指数基本信息|292749174710315`。
