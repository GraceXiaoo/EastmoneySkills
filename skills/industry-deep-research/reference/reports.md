## 3. 检索重取流程（路径失效时）

```
1. Search_Business_Knowledge(varieties=["板块","指数","沪深股票"], user_query=<原句>,
       keywords=[<报表中文名>, 相关词], query_rewrites=[2~3条标准化改写])
   → 记录返回的全部 typeCodes
2. Search_Context(typeCodes=<首次原样全量>, searchIndicator.keys=[<报表中文名>], searchSector.words=[<所属业务域>])
   → 在 results.Search_Indicator.data.results[] 中取 type="报表" 的候选
3. 校验：候选须含 reportFields 与 matchedReportFields（报表专用字段），取 indicatorPath 解码后的完整值
4. 更新本文件对应行，并在「变体盘点」补记新旧关系
```

**路径写法红线**：JSON 中的 `\\` 只是转义，写入 MQL 时每个路径边界**只能有一个实际反斜杠** `\`；末尾 `|指标ID` 必须原样保留。
