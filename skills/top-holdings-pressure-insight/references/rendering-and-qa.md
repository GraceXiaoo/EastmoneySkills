# 报告生成、渲染与质检规范（6.0）

## 1. 目的

本规范用于避免 PDF 页面方向切换、生成器重写、文件创建和图片分析等宿主差异导致报告链路中断。它不限定唯一库，而是要求在完整生成前确认能力，并选择可重复验证的路径。

## 2. 生成前能力探测

在目标工作目录执行小规模测试，不要直接拿完整报告试错：

1. 创建、读取并删除一个短 UTF-8 临时文本，确认目录可写、中文文件名和路径长度可用。正式成果使用简单、稳定的文件名；平台对中文路径支持不明时，内部中间文件使用 ASCII 名称。
2. 查找至少一种可用 PDF 路径：浏览器打印、HTML/CSS 转 PDF 引擎，或 ReportLab。用一页中文、一个小表格生成最小 PDF，并确认文件非空、页数可读、中文可提取。
3. 查找可用中文字体并显式注册或通过 CSS 指定；不得假定某个平台必然安装同一字体。
4. 查找至少一种 PDF 转图能力和一种图片查看能力。先渲染最小 PDF 的第一页并查看；若无图片查看能力，预先标记为“程序化 QA”，不得在完整报告完成后才发现工具缺失。

能力探测结果只需在内部记录，不写入面向用户的报告。

## 3. PDF 路径选择

### 3.1 优先路径：由最终 HTML 打印为 PDF

当 Chromium、Playwright 或兼容的 HTML/CSS PDF 引擎可用时，优先复用最终 HTML 的正文样式与内容。打印前隐藏交互弹层、提示和按钮装饰。使用本地资源或内联资源，不依赖联网字体、脚本或样式。

为保证跨引擎稳定，包含宽表时默认整份 A4 横向。不要假定命名 `@page`、章节级页面方向或复杂分页 CSS 在所有引擎中行为一致。

### 3.2 回退路径：ReportLab

ReportLab 可用时采用单一页面方向构建整份文档。包含宽表时使用 A4 横向，并在开工前用最宽的一张表做一页试排。

不得把 `NextPageTemplate`、文档中途切换模板或不同版本下未验证的 PageTemplate 行为用于正式报告。确需混合方向时，只有在最小样例验证成功后才可采用；否则生成独立 PDF 分段并用当前环境已有的稳定 PDF 合并库合并。合并不是默认方案，也不得为了合并临时强依赖 PyMuPDF。

### 3.3 不可用时

若没有任何可用 PDF 引擎，仍可交付已验证的 HTML，并明确说明缺失的 PDF 能力及探测结果。不得伪造 PDF、输出空文件或宣称 PDF 已生成。

## 4. 安全写入与修改

- 中间文件统一放在任务工作目录，不写入技能目录、系统目录或不可确认权限的位置。
- 生成器修改采用新文件或临时副本；先完成语法检查和最小运行，再替换当前可运行版本。
- 禁止先删除旧生成器。不要在一次文件创建调用中写入过大的完整程序；必要时使用已有模板、补丁式修改或拆分为稳定模块。
- 文件创建失败后，先确认目标目录存在、路径可写、文件未被占用、名称和内容规模合理。只做一次针对明确原因的重试。
- 每次成功生成后立即检查文件存在、大小大于零、可被解析，再进入下一阶段。

## 5. 数值格式

分析数据保留源值。展示层使用统一格式化函数，不在 HTML 与 PDF 中分别手工格式化：

- 排名、基金数量：整数。
- 百分比和 `%ADV` 展示字段：优先保留源展示字符串；若只能从数值字段展示，使用业务约定精度并在两种输出中保持一致。
- 普通压力数值：最多 6 位小数，去掉无意义尾零；不得用二进制浮点的长尾直接输出。
- 缺失值保持缺失语义，不转换为 0。

溯源弹层的原始数据仍保留 MQL 本次返回的字段、顺序与值；正文格式化不覆盖原始载荷。

## 6. 分层质检

质检按以下层级执行，并记录哪些层级实际完成：

1. **结构检查**：HTML 可解析、必需章节存在、四榜行数和字段符合本次数据；PDF 可解析、页数大于零、文字可提取。
2. **几何检查**：所有 PDF 页面尺寸符合预期；表格计算宽度不超过可用页宽；图片和表格没有负坐标或明显越界。若整份横向，确认所有页均为横向属于预期，不要误判为模板切换失败。
3. **视觉检查**：将 PDF 渲染为图片，先看首页、最宽表格页、跨页表格页和末页；再抽查其余页面。检查中文字体、裁切、重叠、孤行、表头重复与无意义留白。
4. **一致性检查**：抽取至少 5 个关键证券/数值，对比 HTML、PDF 与原始数据；核对数据日期、核心结论和排名。
5. **HTML 交互检查**：验证至少一个核心结论、一个证券和一个榜单标题的 hover、点击、键盘和关闭行为。

## 7. 图片查看失败的回退

图片分析或查看工具失败时，按顺序处理：

1. 确认图片已成功生成且格式受支持。
2. 一次只查看一页，优先关键页；必要时降低到 120—160 DPI，避免一次提交多张大图。
3. 换用宿主已有的本地图片查看能力；不要重复调用同一失败工具和同一输入。
4. 仍不可用时完成结构、几何、文本与一致性检查，并明确标记“未完成视觉检查”。不得因此声称视觉 QA 已通过，也不得删除已经通过其他检查的 PDF。

## 8. 完成判定

只有实际完成结构、几何、一致性检查，并完成视觉检查或明确披露视觉检查不可用时，才能结束。任何“通过”结论必须对应已执行的检查；工具调用失败、推测页面看起来正常或仅成功生成文件，都不能等同于 QA 通过。
